# Nature DQN 2015 再現構成

# Mnih et al. 2015 の Breakout 401.2 が再現できるかを見る検証用。目的は成績追求ではなく
# 「実装が健全か」の切り分け(再現できれば以後の未達はハイパラ調整の問題と確定できる)。
#
# 有効化する 2 行:
#   DefaultDQNAgent.$ = DefaultDQNAgent.baseline > A > BF16.agent > NatureDQN > R > X
#   AtariEnv.$ = AtariEnv.classic > E
# あわせて net.branch.[main_feature].$ = net.branch.AtariNature(論文と同一 CNN)であること。
#
# 合わせる: 素の DQN(分布 RL / PER / n-step / dueling / double を全て切る)、
#           Extended Data Table 1 のハイパラ、classic env(noop 30 / fire_reset)。
# 合わせない: optimizer(論文 RMSProp 0.00025。RMSProp は未実装のため Adam のまま)、
#             minibatch(論文 32。256 のままにするのは更新回数が 8 倍になり実行時間が
#             数十時間に伸びるため)。RR 8 は論文の「batch 32 ÷ update frequency 4」と一致済み。
#             BF16 は速度設定なので有効のままとする。
#
# 配線: quantile_mode=none + use_dueling_net=false は LinearHead になり、value_feature /
#       adv_feature ではなく `features` だけを読む。NN 章の net.body.output.[features] が
#       これを供給する(未指定だと起動時に fail-fast)。実 Run 前に 0.05M 程度で起動確認すること。
#       なお value_stream / adv_stream ブランチは写像されないまま実行され続ける(死に計算。
#       Linear(512→512)×2 ぶんで、conv スタックに対しては誤差)。
