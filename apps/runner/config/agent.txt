# ==============================================================================
# 【 Action Policy 設定ガイドライン 】
# エージェントの「行動選択」と「価値計算」の基準を設定。
#
# [1] train_policy (学習用のデータ収集・探索向け)
#     - 役割: 未知の領域を効率よく開拓するための「行動方策 (Behavior Policy)」。
#     - 推奨: UQE (不確実性による探索) または EpsilonGreedy。
#     - 備考: uqe_tau_start(楽観度) や eps_start(ランダム度) を高く設定し、学習進行で減衰させる。
#     - 備考: RunMode=TrainでのCreateActionContext/MakeAction呼出で適用される。
#
# [2] eval_policy (評価・本番推論向け)
#     - 役割: 学習の真の実力を測るための「評価方策 (Eval Policy)」。
#     - 推奨: Greedy (完全な平均Q値の最大化)。
#     - 備考: 無駄な探索ノイズを排除するため、Greedy固定が鉄則。
#     - 備考: RunMode=Eval/Eval1/Eval2でのCreateActionContext/MakeAction呼出で適用される。
#
# [3] target_policy と use_optimistic_target (TDターゲット計算・学習用) ★最重要
#     - 役割: 「もし次状態で最善を尽くしたら価値はいくらか」を計算する基準。学習でTD誤差を算出する為に使用。
#     - 戦略A (王道): use_optimistic_target = false の場合（デフォルト）：
#         -> target_policy はデフォルトで Greedy。
#         -> 客観的な期待値を厳格に学習。最も安定。
#     - 戦略B (Deep Exploration): use_optimistic_target = true の場合：
#         -> 長期戦略が必要な環境向け。
#         -> train_policy の設定(UQE等)を自動継承し、探索の期待感をQ値に練り込む。
#            UQEなら、過去の状態へ逆伝播させることで長期戦略を発見しやすくする効果が。
#         -> target_policy.uqe_tau_start 等を個別に記述することで、
#            「ベースはTrainと同じだが、Targetの楽観度だけ少し下げる」等の部分的な上書きが可能。
#             ※注意: 環境のランダムな上振れを過信して学習が崩壊するリスクがあるため、安定感とのトレードオフ
# ==============================================================================


# ■per_alpha
#  α（0≦α≦1）はExperienceサンプリングのランダム度合い。
#  α=0でランダムサンプリングと同一、α=1.0でGreedyに優先度を反映させる。
# ■per_beta
#  優先度に応じてサンプリングを行うと同じExperienceを何度も学習して学習安定性を損なう恐れがあるため、
#  TD誤差に対してサンプリング確率に応じた補正を行う。（サンプリング優先度が高いほどQ値への反映度合いを抑える）
#  学習初期はTD誤差が安定していないため、per_betaを小さくして上記補正を抑制する。
# 　per_beta=0　→ 補正無し、 per_beta=1.0 →完全補正
