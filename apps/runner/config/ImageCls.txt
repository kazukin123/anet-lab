# --- ImageCls augment 仕様 ---
# augment は train mode の画像取得時だけに適用するデータ拡張。
#
# ・eval mode では augment.enabled=true でも適用しない（評価画像は無加工）。
# ・ImageDataSource が読み込み・224x224 resize した [3,H,W] uint8 画像に対して処理する。
# ・変換順は RandomResizedCrop -> horizontal flip。
# ・乱数は env の seed 由来なので、同一 seed・同一実行系列なら再現可能。
#
# RandomResizedCrop は「画像のどの範囲を見るか」を毎回ランダムに変える処理。
# 元画像から、設定された crop 面積比（rrc_scale_*）と crop 矩形の幅/高さ比（rrc_ratio_*）の範囲内で
# ランダムな矩形を選び、その矩形を切り抜いて image_width/image_height へ resize する。
# つまり、元画像全体をそのまま縮小するのではなく、料理の見える位置・大きさ・周辺の切れ方を揺らす。
#
# RandomResizedCrop仕様:
# ・ rrc_scale_min/max は crop 面積比。元画像面積に対して [min,max] の範囲から乱数で選ぶ。
# ・ rrc_ratio_min/max は crop 矩形の幅/高さ比。比率は log 空間で乱数選択する。
# ・ 選んだ面積比と幅/高さ比から crop_w/crop_h を計算し、画像内に収まる矩形を最大10回試す。
# ・ 有効な矩形が取れたら top/left を乱数で選び、その部分を切り出す。
# ・ 10回失敗した場合は、ratio 範囲に収まる中央 crop に fallback する。
# ・ crop 後の画像は bilinear resize で image_width/image_height に戻す。
#
# horizontal flip仕様:
# ・ hflip_p は crop 後画像を左右反転する確率。0.0=無効、1.0=常に反転。
