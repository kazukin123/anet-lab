# Conv -> Conv -> Flatten -> (Vector Output)

net.body.ResNet.structure = Linear_128 > ReLU > Linear_128(=skip_val) > Linear_128 > ReLU > Linear_128(=proc_val) > Add(@skip_val @proc_val) > ReLU > Linear_512 > MyReLU



# --- CNN + Transformer ハイブリッド (ViT Style) サンプル ---

## 記法[net.body.structure]
# 記載      意味	              例
# BlockName ブロックの配置        Conv1
#  >		ブロックの連結        Conv1 > ReLU > Conv2
# (=Tag)    出力に名前を付ける    Conv1(=skip)
# (@Source) 入力元をtagで指定する Add(@skip @main)
# (*N)      同じブロックを繰り返し配置する      ResBlock(*3)


## MEMO:表現出来ないパターン
# ・重み共有
#    「同じ構造のブロックを2回使う」のではなく、「全く同一の実体（メモリ上の重み）を2回使い回す」 ケース
# ・密なスキップ結合：
#  　U-Netでは「Encoderの1層目の出力を、Decoderの最後の層に入力」「Encoderの2層目を、Decoderの最後から2番目に...」という風に、遠く離れた層同士が多数結合する。
#　  今の記法での表現: 可能だが、タグだらけになる。
# ・条件分岐
#    「入力データの平均値が0.5以上ならBlockAを、そうでなければBlockBを通す」といった、データ依存の動的な分岐。
#     必要になったらConditionalBlockをC++側で実装して対応。
# ・再帰構造
#    RNNやLSTMのように、同じブロックを時間軸に沿って繰り返し適用する構造。
#    必要になったらLSTM層やRNN層をC++側で実装して対応。
