# PRD 品質確認観点

PRD を書く前の参照、レビュー、起草した側の自己点検で走査する観点。

## 位置づけ

| 項目 | 内容 |
| --- | --- |
| 対象の成果物 | [レジストリ](../process/registry.md) の成果物キー `prd` |
| 参照するエージェント | レビューエージェント。依頼で、観点ファイルのパスとして渡される。書く側は、起草の前に読む。PRD を起草・改訂する側も、レビューに出す前の自己点検で読む |
| 対象外 | 設計の妥当性。別枠の再グリルと、人間のレビューが見る。今回起票も改訂もしない既存の PRD も、対象外である |

- 各項目は、PRD が規約を満たすかを問う。
- 作業の種類でだけ要る細則は、本書の節の「規約」が正本である。そのほかの項目は、規約の所在を指す。
- 節の規約を直したら、同じ節の項目も見直す。
- 項番は本書の中で一意である。指摘は項番で引用する。項目を消しても、番号は詰めない。
- 項番 10・11・12・27 は廃止した番号であり、再び使わない。
- 判定の範囲と応答の形は、[プロセス契約](../process/protocol.md) の 2 節と 3.1 節による。
- 節の適用範囲に当たらない項目は、対象外として扱う。

## 機械検査

### 検索による検査

検索対象の「レビュー対象」は、依頼で渡された PRD のファイルである。

| 項番 | 確認観点 | 検索対象 | パターン | 期待値 | 規約の所在 |

| 1 | 状態行の不在 | レビュー対象 | `^\s*>?\s*\**状態\s*\**\s*[:：]` と `^\s*>?\s*\**Status\s*\**\s*[:：]` | どちらも 0 件 | [docs/memo/README.md](../memo/README.md) 冒頭（状態はフォルダで表す） |
| 2 | ファイル名の形 | レビュー対象のファイル名 | `^\d{3}_.+_10prd\.md$` | 一致する | [docs/memo/README.md](../memo/README.md) 冒頭、§採番 |
| 3 | 正式採番の一意性 | `docs/memo/**/{NNN}_*_10prd.md`（`{NNN}` はレビュー対象の番号） | ファイル名 | 番号が `0` で始まるとき、1 件（レビュー対象だけ）。`9` で始まる番号は対象外 | [docs/memo/README.md](../memo/README.md) §採番 |
| 4 | リンク切れの不在 | レビュー対象 | `\]\([^)#][^)]*\)` のうち、`http` で始まらないもの。コードの中に書かれた記法は除く | `#` より前のパスを、レビュー対象のあるディレクトリから辿った先が、すべて実在する | [docs/memo/README.md](../memo/README.md) §リンクの注意 |

### 設計の形

**規約**

PRD の確定事項と実装契約に、内部の型・入れ物の型・引数の型・添字の決め方などの実装の語を書かない。公開 API の名前、設定キー、メトリクス名、クラス一覧の名前と置き場（機能グループ）は書いてよい。

適用: 項番 30 は、汎用層（共通の型、target、設定の文法、検証）に契約を定める PRD。項番 31 はクラス一覧を持つ PRD。項番 32 は常時。項番 33 は性能の受入を持ち、ホットパスの順番や回数を変える PRD。

| 項番 | 確認観点 | 確認内容 | 規約の所在 |
| --- | --- | --- | --- |
| 30 | 汎用層の契約 | PRD が汎用層（共通の型、target、設定の文法、検証）に定める契約が、特定の Agent・Env・アルゴリズムの名前（鍵、欄、モード）に依存していない | [AGENTS.md](../../AGENTS.md) §汎用機構と利用側の責任境界 |
| 31 | クラス一覧の置き場 | クラス一覧に、置き場（機能グループ）の列がある | [anet-create-prd](../../.agents/skills/anet-create-prd/SKILL.md)（クラス一覧） |
| 32 | 契約と実装の語 | 確定事項と実装契約に、内部の型・入れ物の型・引数の型・添字の決め方などの実装の語がない。公開 API の名前、設定キー、メトリクス名、クラス一覧の名前と置き場は除く | 本節の規約 |
| 33 | ホットパスの見積もり | 性能の受入を持ち、ホットパスの順番や回数を変える決定に、頻度×単価を step 単位で見積もった記述がある | [anet-create-prd](../../.agents/skills/anet-create-prd/SKILL.md)（論点の仕分け） |
