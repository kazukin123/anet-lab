# 記録の発番

課題記録の ID を出す手順である。anet の作業記録は PRD と実装計画が兼ねるので、接頭辞 worklog は使わない。

## 発番のしかた

**次のコマンドを実行し、出力をそのまま ID にする。** 日付も乱数も推測で書かない。言語モデルが出す乱数は偏るため、AI に値を作らせない。コマンドを自分で組み立て直さない。

```
node docs/process/scripts/newid.js <接頭辞> [件数]
```

| 引数 | 値 |
| --- | --- |
| 接頭辞 | `issue`（課題記録）／ `worklog`（作業記録）。**ハイフンは含めない** |
| 件数 | 省略すると 1 件。**1 〜 100**。複数起票するときはまとめて出す |

**出力は拡張子を含まない ID である。** 形は `<接頭辞>-YYYYnnDD-xxxxxx` で、`nn` は月、`xxxxxx` は 6 桁の 16 進の乱数である（時刻は含めない）。ファイル名にするときは `.md` を付ける。

```
出力     issue-20260907-39e29e
ファイル issue-20260907-39e29e.md
```

## Node.js が見つからないとき

コマンドが「`node` が見つからない」旨のエラー（`command not found`、`is not recognized` など）で失敗したら、**ID を推測で作らずに止まり**、開発者へ次をそのまま示す（`docs/process/protocol.md` 5 節の停止条件 6）。

> 記録に付ける番号を作るのに Node.js が必要ですが、この環境では見つかりませんでした。Node.js（https://nodejs.org/ の LTS 版）を入れたら、この AI を使っているエディターを閉じて開き直し（ターミナルで使っているときは、そのターミナルを開き直し）、もう一度依頼してください。入れたコマンドを読み込ませるためです。
