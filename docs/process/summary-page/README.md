# 会話のまとめページ

会話の案や判断、進捗、残っている作業を、スマホからも見返せるようにする。作成・更新・引き継ぎの手順は [anet-summary-page](../../../.agents/skills/anet-summary-page/SKILL.md) にある。

## 場面の一覧

| 場面 | 始める時機 | 指針 | ページの名前の印 |
|---|---|---|---|
| グリル | `anet-create-rfd` でグリルを始めるとき、goal anchor の応答を出す前。質疑のない暫定の起票には、この応答がない | [grill.md](grill.md) | `grill-` |
| 実験 | 流す Run を決めて bat に新しい段を足したとき、2 本以上の Run を比べ始めたとき、または Run の分析から次の対策や Run の案を出したとき。既存の段を直すことは、新しい段を足す条件に当たらない | [exp.md](exp.md) | `exp-` |
| 一般 | 固有の始める時機はない。頼まれてほかの場面に当たらないときか、前の応答で振った記号をあとの往復で引く条件に当たったときに使う | [general.md](general.md) | なし |

## 共通の型

1. **冒頭**に題、最終更新の時刻、目次を置く。「見返し用の写しです。正本は会話と RFD・実験記録・課題にあります。」の 1 行を添える。前のページから続けた別の枠では、前のページへのリンクも置く。
2. **進行状況**は、WAITING（あなたの返事待ち）、DOING（進行中）、TODO（次にすること）、DONE（直前に済んだこと）を同じ形で並べる。TODO は次にすることを先頭に置き、残っている作業をすべて続ける。
3. **案と論点の一覧**には、振った案・選択肢・論点ごとに記号と短い名前、要点、状態を置く。状態は「未試行」「試行中」「結果あり」「決まった」「退けた」を使う。

## ページの単位と見た目

会話の枠ごとに 1 枚。同じ面で同じ仕事を続ける間は、チャット枠を移っても同じページを使う。枠の中で別の場面に入ったら、その場面の節を既存のページに足す。主題が並ぶ場合は主題ごとの塊に分ける。済んだ塊には「終わった」と書き、既定で畳む。

[ひな形](template.html) を写して共通の 3 節と場面の節を埋める。目次には追加した節へのリンクも置く。文言は平易にし、作業手順の内部用語は使わない。日本語の指定、端末の日本語フォント、明暗に応じた配色、スマホの幅での読みやすさ、常に見える先頭へ戻るリンクは、ひな形の設定を使う。塊は `<details>` と `<summary>` で囲み、進行中の塊は `open` を付けて表示し、済んだ塊は `open` を外して畳む。
