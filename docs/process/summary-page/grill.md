# グリルの場面

グリルでページを作るときは、題を「RFD<4 桁の番号> <主題>」にする（例: `RFD0197 会話のまとめページ`）。新しい RFD で番号をまだ取っていなければ主題だけで作り、番号を取った応答で `<title>` と `<h1>` の題の先頭に番号を足す。ほかの場面で作ったページにグリルの節を足すときは、ページの題は枠の主な主題のまま変えない。グリルの節は 1 つの塊にまとめ、その塊の見出し（`<summary>`）を同じ形にする。番号をあとで取るときは、その見出しの先頭に足す。

[共通の 3 節](README.md#共通の型)に次の節を足す。

- **ゴールと非ゴール**。この RFD で何をできるようにするかと、何を扱わないか。
- **前提**。判断に使う事実と、まだ欠けている前提。欠けていた前提が全部そろったら、その塊を畳む。
- **未決事項**。未決表の行ごとに名前と要点、いまの状態。
- **決まったこと**。選ばれた内容と理由。推奨と違う選択なら、その旨も書く。
- **聞かずに決まったこと**。現行の仕様や、それまでに合意した内容から決まった事項。
- **進み具合**。グリルの手順のどこまで来たか。
- **用語**。判断に関わる語と、その会話での意味。
