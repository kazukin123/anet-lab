## 現時点のまとめ

1. 勾配ノイズの臨界バッチ（Adam 前処理版）は学習とともに増え続けた。B256/RR1 で 0–10M の 232 から 170–230M の約 3,900 まで、B で割った比は 0.9 から 15.2 になった。0〜50M は分散が 4 倍に増え、50M 以降は分散が横ばいのまま信号が 1/3 に細った。分散の約 95% は feature 側にある。
2. 停滞区間（170→230M）の対照（42A）は、学習側の平均点が 60M で +2.7%（20M あたり約 0.9%）だった。同じ系列の 300M の延長 Run の同じ区間と 10M 窓で ±0.3% 以内で一致した。評価専用 Run の平均点は同じ 60M で +4.2%（1,950→2,032）伸びており、評価で見る限り成長は止まっていない。
3. B を上げた腕は、学習側の平均点を水準で押し上げた（B512/RR2 +0.5〜1.2%、B1024/RR2 +2.3〜3.0%、B1024/RR1 +3.1〜3.9%）。学習中の評価（target ネット）でも、B1024 の 2 本は分岐後 20M までに対照より約 3% 高くなり、その後は横ばいだった。対照は 60M かけて同じ水準に着いた。B を上げると、評価でも同じ水準に早く着く。
4. 最終 checkpoint の評価専用 Run（target ネットの Eval1・Eval3、各腕約 10,000 局）では、対照の複製 2 本が 2,031.9 / 2,031.8 で一致した。B1024/RR1 は +0.9%（約 2.4σ）、B512/RR2・B1024/RR2 は +0.2〜0.3%、B256/RR2 は −0.8%（約 2σ）だった。online ネットの Eval2 は、同じ設定の複製でも 2.2% ずれた。
5. 学習側の上乗せの大部分は、NoisyNet の揺らぎに対する感度の差で説明できた。NoisyNet ありで評価すると学習側と同じ順と差（B1024/RR2 が +2.3%）が出た。B を上げた腕は、同じ σ でも Q の動きが 7% 小さく、行動が変わる割合が 10.5% から 8.3〜8.4% に下がった。online と target の行動の食い違いも 9.8% から 5.2〜6.3% に下がった。
6. 評価のダブルスイカ率（target ネット）は、対照 1.35% / 1.54% に対し B512/RR2 1.92%、B1024/RR2 1.91%、B1024/RR1 1.48%、B256/RR2 1.41% だった。同じ checkpoint でも局の組で、同じ設定でも Run で 0.2〜0.3 ポイント動く。同じ経験を 2 回ずつ使う RR2 の 3 本は DS の無い局の平均が対照より 0.4〜0.8% 低く、B1024/RR1 は +1.0% だった。一度も学習に使われずに消える経験を 29% から 5.6% に減らしても（B256/RR2）、ダブルスイカ率は増えなかった。
7. 評価方策の UQE τ を下げると対照の評価が +1.8% 上がる、という 1 組目の結果は、別の局の組で再現しなかった。τ の効果は 4 checkpoint 中 1 つで約 2σ、他は差なしだった。
8. 7 月の長期 lineage（NoisyNet なし、B512/RR2）も、学習中の評価は 300M の間ほぼ横ばいだった。B を上げても評価の停滞が破れないことは NoisyNet に固有ではない。
9. このマシン（32GB GPU）で使える B の上限は 1024。B2048 は GPU メモリが溢れて 1/4 の速度になり、B4096 は最初の更新で止まった。
10. 学習中の評価（1 セッション 1 局、10M あたり 390 局）は、平均点で 2% 以上の差なら読める。Eval1・Eval3 を 1 セッション 8 局にすると 20M 窓の誤差が約 ±0.3% になり、最後の 10M は最終の評価専用 Run と 1% 以内で合った。実時間は約 9% 増えた。ダブルスイカ率は、評価専用 Run（各ランナー 5,000 局以上、複数の局の組）が要る。
11. 1 回の更新のノイズを下げた直後は勾配の信号が勝つ（前処理なしの版で B1024/RR1 の ÷B が 0.48）。速く進むぶん信号が細り（0.017 → 0.008）、40〜60M にはノイズの比が対照と同じ水準（÷B 1.1〜1.3）に戻った。評価の伸びが横ばいになった時期と合う。
12. B と RR の組み合わせを 3 つの性質に分けると、1 回の更新のノイズ（B）は成績・NoisyNet の感度・Q の水準（B1024 で −4%）・feature の大きさの維持に、経験あたりの更新回数は feature 側の重みの増え方（2 倍で +7.7%、1/4 で +0.1%）に、1 つの経験が使われる回数は取りこぼしと DS の無い局に沿って動いた。

## この文書の読み方

- 経験数は各 Run の自分の経験数（分岐からの経験数）で書き、通算の位置を括弧で添える。
- 「学習側の平均点」は学習中の env（NoisyNet あり）の局の平均、「学習中の評価」は学習 Run の中の評価セッション、「評価専用 Run」は checkpoint を読んで学習せずに評価だけを回した Run を指す。
- 勾配ノイズの指標は学習ステップの軸で記録されるので、腕どうしは経験数でそろえた区間の生の値（信号・分散）の平均の比で比べた（PRD092 §7.4）。
- 評価ランナーは 3 つ。Eval1 は target ネットの UQE（τ0.85）、Eval2 は online ネットの UQE、Eval3 は target ネットの Greedy。評価では NoisyNet の揺らぎを使わない（`mu_only`）。
- 探索ブロック 05〜08 の評価専用 Run の平均点とダブルスイカ率は 3 ランナーの合算、探索ブロック 10 以降は target ネットの Eval1・Eval3 の合算で書く。Eval2 は checkpoint の瞬間の online ネットの揺れが乗る（探索ブロック 11）。

## 探索ブロック 01: 勾配ノイズの推移（B256/RR1 の系列）

**記録時点:** 2026-10-16〜2026-10-18
**状態:** completed
**確度:** 2 系列（seed 1・seed 2）、各 1 Run。測定は 503 学習ステップごと

### 探索観点

学習が進むと停滞するという現象と、勾配ノイズの相対的な増加が同時に起きているかを確かめる。

### 探索条件・対象 Run

| Run | 内容 |
|---|---|
| `run_20261015-204705_dmfb_40_s2` | seed 2、0→50M |
| `run_20261016-005647_dmfb_41a_40_b256` | 40 の 50M から B256/RR1 のまま +100M（通算 50→150M） |
| `run_20261017-185400_dmfb_42a_34a_ctl` | seed 1 の系列の 170M から B256/RR1 のまま +60M（通算 170→230M） |

### 探索結果

| 区間（通算） | 臨界バッチ（Adam） | ÷B | 信号（Adam） | 分散（Adam） |
|---|---:|---:|---:|---:|
| 0–10M | 232 | 0.9 | 144,748 | 34M |
| 10–20M | 530 | 2.1 | 129,007 | 68M |
| 40–50M | 958 | 3.7 | 147,569 | 141M |
| 50–70M | 1,633 | 6.4 | 96,208 | 157M |
| 70–110M | 約 2,500 | 9.7 | 約 55,500 | 約 138M |
| 110–150M | 約 3,000 | 11.9 | 約 41,900 | 約 127M |
| 170–230M（seed 1） | 約 3,890 | 15.2 | 約 34,200 | 約 133M |

- 1 回の更新がノイズ優勢（÷B > 1）になるのは 10M 前後から。
- 0〜50M は分散が 4 倍に増え、信号はほぼ横ばい。50M 以降は分散が 130〜160M で横ばいのまま、信号が 1/3 に細った。
- feature 側の臨界バッチは readout 側の 10〜15 倍（170–230M で feature の ÷B 約 24、readout の ÷B 約 1.9）。分散の約 95% が feature 側、信号の約 60% が feature 側。0–10M では両者の差は 2 倍だった。
- 前処理なしの版（SGD 版）は Adam 版の約 1/10（170–230M で ÷B 約 1.25）。
- `05_ratio_adam` の 1M ごとの揺れを他の約 30 指標と比べた（42A の 60 区間、41a の 100 区間、9 区間の移動平均を引いた揺れの相関）。揺れと一緒に動いたのは勾配ノイズの内側だけだった（feature の臨界バッチ +0.94 / +0.96、SGD 版 +0.85 / +0.90、分散 +0.70 / +0.55、信号 −0.48 / −0.50）。学習側の平均点・TD・loss・Q・churn・可塑性・attention・PER・ダブルスイカ率とは、2 本とも |r| < 0.35 で、2 本で同じ向きに再現する相関はなかった。

### 考察

停滞区間では、改善の方向を示す勾配（信号）が細り、一定のノイズに埋もれていく。①（停滞）と ②（ノイズの相対的増加）は同時に進んでいる。ノイズの大部分は feature 側にある。

`05_ratio_adam` の一時的な跳ねは、推定のぶれ（信号は大きい数の差）と feature 側の分散の一時的な増加で、他の指標や成績には表れていない。読むのは 10M 程度の平均の傾きである。

### 考察

- **① に沿って動いたもの**（42D < 42H ≈ 42J の順、42I は対照並み）: NoisyNet で行動が変わる割合、online と target の食い違い、1 回の更新で行動が変わる割合、Q の水準（B1024 で −4%）、Munchausen のボーナスの小ささと次状態のエントロピー、feature の大きさの維持、勾配ノルム。replay の行動を今の方策が選びやすくなった（ボーナスが小さい）のは、学習中の Actor が揺らぎで外れにくくなったことと合う。
- **② に沿って動いたもの:** feature 側の重みの増え方。更新回数 2 / 1 / 1/2 / 1/4 の順に、+7.7% / +2.7〜3.1% / +0.9% / +0.1% だった。
- **③ に沿って動いたもの:** 取りこぼし、dormant 率（0.3% 前後で絶対値は小さい）、評価の DS の無い局（探索ブロック 10）。
- **ほとんど動かなかったもの:** σ、Munchausen の打ち切り、attention（1% 以内）、有効ランク（±3%）。loss は対照以外の 4 本で 8〜10% 低いが、成績の順とは対応しない。

勾配ノイズは、1 回のノイズを下げた直後は信号が勝った（B1024/RR1 で ÷B 0.48）。速く進むぶん信号が細り（0.017 → 0.008）、40–60M には ÷B が対照の 2 本（1.14〜1.30）と同じ水準に戻った。評価の伸びが横ばいになった時期（探索ブロック 12）と合う。更新回数を増やした 42I も信号が細り、÷B は対照より高くなった。

対照 2 本の差は、学習中の指標で 0.1〜8%、勾配ノイズの推定で 20M 窓 1〜6 割だった。勾配ノイズの腕どうしの差は、B1024 の 3 倍のように大きいものだけを読む。
