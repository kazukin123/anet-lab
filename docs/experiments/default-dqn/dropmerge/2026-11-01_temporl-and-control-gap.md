## 現時点のまとめ

1. **TempoRL（分離×合算、J=10）は Greedy の評価で無効の対照を下回った。** 50・55・60M の 3 回平均は full 1,033、single 1,145 で、同じ seed の対照 47b の 1,233、1,242 より 16%、8% 低い。maxrank の平均も full 9.75、single 9.85 に対して 10.05、10.06 だった。合算は 1 本で、61M で閉じた。
2. **差は序盤ほど大きく、進むにつれて縮んだ。** full の 47b との差は 10〜20M で −30%、35〜45M で −25%、50〜60M で −16%。single は −23%、−13%、−8%。
3. **Train Actor は 20〜28% の step でしか判断しなかったが、Greedy の full はほぼ毎 step 判断した。** Train の平均スキップ長は 3.7〜5.2。Greedy は 10M 以降、判断の率 76〜92%、長さ 1.11〜1.34 だった。
4. **スキップ長にも UQE を掛ける評価は、合算で Greedy より大きく低かった。** 評価専用 Run で Eval1 721 に対し `53_evalg` 1,099。対照はどちらもほぼ同じ（47c で 1,292 と 1,295）。
5. **補助学習のみ（47f）は、10.8M で止めるまでに対照を上回っていた。** 6M までは対照と同じ帯で、8〜10M の Eval3 は 963（対照 703、744）、10M の Greedy は 1,069（対照 733、768）。1 本で、判断の予算に届いていない。
6. **新ビルドの対照 2 本は、旧ビルド 3 本より低かった。** Eval3 の 40〜50M は 1,158、1,254 に対して 1,422、1,450、1,476。20〜30M までは重なり、30M 以降に分かれた。10/15 の exe を 11/02 に走らせた 47d も旧の帯に入った。5 本のうち新の 2 本が下位 2 本である。
7. **Q の再上昇の時期が違った。** 旧の 3 本は 30〜50M で 8.3〜9.0 に上がり、新の 2 本は 40〜50M で 6.3〜6.5 だった。47b は 70〜80M で 8.1 に届き、そのとき TD の平均・loss・replay の指標も旧の 30〜50M の値の範囲に入った。100M の評価専用 Run の差は nzrep に対して −8〜−10% だった。
8. **決定的モードでは、10/15 の exe と 11/01 の exe の学習系列は 30M まで一致した。** UQE の ε を揃えて、7 指標（loss は 117,086 点）の全点が値まで同じだった。
9. **原因は特定できていない。** 設定で学習に効く差は UQE の ε（旧は全 lane 1e-4、新は 0）だけである。本番モードで ε を 1e-4 にした Run は測っていない。
10. **特徴ノルム・勾配ノルム・序盤のエントロピーの水準は、ビルドではなく seed で揃った。** seed 1 の 47d と 47b、seed 2 の 40_s2 と 47c がそれぞれ同じ帯で、新旧の成績の差とは対応しなかった。

## この文書の読み方

- 評価は 5 種類ある。Eval1 は target ネットの UQE（τ0.85）、Eval2 は online ネットの UQE、Eval3 は target ネットの Greedy。学習中の評価は Eval1・Eval3 が 1 セッション 8 局（nzrep と 40_s2 は 1 局）、Eval2 が 1 局である。`53_evalg`（`[greedy]`）と `54_evalgs`（`[greedy_single]`）は Greedy の 128 局を 5M ごとに行い、`53_evalg` は Actor のスキップ設定のまま（TempoRL の Run では full）、`54_evalgs` は毎 step 判断する（single）。
- TempoRL の無い対照では、`53_evalg` と `54_evalgs` は同じ方策の別のセッションである。この 2 つの差は 47b で平均 29（最大 120）、47c で平均 17（最大 55）だった。
- 値はセッションごとの報酬の合計の平均で、終局の罰（−10、NoDropTimeout は −20）を含む。ログに出るゲームの点とは違う。
- 判定は評価の値で行い、学習側の平均点は使わない。内部の指標は学習の進みを見るためだけに使う。
- 経験数は exp step。学習ステップの軸の指標は ×256 で経験数にそろえた。

## 探索ブロック 05: 決定的モードでの新旧の比較

**記録時点:** 2026-11-04（Run は 2026-11-01〜11-02）
**状態:** completed
**確度:** 同じ exe の 2 回走らせが一致することを確かめた上での、1 組の比較

### 探索観点

新旧の差がコードの差から来るなら、決定的モードで学習系列が分かれるはずである。分かれた step と指標から原因を絞る。

### 探索条件・対象 Run

共通: backend を決定的（`cudnn_benchmark=false`、`cudnn_deterministic=true`、`deterministic_algorithms=true`、`deterministic_warn_only=false`）、seed 1。旧 exe（10/15 20:23）は 40_s2 の実効設定を、新 exe（11/01 01:31）は 47b の実効設定から新しい指標を除き UQE の ε を全 lane 1e-4 にしたものを読む。

| 比較 | 経験数 | 評価セッション | 比べた指標 | 違った指標 |
|---|---:|---|---:|---:|
| 新 exe の 2 回走らせ | 1M | なし | 139 | 0 |
| 旧 exe と新 exe | 1M | なし | 137 | 0 |
| 新 exe の、評価なしと評価あり（`[greedy]` 系は 47b の 10 倍の頻度）| 1M | なし／あり | 139 | 0 |
| 新 exe の、評価なしと attention の指標あり | 1M | なし | 139 | 0 |
| 新 exe の評価ありの 2 回走らせ | 1M | あり | 213 | 72（すべて評価の指標） |
| `run_20261102-091611_rg_e0L`（旧）と `run_20261102-114539_rg_e7L`（新） | 30M | なし | 7 | 0 |

30M の組で比べた 7 指標は、loss、Q 側の勾配ノルム、Q の最大（実空間）、学習側の報酬、バッチの優先度の平均、次状態のエントロピー、PER の β。loss は 117,086 点で、全点が同じ値だった。

### 探索結果

| 指標 | 窓 | rg_e0L | rg_e7L |
|---|---|---:|---:|
| Q の最大（実空間） | 0–10M | 3.1277 | 3.1277 |
|  | 10–20M | 4.8446 | 4.8446 |
|  | 20–30M | 5.9675 | 5.9675 |
| loss | 20–30M | 0.0163 | 0.0163 |
| Q 側の勾配ノルム | 20–30M | 0.4454 | 0.4454 |

- Train 側で時間で変わる設定のうち、この設定で実際に効くのは PER の β（0.4 から 0.6 を 20M で）だけである。ε と UQE の τ は lane ごとの固定値を使うので、時間の減衰は効かない。β が止まる 20M を越えても差は出なかった。
- 1 本 30M に 2.49 時間かかった（評価オフ）。

### 考察

UQE の ε を揃えれば、30M までの学習の計算は新旧で同じだった。旧の Run で Q が再び上がり始める 30〜35M の手前までの比較である。本番モードだけで通る経路（cudnn benchmark など）の差と、UQE の ε が 0 か 1e-4 かの差、Run ごとのぶれは、この比較では分けられない。
