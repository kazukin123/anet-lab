## 現時点のまとめ

1. **3 腕とも基準以上で、基準を上回る腕は無い。** AUC は合算 135.2／112.5／125.2（平均 124.3）、分割 147.8／133.3／98.1（126.4）、`kmax` 140.5／134.8／134.1（136.5）、ε-greedy 149.8／104.0／84.0（112.6）。「上回る」に最も近いのは `kmax` で、最小 134.1 対 基準の最大 135.2。ε-greedy の「以上」は平均 112.6 対 基準の最小 112.5 で紙一重。PRD103 §9 の 1 の規則では LunarLander の既定（合算・`uniform`・スキップ長は行動と同じ規則）は据え置き（探索ブロック 01）。
2. **`kmax` は長い j を増やさなかった。** `[greedy]` session の j=1 の割合（1.5M〜）は `kmax` 0.53〜0.66、合算 0.48〜0.53 で、判断率も `kmax` 0.56〜0.64 対 合算 0.53〜0.56 と判断が増える向き。学習側の判断率・長さ別の割合はどの腕も合算と同じ（判断率 0.46〜0.49、j=1 が 37〜46%）（探索ブロック 01）。
3. **`[greedy]`（行動もスキップ長も greedy）の報酬は `[eval]`（行動は UQE τ 0.25）より低い Run がある。** 1.5M〜の平均は、合算 s1 で 130 対 206、分割 s3 で 161 対 185。ほかの Run は 200〜229 で `[eval]` と同じ帯。`[greedy]` は 62 点（初回は学習前の捨て点）で `[eval]` の 312 点より粗い（探索ブロック 01）。
4. **分割で primary に入る skip の loss の勾配は、skip Network の勾配より大きく、クリップにはほぼ掛からない。** `17_skip_primary_grad_norm` の Run 平均は 0.31〜0.36、`15_grad_norm`（skip Network）は 0.19〜0.25、`18_skip_primary_clip_ratio` は 0〜0.15%（探索ブロック 01）。
5. **基準の 3 本は 10/26 の同 seed の Run と最初から違う。** 10/26 の合算は AUC 131.4／143.2／137.6、今回は 135.2／112.5／125.2。`[eval]` の最初の点（8448 step、学習前）は一致し、2 点目（14848 step）から違う。学習側の報酬の EMA も 37 エピソード目から違う。設定の差は `[greedy]` session（actor と tag）と、既定値のままの新しいキー `sample_weight = uniform`、表示だけの Evaluation Trace の列番号。`[greedy]` の初回のエピソードが 8448 と 14848 の間に入るので、`[greedy]` session を足したことで同じ seed の乱数の系列が変わったとみる（経路は未確認）。このため 10/26 以前の Run とは比べず、同じビルド・同じ設定の腕どうしで比べる（探索ブロック 02）。
6. **3 seed のブレ幅は分散を小さく見積もる。** 基準の設定の 6 回分（10/26 の 3 本と今回の 3 本）の AUC は 112.5〜143.2 に散り、`kmax` の 134.1〜140.5 はその中にある（探索ブロック 02）。

- seed 1 の照合: `[eval]` の policy 報酬の最初の点（8448 step）は両方 −850.618 で一致し、2 点目（14848 step）は −17.4 対 −52.5 で違う。学習側の報酬の EMA（`20_eps/11_train_reward_ema`）は最初の 8 点が一致し、9 点目（37 エピソード目）から違う。skip の loss（`50_agent_skip/11_loss`）は最初の learn step から違う（4.215 対 4.127。学習は 76,800 step から）。

- GridMaze 6×10 では、10/28 の朝のビルド（`[greedy]` session を足す前）の UQE 3 本が 10/26 の 3 本と完全に一致した（[2026-10-28_temporl-skip-policy-6x10](../gridmaze/2026-10-28_temporl-skip-policy-6x10.md)）ので、違いは PRD103 の実装のあとに入った設定（`[greedy]` session）による。
