# TempoRLのTrainの繰り返しの時期と長さの比較

## 条件と判定方法

| 項目 | 内容 |
|---|---|
| 目的 | 通常TempoRL（合算）の得が、Trainが同じ行動を繰り返すことのどの部分から来るかを分ける。warmupの間だけ繰り返す、50万exp stepまで繰り返す、スキップ長を無作為に選ぶ、の3つを基準と比べる |
| 対象 | LunarLander、DefaultDQNAgent、IQN＋Munchausen、TempoRL分離×合算（`learner.skip.feature_gradient=merge`）、J=4、256 env、batch256、replay ratio8、replay容量512,000、n_step 5、`update_warmup_steps=8,192`（最初の学習は8,448 exp step）、3 seed、各2M experience |
| 実行 | 2026-11-05 00:53〜08:56 JST。12本を順次実行した。最後の評価点は全本1,998,848、stderrは全本空、logにWARN・ERRORなし |
| 固定条件 | 同じRelease実行体（2026-11-03 22:02）。SHA256は`0408933b25dd502867e1ec2fda00a35c440bbfa2d0f41923c0a9f94bece92d96` |
| 比較上の注意 | DropMergeの学習RunとRTX 5090を共有して実行したので、実時間は群の効果に使わない。LunarLanderの結果を他の環境へ一般化しない |
| 主指標 | `[eval_single]`の`21_eval/33_eval_s_reward`（UQE τ0.25、固定32τ、ε=0、毎step判断、1 episode、200 learn stepごと、312点）。スキップ長の学習の有無によらず、同じ選び方で重みを比べられる |
| 副指標 | full `21_eval/02_policy_reward`、Greedy single `21_eval/31_greedy_s_reward`、Greedy full `21_eval/09_greedy_reward`（Greedyは1 episode、1009 learn stepごと、62点）。局の長さは`21_eval/34_eval_s_steps`、`21_eval/06_policy_ep_steps`、`21_eval/32_greedy_s_steps` |
| EMA50の定着 | 評価点のEMA（係数0.1。`21_eval/04_policy_reward_ema`と同じ計算）が50を下回らなくなった最初のexp step |
| 比較規則 | 差と呼ぶのは3 seedの範囲が離れたときだけ。「同じ帯」は範囲が重なること。統計的有意差の検定ではない |

|---|---|---|---|

評価のActorは全群で同じで、full（`[eval]`・`[greedy]`）とsingle（`[eval_single]`・`[greedy_single]`）を同じ重みで走らせた。補助のlossは全群で動いている。warmupの間に専用の無作為方策は無く、学習前のネットワークのままTrainの方策で動く。8,192 exp stepはlane 1本あたり32 stepで、replay容量の1.6%にあたる。

## 現時点のまとめ

1. **warmupの間だけ繰り返す群は、基準の立ち上がりを再現しなかった。** singleの0.25〜0.5Mの報酬は78.1／−37.2／15.6（平均18.9）で、基準の112.6／147.4／89.9（平均116.6）と範囲が離れた。同じ窓の局の長さは673対155で、ホバリングが残った。Run全体の平均は79.8対129.9で、範囲が重なるのはs1だけである。1.5〜2Mは182.5対211.0で、範囲は重なる。
2. **50万exp stepで繰り返しを止めても、その後は基準と同じ帯だった。** singleのRun全体は121.0対129.9、1.5〜2Mは195.2対211.0、fullの1.5〜2Mは207.7対213.2。Greedyの1.5〜2Mは逆向きで、singleが211.1対200.7、fullが209.7対200.5。どの比較も範囲が重なる。
3. **スキップ長を無作為に選んでも、基準と同じ帯だった。** singleのRun全体は127.6対129.9、1.5〜2Mは199.1対211.0、fullの1.5〜2Mは217.0対213.2、Greedyの1.5〜2Mはsingleが203.1対200.7、fullが208.8対200.5。基準の序盤のスキップ長もほぼ一様で、0〜0.5Mの長さ1の割合は0.20〜0.27、長さ4は0.22〜0.31、平均の長さは2.41〜2.69だった。
4. **これまでの比較と合わせると、LunarLanderの得は序盤のTrainの繰り返しで説明できる。** 学習した長さ（3）、0.5Mより後の繰り返し（2）、補助の勾配（[PRD098](../../../memo/098_temporl_skip_policy_10prd.md) §7の遮断は1.5M〜が209 [176〜231]で、合算の209 [189〜228]と同じ帯）、評価時の繰り返し（[同じ重みの評価](2026-10-29_temporl-auxiliary-only-stage1.md)）は、それぞれ無くても基準と同じ帯だった。ただし、これらを同時に外した組み合わせは測っていない。
5. **同じRunのfullとsingleは、立ち上がりでも同じ帯だった。** 基準のRun全体はsingle 136.2／145.6／107.8、full 131.4／144.0／125.2、0.25〜0.5Mはsingle 112.6／147.4／89.9、full 34.6／109.4／118.6で、範囲が重なる。2M終了時の重みだけを比べた[同じ重みの評価](2026-10-29_temporl-auxiliary-only-stage1.md)を、Runの途中まで広げても同じ読みになる。
6. **warmupだけの群と、繰り返しの無い過去の群との差は確定しない。** Run全体の範囲45.3〜115.9は、スキップなし−6.8〜68.4、k=1対照−32.78〜50.35、STOP対照18.20〜102.58と重なる。1.5〜2Mの範囲170.9〜198.9はスキップなしの151.4〜164.9より高いが、STOP対照の147.7〜186.1とは重なり、ビルドも違う。（2026-11-06追記: STOP対照は無効の別の標本と分かったので、この比較はどちらも繰り返しの無い無効との比較になる。[STOP×Singleと無効のbit比較](2026-11-05_temporl-stop-single-bit-compare.md)）

## 解釈の限界と残る問い

- どの群も3 seedである。warmupだけの群ではs1だけが早く抜け（0.25〜0.5Mの局の長さ219.4）、基準とのRun全体の範囲の重なりもs1による。
- 50万までの証拠は0.5Mより後だけである。fullの点はs1とs3が501,248 exp stepの直前まで基準と全点一致し、s2は14,848 exp stepから違う。singleの点はs1が130,048 exp stepから違うが、理由は確かめていない。同じ設定の区間なので、0.5Mまでの一致は同等の証拠にならない。
- 50万までは、繰り返した経験がreplayに約100万exp stepまで残る。kmax平均は0.5〜1Mで1.43〜1.46、1〜1.5Mで1.00である。50万で止めても学習の教材は約100万まで続く。
- warmupだけのfullは序盤にsingleより大きく低い（0.25〜0.5Mで−355.4対18.9）。kmax平均が1.03〜1.04でスキップの教材がほとんど無いまま、fullの評価は判断率0.50〜0.69で長さを選んでいる。fullの低さを重みの差として読まない。
- 50万までのfullは1.5〜2Mで判断率0.87〜0.93に上がり、局の長さは基準より長い（246.7対181.0）。singleの局の長さも243.8対200.3で長い。Greedy singleは251.1対269.3で逆向きである。
- 繰り返しが効く経路は分かっていない。訪れる状態が広がるのか、TDの学習がしやすくなるのかを分ける値（訪れた状態の分布など）は測っていない。
- 繰り返す期間をどこまで短くできるかは分からない。測ったのは8,192と500,000の2点だけである。
- 補助の勾配を止め、長さを無作為にし、繰り返しを序盤だけにする組み合わせは測っていない。これが基準と同じ帯なら、skip側を学習しなくても得が出ることになる。
- warmupだけの群の実時間が他の群より長い理由は確かめていない（下の表）。
