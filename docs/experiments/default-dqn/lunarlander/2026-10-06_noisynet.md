## 現時点のまとめ

1. **9 Run とも学習は壊れなかった。** すべて 2M exp step まで完走し、loss・Q・grad に非有限値は無かった。
   NoisyNet の 6 Run では、readout 群の σ 統計 4 つと probe の 3 指標が全区間で有限値を出した。
   σ を持たない feature 群の 4 統計と、OFF の Run の 11 キーは記録されなかった（NaN は metrics に書かれない）（探索ブロック 01）。

2. **成績の差は seed の幅の中だった。** 1.5M〜2.0M の policy reward 平均は OFF 145.1、上乗せ 134.0、置き換え 127.3。
   腕の中の seed の幅（最大と最小の差）は 102.8〜158.9 で、腕の平均の差（最大 17.8）より大きい。3 seed では差を判定できない（探索ブロック 01）。

3. **T180 到達は OFF 2/3、上乗せ 2/3、置き換え 1/3。** T50 の範囲は 3 腕で重なった（OFF 0.456〜1.032M、上乗せ 0.226〜1.058M、置き換え 0.232〜1.064M）（探索ブロック 01）。

4. **ε のランダム行動を外して NoisyNet だけにしても、ホバリングからの離脱は遅れなかった。**
   置き換えの T50 は 0.232 / 1.064 / 0.296M で、OFF（0.828 / 0.456 / 1.032M）と範囲が重なる（探索ブロック 01）。

5. **σ は学習とともに縮み、0 には張り付かなかった。** readout weight の平均 |σ| は初期値 0.0442（σ0/√128）から終盤 0.0165〜0.0209 に、
   ‖σ‖/‖μ‖ は 0.635〜0.640 から 0.149〜0.214 になった（探索ブロック 01）。

6. **ノイズが行動を変える度合いは、学習開始時に大きく、終盤には小さくなった。** 学習開始時（learn step 0）の probe では、ノイズだけを変えると
   greedy 行動の 71〜74% が μ-only と食い違い、行動のエントロピーは 1.33〜1.37 だった（4 行動の上限は ln 4 ≈ 1.386）。
   終盤は食い違い 2〜4%、エントロピー 0.05〜0.09 だった（探索ブロック 01）。

7. **学習開始時の大きな効きは、Head の初期化と整合する。** LunarLander は Head の V/A 射影を orthogonal・gain 0.01 で初期化するので、
   射影の ‖σ‖/‖μ‖ は σ0/gain = 50 になる。readout 群全体の初期値 0.635〜0.640 は、HeadFC128 2 層（xavier、0.5）と射影から計算した 0.637 と一致した（探索ブロック 01）。

## この文書の読み方

- 実効設定の正本は各 Run の `config/config_data.txt` で、複製を [config/](config/) に置いた。
- 数値は Run の Metrics マスタから `inspect_run.py` で取得した。
- policy reward は eval Actor（online ネット、NoisyNet は μ-only、UQE τ 0.25 固定）、target reward は eval_target Actor（target ネット、μ-only）の 1 エピソードの return である。
  どちらも train step 200 ごと（51,200 exp step ごと）に 1 回測る。1.5M〜2.0M の窓には各 Run 78 点が入る。
- `T50` / `T150` / `T180` の定義は [2026-08-08](2026-08-08_iqn.md) と同じで、`21_eval/04_policy_reward_ema` が閾値以上を 3 回連続で満たした最初の exp step である。間引かない系列（各 Run 312 点）で求めた。
- 「T180 到達」は 2M までに `T180` が付いた Run の数で、到達後に下がった Run も数える（OFF seed 2 の最終 EMA は 133.0）。
- `47_agent_noisy` は learn step 503 ごと（約 16,000 exp step ごと）に測る。learn step 0 は学習開始時（exp step 8,192）である。
  probe は ReplayBuffer から一様に選んだ 128 状態について、Learner の現在値のノイズ設定で 32 回引き直した Q を μ-only の Q と比べる。エントロピーは自然対数で求める。

### 探索観点

NoisyNet を実際の学習で動かし、次の 3 点を見る。

1. 学習が壊れないか（完走、非有限値、checkpoint の保存）。
2. NoisyNet の診断メトリクス（σ 統計と probe）が成立するか。
3. 既存の探索への上乗せと、ε のランダム行動の置き換えで、成績が変わるか。

### 考察

- 上乗せでも置き換えでも、1.5M〜2.0M の policy reward は OFF の seed の幅に収まった。LunarLander の QR は 2M で seed の差が大きく（[2026-08-08](2026-08-08_iqn.md) の QR 32 の 3 seed も 100.0〜190.3 に散らばった）、3 seed では 20 程度の差は判定できない。
- 学習開始時は、ノイズだけで greedy 行動がほぼ一様にばらついた（エントロピーが上限 1.386 の近く）。Head の μ が gain 0.01 で小さく、射影の σ が μ の 50 倍あることと整合する。
  その後 σ が縮み Q の差が開くにつれて、ノイズが greedy 行動を変える割合は 2〜4% まで下がった。ノイズの効きは学習の中で小さくなった。
- 置き換えの Munchausen の clip 率（0.015〜0.018）は OFF（0.025〜0.033）より低い。ε のランダム行動が replay に入らないので、方策の確率が小さい行動の `τ·log π` が下限 −1 に当たりにくいことと整合する。
- readout の weight norm（σ を含まない）の最終値は、NoisyNet の腕で 34.8〜40.3、OFF で 33.8〜36.3 だった。3 seed では差と判定しない。
- 3 腕を同時に走らせたため、1 Run の実時間は 9〜24 分とばらついた。腕の速さは比べない。
