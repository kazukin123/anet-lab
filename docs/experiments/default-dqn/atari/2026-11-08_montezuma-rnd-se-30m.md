- Train Actor の探索は、lane ごとの ε ラダー（0.4〜0.01、log）と UQE。τ は 32 本・乱数。
- RND: β=0.1、出力 512、target の NN は公開実装の形（32@8/4、64@4/2、64@3/1、LeakyReLU 0.2）、predictor の学習率 1e-4。
