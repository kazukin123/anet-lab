## 現時点のまとめ

1. **BTR 型の ε の経過（3 段）は ε 腕と同等だった。** 0〜6M をラダー 0.06〜1.0、6〜25M を全 lane ε 0.01、25〜50M を ε 腕のラダーにして
   checkpoint でつないだ。45-50M の突破率は 7.7%（ε 腕 5.1%）、ε=0 断面の最良は 26,676（ε 腕 26,068）。BTR との差は埋まらない（探索ブロック 01）。

2. **6〜25M の全 lane ε 0.01 は、ε 腕のラダーより第 7〜8 面の経験が少ない。** 20-22M の train で第 7 面以降に着いた割合は 37.8〜40.0%（ε 腕 55.8〜58.0%）。
   ε 腕は半分の lane が 0.0022 未満にあり、低 ε の lane ほど深い面に届く（探索ブロック 01）。

3. **battle_zone の ε ラダー腕は、旧ラダー（0.01〜0.4）とほぼ同点だった。** ε=0 断面の最良は 118,388（旧ラダー 115,533）、40-50M の ε=0.01 評価は 106,389（97,553）。
   序盤は遅い（10.3M の ε=0 断面 35,590 対 59,858）（探索ブロック 02）。

4. **qbert の第 8 面突破率は、64 env + replay 1M（BTR と同じ env 数・容量、lane 窓 16,384 据え置き）の Run で高く出やすい。**
   45-50M の突破率は 64 env / 1M の素の 3 seed が 45.6 / 32.6 / 0.7%、UQE・ViT を載せた 2 本が 45.8 / 27.4%。
   128 env 系（2M の 3 seed、3 段、行動ネットの同期 25、1M）と 64 env / 2M の 7 本は、すべて 7.7% 以下だった。
   seed 1 は ε=0 断面 45.7M で 32,948（102 本すべて突破）で、BTR 公開 CSV の 45M（33,105）と同水準（探索ブロック 03）。

5. **ただし再現は確実ではない。** 64 env / 1M の seed 3 は抜けなかった（初突破 45.9M、45-50M 0.7%）。
   ε=0 断面 45.7M の平均点は 64 env / 1M が 25,490〜32,948、128 env / 2M が 23,856〜27,042 で重なる。
   上位 4 本が 5 本の 64 env / 1M 系に偶然集まる確率は約 1%（UQE・ViT を同条件と数えた場合）だが、素の 3 seed 対 3 seed なら 20% になる（探索ブロック 03）。

6. **容量だけ・env 数だけでは効かない。** 128 env / 1M（lane 窓 8,192）は 45-50M で 1.0%、64 env / 2M（lane 窓 32,768）は 0.1%。
   引いたデータの年齢は、lane の step で数えると 64 env / 1M と 128 env / 2M が同じ（約 9,100）。学習の更新数で数えると 64 env / 1M と 128 env / 1M が同じ（約 9.1k 更新）。
   64 env / 1M はその両方がそろった唯一の組み合わせだが、効き方の仕組みは測れていない（探索ブロック 03）。

7. **第 8 面の初突破の時期は seed で大きくぶれ、早く出ても広がらない。** 初突破は 18.5〜45.9M に散らばる。
   128 env / 2M の seed 2（25.0M）・seed 3（19.3M）、同期 25（18.5M）は早く出たが、45-50M でいずれも 5% 以下だった（探索ブロック 03）。

8. **行動に使うネットの同期を 400 → 25 step（遅れ 51,200 → 3,200 遷移）にすると、序盤は速いが突破は定着しない。** ε=0 断面 20.4M で 25,850（ε 腕 22,298）、
   45-50M の突破率は 1.8%。ただし序盤の速さは seed でも大きくぶれる（128 env / 2M の 3 seed で 20.4M が 17,390〜22,298）（探索ブロック 03）。

9. **内部指標は、抜けた Run を見分けない。** q_gap は 64 env / 1M と 128 env / 1M（更新数で数えた replay が新しい 2 つ）で大きく、
   20-25M で 0.65〜0.71 対 128 env / 2M の 0.56〜0.59。抜けなかった 128 env / 1M と 64 env / 1M の seed 3 も大きい（探索ブロック 03）。

10. **env64 の上に載せた UQE と ViT は、env64 の seed の幅の中だった。** 45-50M の突破率は UQE 45.8%、ViT 27.4%（素の env64 は 32.6〜45.6%、seed 3 は 0.7%）。
    ViT は実時間が 7.56h で、env64 の 6.25〜6.84h より 1 割ほど長い（探索ブロック 04）。

11. **battle_zone では 64 env / 1M の効果は見えない。** seed 1 は 25.5M に ε=0 断面 146,203 まで上がったあと、45.7M で 97,236 まで下がった。
    seed 2 の最良は 113,299 で、128 env / 2M と同水準。40-50M の ε=0.01 評価は 94,621 / 86,616 で、128 env / 2M（106,389）より低い（探索ブロック 05）。

12. **ε=0 断面の第 8 面到達は、断面ごとに大きく上下する。** 例: ε 腕 40.6M 93/100 → 45.7M 32/103、64 env / 1M seed 1 20.4M 68/102 → 25.5M 4/109、
    3 段 35.3M 98/100 → 40.4M 22/106。同じ落ち込みは 128 env / 2M の seed 2・3 と UQE にも出ている。1 断面の比較では判定しない（探索ブロック 03）。

## 探索ブロック 01: BTR の ε の経過を 3 段で再現する（qbert）

### 探索観点

BTR の train の ε は、時定数 2M 遷移の指数減衰で 1.0 から 0.01 へ下がり、25M 遷移で切られて NoisyNet だけになる（全 env 共通の 1 つの ε）。
これをラダーと checkpoint の継ぎ足しで近似し、ε 腕と比べる。

### 設計

| 段 | 範囲（通算） | ε | 起点 |
|---|---|---|---|
| 1 | 0〜6M | ラダー 0.06〜1.0（`eps_start=1.0 eps_end=0.06`） | 新規 |
| 2 | 6〜25M | 全 lane 0.01（`eps_start=eps_end=0.01`） | 1 段目の `agent_close.anet`（`A3.auto_load_file`） |
| 3 | 25〜50M | ε 腕と同じラダー 1e-4〜0.05 | 2 段目の `agent_close.anet` |

- 段の長さは CLI の `app.batchrun.exp_exit_step`（6M / 19M / 25M）で切った。
- checkpoint から戻るのはネットと optimizer だけ。replay は空から始まり、exp step は 0 から数え直し、学習開始前の 200k（warmup）も段ごとに入る。
- 1 段目のラダーは、BTR の 0〜6M の ε の時間分布に合わせた。ε 0.5 超の割合は 25%（BTR 23%）、0.2〜0.5 は 33%（31%）、0.06〜0.2 は 43%（45%）。ただし BTR は時間の順に下げ、ラダーは lane に並べて同時に回す。
- 3 段目は NoisyNet の代わりに ε 腕のラダーにした。ε 腕との違いは前半 2 段だけになる。

### 結果

ε=0 断面（約 100 本。括弧は第 8 面到達 / 突破 / 本数）:

|---|---|---|---|
| 5.3M | 3,989 | 5.3M | 3,848 |
| 11.3M | 12,624 | 10.3M | 12,556 |
| 16.3M | 15,598 | 15.4M | 15,843 |
| 21.4M | 22,585（20/0/103） | 20.4M | 22,298（36/0/101） |
| 25.2M | 23,659（34/0/103） | 25.5M | 23,150（54/0/102） |
| 30.3M | **26,676（100/0/100）** | 30.5M | 24,979（80/0/102） |
| 35.3M | 25,902（98/0/100） | 35.6M | 24,768（72/0/101） |
| 40.4M | 18,454（22/0/106） | 40.6M | **26,068（93/0/100）** |
| 45.4M | 26,471（96/0/102） | 45.7M | 23,856（32/4/103） |

| | 3 段 | ε 腕 |
|---|---|---|
| train の初突破 | 39.7M | 41.5M |
| 45-50M の train 突破率 | 7.7%（150 / 1,956） | 5.1%（105 / 2,061） |
| 49-50M の train 突破率 | 7.2% | 13.3% |

**2 段目（全 lane ε 0.01）は第 7〜8 面の経験が少ない。** train のうち `round_clear` が 6 以上（第 7 面以降に到達）の割合:

| 通算 | 3 段 | ε 腕 |
|---|---|---|
| 17-18M | 11.4% | 20.7% |
| 19-20M | 20.6% | 38.2% |
| 20-21M | 37.8% | 55.8% |
| 21-22M | 40.0% | 58.0% |

`round_clear` = 7（第 8 面で終わった）のゲームは、20-21M で 45 本 対 116 本、21-22M で 82 本 対 115 本。
3 段目に入った 25M 以降は逆に 3 段が多く、26-35M の第 8 面到達率は 48〜67%（ε 腕 32〜50%）。
lane の ε 帯ごとの到達率も、ε 0.001 未満で 82.8%（ε 腕 66.5%）、0.001〜0.003 で 76.0%（61.4%）と高かった。突破率は 2.1% 対 1.3% で、ほぼ同じ。

**段の境目に成績の段差は無かった。** ε=0.01 評価は、1 段目の終盤（5.45〜5.95M）4,035〜4,062、2 段目の warmup 中 3,878 / 3,875、学習再開後 4,055（通算 6.7M）。

**ε を 0.01 にそろえた直後に loss が大きく振れた。** replay からランダム行動の遷移がほぼ消え、次の値が下がった。

- `36_agent_munchausen/01_scaled_logp_mean`: −0.38 → −0.02
- `03_clip_ratio`: 0.10 → 0.003
- TD の標準偏差: 7M までに 2.8 → 0.7

loss は 7.25M で 0.9 まで下がり（ε 腕 1.8）、11.5M に 9.7 の山を作った（ε 腕 5.0）。そのとき grad clip の発動率は 0.90（ε 腕 0.60）。
16.5M では 2.1（ε 腕 2.5）で同水準に戻った。同じ谷と山は ε 腕にもあり（7.25M 1.8、12.25M 7.1）、3 段は振れ幅だけが大きかった。

## 探索ブロック 03: env 数・replay 容量・行動ネットの同期（qbert）

### 探索観点

ネット構成・損失・主要ハイパラを BTR に合わせたあとも、BTR との間に次の違いが残っていた。

| 項目 | BTR | 基準（ε 腕） |
|---|---|---|
| env 数 | 64 | 128 |
| replay 容量 | 1M | 2M |
| 行動に使うネット | 毎 step、最新の online net | online net の複製を 400 train step（51,200 遷移 ≈ 800 更新）ごとに同期 |

1 lane の窓（容量 / env 数）は Breakout で効いた量なので、64 env / 1M では 16,384 のまま据え置いた。
行動ネットの遅れは遷移数でそろえた（64 env では同期を 800 step）。

### 腕の設計

| 腕 | env | replay | lane 窓 | 同期（step / 遷移） | replay の長さ（更新数換算） |
|---|---:|---:|---:|---|---:|
| 128 / 2M（ε 腕） | 128 | 2,097,152 | 16,384 | 400 / 51,200 | 約 32.8k |
| 64 / 1M（env64） | 64 | 1,048,576 | 16,384 | 800 / 51,200 | 約 16.4k |
| 128 / 1M | 128 | 1,048,576 | 8,192 | 400 / 51,200 | 約 16.4k |
| 64 / 2M | 64 | 2,097,152 | 32,768 | 800 / 51,200 | 約 32.8k |
| 128 / 2M 同期 25 | 128 | 2,097,152 | 16,384 | 25 / 3,200 | 約 32.8k |

再利用回数（1 遷移あたり約 4 回、64 遷移に 1 更新）はすべて同じ。

- **seed 1 は BTR の曲線に乗った**: ε=0 断面は 35.6M 28,055 → 40.6M 30,933（101 本中 70 本突破）→ 45.7M 32,948（全本突破）。BTR 公開 CSV は 40M 31,188、45M 33,105。
- **第 8 面に着く割合は変わらず、着いた後に抜けるかが変わった**: 25M 以降の lane の ε 帯ごとの第 8 面到達率は、seed 1 と ε 腕でほぼ同じ（ε 0.001 未満で 68.4% 対 66.5%、0.01〜0.016 で 41.8% 対 38.8%）。突破率は 26.1% 対 1.3%、9.5% 対 1.1% と 1 桁違った。
- **平均点の差は小さい**: ε=0 断面 45.7M の平均は、64 env / 1M が 25,490〜32,948、128 env / 2M が 23,856〜27,042 で重なる。

## 探索ブロック 04: env64 の上の UQE と ViT（qbert）

### 探索観点

UQE と ViT ハイブリッドは、Breakout ではどちらも成績中立だった。qbert の 64 env / 1M の上に 1 変数ずつ載せる。

- **UQE**: `A2.actor.[train].policy.policy_type=UQE`。τ ラダー 0.9〜0.5（既定）、ランダム行動のラダー `uqe_eps` 0.05〜0（ε 腕と同じ）。ランダム行動の多い lane ほど τ が楽観側になる。
- **ViT**: `run.@vitbtr`（Pool6 の後ろに `PosEmbed2D > AtariImpalaTrans64`）を `run.@btrsn12` の後ろに置いた。

### 結果
