# Atari Breakout: RR4 天井と LayerNorm — 2026-08-31

対象 workspace: `atari-2nd`。ゲームは breakout 固定。すべて seed 1、n=1。

## 現時点のまとめ

1. **LayerNorm(Linear512 直後)は RR4 の天井を大きく押し上げた。** 45-50M 窓で 378.4、無保護対照 295.7。終盤も上昇中（47.5-50M で 391.3）（探索ブロック 01）。
2. **RR1 では eval 終端平均が対照と同等だった。** RR1+LN512 の 25-50M 窓平均 409.6 ± 26.9、対照 399.6 ± 37.9。差はブレ幅の内側（探索ブロック 02）。
3. **しかし eval1 は壁突破を検出できない。** 突破は約 1% の事象で、平均への寄与は約 2 点。eval1 の窓ブレ幅 30-40 の 1/15 で、原理的に埋もれる（探索ブロック 05）。
4. **train 側で見ると RR1+LN512 は対照の 2.8 倍の突破率だった。** 25-50M プール（n≈16,000）で `≥432` が 1.32% 対 0.47%、`≥600` が 21 本対 4 本（探索ブロック 06）。
5. **RR1+LN512 の 50M 時点の突破率は、素の RR1 が 75-100M で到達する水準と同じ。** 1.32% 対 1.31%（探索ブロック 06）。
6. **train score は 50M でも単調上昇していた。** 35M 以降 173.5 → 185.0 → 187.4 → 193.2 → 198.0 → 198.4。頭打ちではない（探索ブロック 07）。
7. **スコア分布は 432 点に壁がある。** 400-449 に集中し、475-624 がほぼ空で、その上に高得点が散在する。Breakout の 1 画面は 18 列 ×(1+1+4+4+7+7) = 432 点である（探索ブロック 04）。
8. **勾配ステップ軸を揃えると RR1 が RR4 を大きく上回る。** 150-190k grad で RR1 439.6、RR4 系 326.9〜341.2。同一 exp 予算では RR4 が勾配 4 倍を使って負ける（探索ブロック 08）。
9. **target 追従の整合(τ=0.00025)は可塑性に一切効かない。** 15-20M で `02_dead_ratio` 0.335、無保護対照 0.338。動くのは `11_q_max_mean`(4.9 対 9.9)・`61_weight_norm_feature`(76 対 89)・`01_loss`(0.13 対 0.22) である（探索ブロック 09）。
10. **τ 単独は速いが崩壊する。** 7.5-10M で 420.6（RR1 が 37.5M で到達する水準）まで伸び、そこから −24% で 320 に落ちて安定した（探索ブロック 09）。
11. **τ + LN512 は崩壊しないが壁を越えない。** 15M 以降の train 突破率が 0.00〜0.05%。機序は健全（20-25M で dead 0.036、`45_probe_srank_ratio` 0.907）（探索ブロック 10）。
12. **PER の除外機能は RR1 でしか生きていない。** `07_evicted_unsampled_ratio` は RR4 で 0.0001、RR1 で 0.249（探索ブロック 11）。
13. **機序指標の健全性はスコアを予測しない。** LN512(RR1) は全腕中最良の表現健全性（dead 0.005）で eval 終端平均は対照と同等、τ+LN512 は dead 0.036 で全 LN 腕中最下位だった（探索ブロック 02・10）。

## 探索ブロック 05: eval1 の検出力

`51_eval1` は 1 eval = 1 エピソードで、5M 窓あたり RR1 系で 19-20 本、RR4 系で 78 本である。壁突破は約 1% の事象で 1 本あたり +200 点程度なので、窓平均への寄与は約 2 点になる。窓平均の sd は 27-38 であり、**約 15 分の 1 で埋もれる**。

実際、37.5M 以降の `≥600` は eval1 では RR1+LN512 5/117、RR1 対照 5/117 で区別が付かなかったが、train 側では 21 対 4 と分離した（探索ブロック 06）。

**壁突破の判定に eval1 の窓平均を使ってはならない。**
