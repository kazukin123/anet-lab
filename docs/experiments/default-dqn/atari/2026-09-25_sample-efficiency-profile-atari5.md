## 現時点のまとめ

1. **Atari-5 回帰は 458.3（学習中の最良、50M）で、BTR 555.2 の 82.5%。** 同じ 50M の実時間優先は
   seed 1 370.7 / seed 2 420.7 で、**+8.9〜+23.6%**。実時間優先 seed 2 の 100M（465.5）とほぼ同じ（探索ブロック 01）。

2. **実時間は 5 本合計 35.6h。** 実時間優先は 50M で 18.9h（seed 1）/ 11.9h（seed 2）、100M で 24.0h（seed 2）。
   **同じ水準の Atari-5 に 1.5 倍の実時間がかかる**（探索ブロック 01）。

3. **BTR 比はゲームで二分される。** phoenix 94% / name_this_game 102% / double_dunk 101% に対し、
   **battle_zone 68% / qbert 60%**。残りの差はこの 2 本にあり、battle_zone は Atari-5 の重みが最大（0.382）である（探索ブロック 01）。

4. **phoenix は実時間優先の 2.2〜2.6 倍。** ε=0 断面の最良 399,895（45.7M）は Table A2 427,481 の 94%、
   公開 CSV の最大 367,284 の 109%。45.7M の断面は 100 本中 44 本が 27,000 step の上限で打ち切られており
   （打ち切り組の平均 454,277）、**上限が成績を抑え始めている**（探索ブロック 02）。

5. **name_this_game は同じ 50M で実時間優先の +24%、BTR の 102%。** ε=0 断面の最良 28,465（45.7M）は
   実時間優先 seed 2 の 100M の最良 24,851 も上回り、最後まで伸びている。**45.5M 以降のメトリクスはディスク容量切れで欠落**し、
   評価値は Run ログから復元した（探索ブロック 02）。

6. **double_dunk は 20M で天井に着く。** ε=0 断面は 20.4M 22.1 → 45.7M 23.2（BTR の 101%）。
   BTR の公開 CSV（20M 19.8）より早く、実時間優先は seed 2 でも 50.7M で 21.5 だった（探索ブロック 02）。

7. **battle_zone は序盤だけ速い。** ε=0 断面で実時間優先を上回るのは 15.4M まで（10.3M で +34〜38%）。
   eval2 は 15-20M 91,545 → 45-50M 103,735（+13%）でほぼ横ばいになり、実時間優先は同じ区間で seed 1 +70% / seed 2 +145%（探索ブロック 02）。

8. **battle_zone の train の得点は lane の ε で大きく変わる。** 25M 以降、ε 0.01〜0.016 の lane は平均 97,023・10 万点以上 32.9% に対し、
   ε 0.25〜0.4 は 35,340・0.1%。**ε 0.1 以上の lane が train のゲームの 44% を占める**（探索ブロック 02）。

9. **特徴層の痩せは battle_zone と double_dunk に出る。** プール後の特徴で死んだユニットが battle_zone 4.9% → 19.1%、
   double_dunk 9.0% → 17.5% に増え、実効ランクも下がる。phoenix / name_this_game / qbert では起きない。
   **double_dunk は痩せても天井に届いた**ので、battle_zone の頭打ちの原因とは言えない（探索ブロック 02）。

10. **qbert の第 8 面の壁は RR4 でも同じ。** ε=0 断面の最良 25,564（BTR の 60%）。train で第 8 面に着く割合は lane の ε で急落し
    （25M 以降、ε 0.01〜0.016 で 37.6%、0.1 以上で 0.1%）、全体では 11% に留まる（探索ブロック 02）。

11. **qbert の ε ラダーを 1e-4〜0.05 に下げると、第 8 面の突破が 41.5M から出始める。** 49-50M の train で 392 本中 52 本（13.3%）、
    最高 34,375。旧ラダー（0.01〜0.4）は 50M 全体で 0 本。第 8 面への到達は 35-50M の train で 49〜61%（旧 8〜11%）（探索ブロック 03）。

12. **効いたのは低 ε の lane の割合で、同じ ε での腕前ではない。** 同じ ε 帯の第 8 面到達率は 2 本でほぼ同じ
    （0.01〜0.016 で 38.8% 対 37.6%、0.025〜0.04 で 18.1% 対 16.0%）。代わりに序盤が遅くなる（ε=0 断面 5.3M で 3,848 対 6,436）（探索ブロック 03）。

13. **qbert の `round_clear` = 8 は第 8 面のクリアと一致しない場合がある。** 第 8 面に入ってすぐ（25,450〜26,950 点）に終わったゲームも 8 を返す
    （ε 腕 43 本、旧ラダー 29 本）。旧ラダーで唯一 29,000 点を超えたゲーム（29,575）は 7 だった。
    **クリアの判定は「8 かつ 29,000 点以上」で行う**（探索ブロック 03）。

14. **grad clip（`grad_clip_tau` 10）の発動率は qbert と name_this_game で高いが、削った勾配は小さい。**
    発動率は qbert の 10-20M で 45.7%、name_this_game で 10〜16%。削った量（1 − Σmin(ノルム, 10) / Σノルム）は qbert で最大 12.4%、
    name_this_game で 3〜4%。クリップされた step の倍率は中央値 0.84〜0.90（探索ブロック 02）。

### 考察

同じサンプル数ではサンプル効率優先がはっきり上で、同じ実時間では実時間優先 seed 2 の 100M と並ぶ。

## 探索ブロック 02: ゲーム別の中身と内部指標

### 探索観点

Atari-5 回帰の中身をゲームごとに分け、BTR に届く 3 本と届かない 2 本の違いを、スコアの推移・ゲームの長さ・lane 別の得点・内部指標で見る。

### phoenix

**ε=0 断面の最良は 399,895（45.7M）で、同じ 50M の実時間優先（seed 1 155,188 / seed 2 185,402）の 2.2〜2.6 倍。**
実時間優先 seed 2 の 100M の最良 197,025 に対しても 2.0 倍。
Table A2 427,481 の 94%、公開 CSV の最大 367,284（178M frames）の 109%。

RAM メトリクスでは 45.7M の断面で、1 ゲームあたり母艦以外 130.4 + 母艦 32.0 = 162.4 ウェーブを抜けている。
1 ウェーブあたり約 2,460 点で、40.6M（153.4 ウェーブ、約 2,430 点）とほぼ同じ。**得点の伸びは抜けたウェーブの数の伸び**である。

**27,000 step の上限で打ち切られるゲームが増えている。** Run ログで ε=0 断面の最初の 100 本を分けた値
（ログの終了順で 100 本を取るので、平均はメトリクスの断面値と数 % ずれる）。

| 10.3M | 0 本 | — | 76,458 |

### name_this_game

**ε=0 断面の最良は 28,465（45.7M、ログから復元）で、Table A2 27,917 の 102%。** 公開 CSV の同じ step（45M 27,227）の 104.5%、
CSV の最大 28,710 の 99.1%。40.6M → 45.7M で +5.0% と、最後まで伸びている。

**実時間優先との差は seed の幅を大きく超える。** eval2 の 45-50M はサンプル効率優先 27,849（ログ、200 エピソード）に対し
実時間優先 seed 1 23,039 / seed 2 21,696 で、+21% / +28%。seed 1 と seed 2 の差は 6%。
train の EMA（45-50M、メトリクスは 45.5M まで）は 23,809 対 19,648〜20,579。

**実時間をそろえると実時間優先 seed 2 の 100M と並ぶ。** 実時間優先 seed 2 の 100M（4.76h）と同じ実時間で、
サンプル効率優先は約 31M にいて、ε=0 断面は 24,941（30.5M）対 24,851（seed 2 の 100M の最良）。

**評価の負担が大きい。** 1 ゲームが約 1 万 step と長く、35.6M 以降の ε=0 断面は 1 回（100 本）に 628〜701 秒かかる。
Run ログの進捗行で分けると、評価セッションが走っている時間が全体の 64.7% を占め、その間の学習速度は評価なしの 62〜78% に落ちる。
評価で失った時間は約 1.25h（全体 7.76h の 16%）。

### 考察

## 探索ブロック 03: qbert の ε ラダーを 1e-4〜0.05 へ

### 探索観点

探索ブロック 02 で、qbert の train が第 8 面に着く割合は lane の ε で急落し、旧ラダー（0.01〜0.4、中央の lane 0.063）では
train 全体の 11% しか着かなかった。低 ε の lane を増やせば第 8 面の経験が replay に入り、壁を抜けるかを 1 腕で確かめる。

`eps_end = 0` にすると、log スケールのラダーは 0 を 1e-4 に丸める（起動時に WARN を 1 回出す）。
lane は 1e-4〜0.05 の対数等間隔になり、中央の lane は 0.0022、74% の lane が 0.01 以下。
spatial exploration の ε は lane ごとに固定で、学習の途中で変わらない。

代わりに探索が減った序盤は遅く、5.3M の ε=0 断面は旧ラダーの 60%。
