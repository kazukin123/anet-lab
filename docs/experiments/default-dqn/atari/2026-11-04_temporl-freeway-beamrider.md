## 目的と比較条件

qbert では合算の変種 8 本がどれもスキップなしを下回った（[qbert の記録](2026-10-31_temporl-qbert-50m-learning.md)）。別のゲームで同じ構成の TempoRL を流し、[PRD103](../../../memo/done/103_temporl_reference_alignment_10prd.md) §8 の再開条件に当てる。

- 構成はサンプル効率優先（RR4、64 env、replay 1,048,576、γ=0.997、n_step 3、IQN、NoisyNet、SN・he の初期値、pixel_area 縮小）。予算は BeamRider が 50M、Freeway が 10M（exp step）。TempoRL の群は J=10、`skip_context = iqn_fusion`。
- Train Actor の ε は、1.0 から 0.01 へ時定数 2M の指数で 25M まで下げ、そのあと 0 にする。
- 評価: `[greedy]`（`53_evalg`）と `[greedy_single]`（`54_evalgs`）は ε=0、100 ゲーム。BeamRider は約 5.05M ごと、Freeway は約 1.01M ごと。`[eval]`（`52_eval2`）は ε=0.01、10 ゲーム、約 0.25M ごと。
- 合算では `[greedy]` と `[eval]` と Train Actor が full、`[greedy_single]` が single である。スキップなしと補助学習のみは全 Actor が毎 step 判断するので、`53_evalg` と `54_evalgs` は同じ方策の別 session である。
- BeamRider の RAM の指標（[220 §4.9](../../../design/220_atari_env.jp.md)）: `sector_clear`（セクター）、`boss_kill`（ボス）、`torpedo_fired`（魚雷）。
- 値の出どころ: 評価と学習の進みは完走 Run の `metrics_cache.db`、止めた合算 s2 の評価は `metrics.jsonl`。学習側と、ゲームごとの分布は Run のログの Game over の行で、session の 100 本を超えて始まったゲームも含む。
- 補助学習のみはメイン機（RTX 5090）、2026-11-03 22:02 のビルド。ほかはサブ機（RTX 4060）で、BeamRider は 2026-10-31 23:18 のビルド。2 つのビルドの差は GUI だけで、学習のコードは同じ。
