## 現時点のまとめ

1. **5 腕試して、成績で対照を有意に上回った腕はゼロ。** 終端窓（4-5M）の対照は 121.9 ± 11.8 で、これを超えた腕が無い（探索ブロック 02）。
2. **機序指標は大きく動く。** `01_dormant_ratio` は SiLU で −10.9σ、LN512 で −9.0σ。`45_probe_srank_ratio` は LN512 で **+14.2σ**。**表現の健全性は明確に改善できる**（探索ブロック 03）。
3. **それでも `18_q_gap_rel` は全腕で対照帯から出ない**（−1.1〜+1.7σ）。**表現の健全性と行動の識別性が繋がっていない**のが本 campaign の中核的な観測（探索ブロック 03）。
4. **機序側だけなら LN512 が総合 1 位。** 実効ランク +14σ は 5 腕で最大、dormant −9σ、dead −5.6σ、しかも複製間の一致が極めて良い。**それでも成績は対照と同等〜悪い**（終端 z = −1.00 / −3.00）（探索ブロック 02・03）。
5. **SiLU は③を完全に消したうえで負けた。** dormant −10.9σ・dead は厳密ゼロ・ランク +8σ。成績は落差 z = −2.7、終端 z = −4.4 / −3.4 で**有意に悪い**。「dormant の増加は 100% dead の増加で説明される」から③を主犯と読んだのは相関であり、因果ではなかった（探索ブロック 02・03）。
6. **Spectral Norm には「①が止まる範囲」と「発散しない範囲」の両立点が無い。** 全層適用は実効ノルムを 28.2 → 26.5 でフラットにする（①を止めた唯一の例）が **Q 値が発散**（q_max 0.89 → 2,700）。BTR と同一範囲（residual conv のみ）は発散しないが**①が止まらない**（実効ノルムが生と一緒に 39 → 61）（探索ブロック 01）。
7. **BTR の適用範囲は residual conv のみ。** 公開実装で確認 — stage の入口 conv も最終 linear も掛けていない。全層適用は本記録の判断で、文献の裏付けは無かった（探索ブロック 01）。
8. **`65_spectral_sigma_feature` は BTR 範囲の SN を評価できない。** feature 群の max σ なので、SN 非適用層（入口 conv・Linear512、σ≈1.9）が max を占め、SN 対象層の σ が見えない。**層別 σ が無いと SN の効きを追えない**（探索ブロック 01）。
9. **判定の物差しは「落差」ではなく「終端の絶対値」。** 落差はピークが分母なので、ピークが下がる腕で自動的に浅くなる。LN512 r1 の落差 −34.7%（z = +6.73）は複製 r2 で −57.7%（z = −0.14）となり再現しなかった（探索ブロック 02）。
10. **zero-init residual（`init2.mode`）は未検証のまま。** B 腕は `res.init2.mode` と書いたが正しいキーは `init2.mode` で、**未知キーとして黙殺**されていた。2 本とも対照と同一構成で走った（探索ブロック 04）。

## 探索ブロック 01: Spectral Norm の適用範囲

### 探索観点

[PRD 065](../../../memo/065_nn_spectral_norm_10prd.md) の SN を初めて実行する。PRD の検証計画は「初手は全層（standalone Conv2d 3 本 + ResBlock 全部 + Linear512）」を推奨していた — 2026-08-28 の GroupNorm 試験が ResBlock 内部のみで測定点を覆わず公正にならなかった反省による。

### 探索結果

**全層適用（C）は Q 値が発散した。**

| exp | 200k | 660k | 773k | 904k | 1014k |
|---|---|---|---|---|---|
| C `q_max_mean` | 0.011 | 0.89 | **12** | **267** | **2,700** |
| 対照 同区間 | 0.022 | 0.60 | 0.60 | 1.0 | 1.3 |

`td_mean` は 7.9e4 まで、`grad_clip_ratio` は 1.0 に張り付いた（全 update がクリップ）。

**ただし SN 自体は設計どおり動いていた。** 発散前（0〜28k 勾配）で PRD が予測した三点証拠が揃う。

| 勾配 | 0 | 14k | 28k |
|---|---|---|---|
| `61` 生ノルム | 49.4 | 49.8 | **53.2**（伸びる） |
| `63` 実効ノルム | 28.2 | 27.3 | **26.5**（**フラット**） |
| `65` σ | 1.88 | 2.13 | 3.50（クランプが噛む） |

対照は同区間で `61` が 42.4 → 44 程度、そのまま 142k で 67.1 まで伸び続ける。**実効ノルムが伸びを止めたのは本 campaign 全 5 腕でこの 1 例のみ**であり、weight_decay の V 字（45.8 → 30.5 → 43.4）とは別種の挙動である。

**BTR の適用範囲は residual conv のみ**（[公開実装](https://github.com/VIPTankz/BTR) `networks.py` で確認）。`ImpalaCNNResidual` の `conv_0` / `conv_1` だけが `norm_func` で包まれ、**stage の入口 conv・最終 linear・Q 出力 linear は素**である。

**BTR と同一範囲（C2 / D2）では発散しないが、①も止まらない。**

| 終端 | `61` 生 | `63` 実効 | `65` σ |
|---|---|---|---|
| C2（spectral） | 69.8 | **61.0** | 1.91 |
| D2（cap） | 65.7 | **60.8** | 1.87 |
| C（全層・発散後） | 67.0 | 10.1 | 31.0 |

C2 / D2 は σ が 1.73 → 1.91 とほぼ動かず、除算量が一定なので `61` の成長がそのまま `63` に通る。

### 考察

**「①が止まる範囲」と「発散しない範囲」に両立点が無い。** 全層は Linear512 まで縛って値のスケールを作る経路を殺し、residual のみは feature 群の大部分を野放しにする。

発散の機序として 2 つが候補に残る。(a) SN が feature の実効ノルムを固定する一方 readout は素（`64` = `62` が完全一致）なので、γ=0.997 が要求する q_max ≈ 12 の負荷が制約のない head へ集中する。(b) `spectral` は常時除算なので **σ<1 の層は拡大される**。**現在のメトリクスでは分離できない。**

**適用範囲を広げる根拠は失われた。** 全層適用は「GroupNorm の部分適用の罠を避ける」という議論から来ているが、**GroupNorm は②を潰す機構で測定点を覆う必要があり、SN は①を潰す機構でその必要が無い**。機構をまたいだ議論の転用だった。

**`65_spectral_sigma_feature` は BTR 範囲の SN を評価できない。** feature 群の max σ を出す定義だが、SN 非適用層（入口 conv・Linear512 とも σ≈1.9）が max を占め、SN 対象層の σ が隠れる。zero-init の conv2 が σ 0 から育つ過程も同様に見えない。**層別 σ（[920_nn_block_metrics](../../../memo/920_nn_block_metrics_10prd.md) の領分）が無いと SN の評価が成立しない。**

## 探索ブロック 02: screening 4 腕の成績

### 探索観点

機序の各段を叩いた腕が、崩壊アッセイの成績を動かすか。判定は対照 4 本の平均 ± 標準偏差に対する z。

### 探索結果

`51_eval1/10_game_score_mean` の 1M 窓平均。

| 腕 | 1-2M | 2-3M | 3-4M | 4-5M | ピーク | 落差 |
|---|---|---|---|---|---|---|
| **対照平均 ± sd** | **168.9 ± 25.7** | **286.5 ± 34.9** | **214.0 ± 40.1** | **121.9 ± 11.8** | 286.5 | **−57.3% ± 3.4%** |
| E SiLU r1 / r2 | 94.0 / 101.7 | 253.6 / 210.3 | 121.8 / 106.3 | 69.8 / 81.5 | 253.6 / 210.3 | −72% / −61% |
| F LN512 r1 / r2 | 129.7 / 160.3 | 168.4 / 204.4 | 132.9 / 136.0 | 110.0 / 86.4 | 168.4 / 204.4 | −34.7% / −57.7% |
| C2 spectral | 62.0 | 172.5 | 106.1 | 66.1 | 172.5 | −62.3% |
| D2 cap | 147.5 | 267.0 | 176.3 | 100.8 | 267.0 | −62.3% |

**z による判定。**

| 腕 | 終端（4-5M）z | 落差 z | 判定 |
|---|---|---|---|
| E SiLU | **−4.4 / −3.4** | −2.7 | **有意に悪い** |
| F LN512 | −1.00 / **−3.00** | +6.73 / −0.14 | **同等〜悪い**（再現せず） |
| C2 spectral | **−4.7** | −1.38 | **有意に悪い**（ピークも 2-3M 平均に対し −3.3σ） |
| D2 cap | −1.78 | −1.49 | **同等** |

### 考察

**対照を有意に上回った腕はゼロ。**

**判定の物差しとして「落差」は不適切である。** ピークが分母なので、ピークが下がる腕では自動的に浅く見える。LN512 r1 の −34.7%（落差 z = +6.73）は本 campaign で唯一の大きな正の z だったが、複製 r2 は −57.7%（z = −0.14）で再現しなかった。r1 のピークが 168.4、r2 が 204.4 と分母が動いただけである。**終端の絶対値**（対照 121.9 ± 11.8）を主読みにすべきで、この基準では LN512 は r2 が −3.00σ と有意に悪い。

**D2 だけが全指標で対照と同等**（終端 −1.78σ、落差 −1.49σ、各窓 |z| < 2）。序盤 2-3M までは対照の軌道を歩き、崩壊局面で対照の下寄りに落ちる。

**C2 は「落差は同等だが到達点が低い」という別の負け方。** 1-2M で 62.0（対照 168.9 ± 25.7 に対し −4.2σ）と立ち上がりが遅い。`spectral` は常時除算なので初期に全 residual conv の実効重みが σ≈1.89 で割られて 5 割強に縮み、かつ C2 は `init2=he` で残差枝が最初からフルに効く。D2（cap + zero-init）が序盤で対照と同じなのと対照的である。

## 探索ブロック 03: 機序指標と成績の乖離

### 探索観点

成績が動かないなら、機序指標は動いているのか。動いているなら、どこで繋がりが切れているのか。

### 探索結果

終端 5% の値を、対照 4 本の平均 ± 標準偏差に対する z で示す。

| 指標 | 対照 ± sd | E SiLU | **F LN512** | C2 spec | D2 cap |
|---|---|---|---|---|---|
| `01_dormant_ratio` | .310 ± .026 | **−10.8 / −10.9** | **−8.8 / −9.0** | +0.7 | −1.6 |
| `02_dead_ratio` | .157 ± .026 | **−6.1 / −6.1** | **−5.7 / −5.6** | −0.6 | −1.7 |
| `45_probe_srank_ratio` | .811 ± .0087 | +8.4 / +7.9 | **+14.2 / +13.7** | −0.5 | **+3.2** |
| `03_feature_norm` | 9.69 ± 0.82 | **+29.9 / +30.2** | +3.6 / +3.2 | −2.5 | **−4.4** |
| `61_weight_norm_feature` | 67.3 ± 0.79 | +1.8 / +1.9 | +2.7 / +3.9 | +3.3 | −2.0 |
| **`18_q_gap_rel`** | **.026 ± .0071** | **−0.5 / −0.9** | **−0.5 / +1.7** | **−1.1** | **−0.5** |

### 考察

**表現の健全性は明確に改善できる。** SiLU は③を完全に消し（dead が厳密ゼロ、dormant −10.9σ）、LN512 は実効ランクを **+14.2σ** 押し上げた。複製間の一致も良い（LN512 の dormant −8.8 / −9.0、srank +14.2 / +13.7）。**再現性のある実効果である。**

**それでも `18_q_gap_rel` は全腕・全複製で対照帯から出ない**（−1.1 〜 +1.7σ）。**表現の健全性と行動の識別性が繋がっていない。**

これは本 campaign の中核的な観測であり、機序の読みを 1 段変える。②③は①の**下流の症状**であり、症状を個別に塞いでも上流が止まっていない限り識別性＝スコアへ届かない。実際 `61_weight_norm_feature` はどの腕でも対照と同水準（−2.0 〜 +3.9σ）で、**①を止められた腕は発散した全層 SN のみ**である。

**SiLU の負け方が示唆的。** ③を消した代わりに `03_feature_norm` が **+30σ**（活性ノルム 4 倍）。SiLU は負側を通すため活性が伸びる。①②の連鎖はそのまま生きていて、**③の出口だけを塞いだので損傷の出口が変わった**と読める。「dormant の増加は 100% dead の増加で説明される」（[2026-08-28_plasticity.md](2026-08-28_plasticity.md)）から③を主犯と見たのは**相関であって因果ではなかった**。

**D2 は SN 腕で唯一②を抑えた**（`03_feature_norm` −4.4σ、実効ランク +3.2σ）。①の実効ノルムは止まっていないが、residual 枝の Lipschitz を抑えた効果が②に出ている。それでも成績は同等である。

## 探索ブロック 04: config キーの黙殺（B 腕の無効化）

### 探索結果

B 腕（zero-init residual の除去）は `net.block.[X].res.init2.mode = he` と書いたが、ResBlock factory のパースは `ANET_READ_CONFIG(config_data, init2.mode)` で、**正しいキーは `init2.mode`**（`init.mode` と同じくブロック型 prefix の外）。既存記法も `net.block.[AtariConv32].init.mode = he` と prefix なしだった。

`net.body.json` が事後検証に使えた。

```json
"AtariImpalaRes32He": {"config": {"res.init2.mode": "he", ...}}   ← 未知キーとして素通り
"AtariLinear512":     {"config": {"init.mode": "xavier", ...}}    ← 正しいキーは prefix なし
```

**未知キーはエラーにならず黙殺された。** B 腕 2 本は既定の `constant`/0 のまま、対照と同一構成で走った。

### 考察

**zero-init residual の実効は未検証のまま。** 教師あり深層 vision では定番の系譜（zero-γ init / Fixup / ControlNet の zero conv）だが、value-based RL 系列に採用例が無く、BTR にも存在しない（公開実装は PyTorch 既定 init）。15 層規模での実効は未測定である。

**怪我の功名として対照が 4 本になった。** 判定の物差しが固くなり、終端窓の標準偏差 11.8（平均比 9.7%）が得られた。

**NN ブロック config だけ未知キーが黙殺される。** `.$` チェーンや metrics 行は fail-fast であり、非対称である。今回は `net.body.json` で事後に捕まえられたが config 段では検出できていない。**別 PRD の起票候補。**

## 次の検証

- **運用点で摩耗が律速かの確認。** 5 腕試して保護機構が全滅した以上、「そもそも RR1 の運用点で摩耗がスコアを律速しているのか」を先に確かめる。RR1 は 50M でまだ登り坂で（[2026-08-29_bundle-fix-rebaseline.md](2026-08-29_bundle-fix-rebaseline.md) 探索ブロック 02）、100M で旧バンドル記録（60-100M プール 474.7）と接続できる。5.1h。
- **層別 σ。** `65` は群の max σ で SN 非適用層に支配されるため、BTR 範囲の SN を評価できない。`920_nn_block_metrics` の簡易版（購読キーで層をピンポイント指定）で足りる可能性がある。
- **`18_q_gap_rel` が動かない理由。** 表現側をどれだけ改善しても識別性に届かない。γ = 0.997 が action gap を潰していること（[2026-08-17_baseline.md](2026-08-17_baseline.md) 探索ブロック 19: 相対 gap 0.81%）と、その補償器である Munchausen が未実装であることが関連する可能性がある。BTR のアブレーションでは Munchausen は 40M frames で +24%、120M で +13% と SN（+25% / +35%）に次ぐ寄与。
- **zero-init residual の実効。** B 腕の再実行（`init2.mode` 修正版）。
- **D2 の複製。** SN 腕で唯一②を有意に抑えた（n=1）。
- **SN の適用範囲の両立点。** 全層は発散、BTR 範囲は①が止まらない。中間（入口 conv + residual、Linear512 は素）は BTR からの逸脱であり、機序が分離できるまで根拠が薄い。
