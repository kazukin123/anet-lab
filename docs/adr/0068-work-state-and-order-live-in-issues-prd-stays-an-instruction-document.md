# 作業の状態と順序は issue が持ち、PRD は指示文書としてフォルダを動かさない

すべての PRD に issue を伴わせて作業の状態・優先度・順序の正本を issue にし、PRD は指示文書のままフォルダを動かさない（PRD114）。PRD は指示文書なので優先度や作業順を持てず、番号とフォルダだけでは未着手の PRD を管理しきれなかったためで、代わりに issue と PRD の紐付けが増える。

## Considered Options

- **置き場を 1 つにし、PRD を書いたら issue を閉じる**: 紐付けは無くなるが、PRD の優先度と作業順は番号でしか持てないまま。却下
- **issue から起こした PRD だけ issue を残す**: ユーザーが直接起こした PRD が仕事の一覧から欠ける。却下
- **今ある `done/`・`frozen/`・`dropped/` の PRD も直下へ戻す**: 形は揃うが、1,000 を超えるリンクを貼り直すことになる。却下
