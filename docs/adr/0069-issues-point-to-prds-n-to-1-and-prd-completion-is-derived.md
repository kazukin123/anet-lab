# 課題が prd 欄で PRD を指し（N:1）、PRD の実装済みは課題から導く

PRD ごとの専用の窓口の課題（`type: 索引`）をやめ、各課題が `prd` 欄で自分を直す PRD を 1 本だけ指し、PRD の実装済みは指す課題の判定と状態から道具が導く形にした（PRD120）。窓口の課題は大半がその PRD のただ 1 件の仕事の課題と重なって種類の欄で仕事の種類を表せず、導く形なら PRD114 が窓口を分けた理由（1 つの判定の欄が PRD 全体の完了と課題の残りを兼ねる）も起きない。ADR 0068（状態と順序は課題が持つ）は、どの PRD にも指す課題を 1 件以上置くことで、そのまま成り立つ。

## Considered Options

- **窓口の課題を残し、種類だけ付ける**：同じ仕事が一覧に 2 行並ぶ。却下
- **課題に PRD を複数書ける（N:M）**：1 本の PRD の実装済みが、ほかの PRD の進み具合を待つ。却下
- **PRD のファイルに状態を書く**：状態の置き場が 2 つになり、食い違う。却下
- **「実装済み」を PRD の課題 1 件に付ける**：1 つの判定の欄が 2 つの意味を兼ね、監査の確かめ直しが上書きする（PRD114 が窓口を分けた理由そのもの）。却下
- **課題の無い PRD を認める**：その PRD が一覧に出ず、状態をどこにも持たない（ADR 0068）。却下
