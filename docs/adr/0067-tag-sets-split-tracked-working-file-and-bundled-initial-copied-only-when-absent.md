# タグセットは追跡する作業用ファイルと jar 同梱の初期値に分け、初期値は作業用が無いときだけ写す

Metrics Viewer のタグセットは、普段の作業で散らかる作業用ファイル（既定は Workspace 群の親の直下の `metrics_viewer_tag_sets.json`。記録と保全のため `git add -f` で追跡し、リリースの梱包からは除く）と、リリース用にきれいに整えた初期値（jar のリソース `initial_tag_sets.json`）を別のファイルにし、Viewer は作業用ファイルが無いときだけ初期値を写して以後は作業用だけを使う。リポジトリ上で 2 つを分けつつ UI を 1 種類に保ち、新しい版を上書き展開しても利用者の作業用ファイルを壊さないためである。代わりに、新しいリリースで増えた初期値は、既に作業用ファイルを持つ利用者には届かない（PRD111）。

## Considered Options

- **初期値を「組み込み」の区画として作業用と並べる（書き換え不可）**: 新しい初期値が必ず届くが、一覧の区画・書き換え不可の規則・同名の扱いで UI と API が一回り大きくなる。却下
- **梱包で初期値を作業用ファイルの場所へ置くだけ（Viewer は関与しない）**: 上書き展開で利用者の作業用ファイルを消す。却下
- **作業用ファイルを Viewer のフォルダに置く**: 追跡も梱包の除外も特別扱いが要らないが、ユーザーは Workspace 群と一緒に置くことを選んだ。却下
