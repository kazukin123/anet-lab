# query channel の単位を、ブラウザタブと問い合わせの種類の組にする

範囲統計の問い合わせ（PRD196）を足すにあたり、query channel の単位を 1 つのブラウザタブから、タブの中の問い合わせの種類（グラフの描画、範囲統計）ごとに改めた。同じタブのグラフの問い合わせと範囲統計が互いを取り消すと、tag の情報パネルを開くたびにグラフの読み込みが止まるためで、サーバ側の supersede の規則（同じ channel の中だけで取り消し、違う channel は同時実行枠だけを共有する。ADR 0023）は変えない。サーバに問い合わせの種類ごとの取り消しを足す案は、channel を分ければ今の仕組みのまま満たせるので採らなかった。
