# PRD の 9xx の番号を、起票の日の順に 900 未満の連番へ振り直し、9xx を再び使える番号に戻す

9xx の番号を持つ PRD 57 本を、起票の日の順に、その時点の最大の番号の次からの連番へ振り直し、この振り直しを「一度使った番号は再利用しない」の例外として、振り直しより前の 9xx の使用を数えずに 9xx も普通の番号として使う（[PRD 131](../memo/0131_rfd_9xx_renumber_by_creation_date_10rfd.md)）。9xx を残すと新しい PRD がいつも 9xx の手前に積まれて番号の並びの最後が最新にならず、9xx を退役させて飛ばすと番号の並びに予約の帯が残るためである。代わりに、番号が 900 台に届いたあとは過去の記録とコミットの件名にある旧い 9xx が新しい PRD と紛れうるので、旧い番号は各 PRD の題の直下の振り直しの行に持たせ、道具はその行の日付以前のコミットに限って旧い番号を引く。

## Considered Options

- **9xx を今の番号のまま残す（PRD 114 の D13）**: 改名が要らないが、番号の並びの最後が最新の PRD にならない。却下
- **振り直したあと、9xx を使われた番号として飛ばし続ける**: 過去の記録の番号が紛れないが、予約の帯が残り、規約にも 9xx の例外が要る。却下
- **900 台の扱いを、番号が 890 に届いたときに 4 桁の形と一緒に決める**: 今は日付の処理が要らず、9xx を使って得るのは 100 個（今の速さで 3〜4 か月）だけだが、規約が暗に 9xx を予約し続ける。却下
- **旧い番号と新しい番号の対応表のファイルを置く**: 道具は読みやすいが、置き場が増え、PRD を開いても旧い番号が分からない。却下
