# RND の設定は、段階ごとのスコープとモード別の名前空間で持ち、被るキーは割り切る

RND の設定キーは `rnd` の直下に平らに並び、あるモードでだけ使うキーを名前から見分けられず、warm-up の 1 つの件数が 2 つの待ちを束ね、倍率の上限は誤差の式で切る対象の単位が変わっていた（[PRD191](../memo/191_rnd_raw_error_and_recent_learning_10prd.md)）。**RND と補助学習の設定は、段階（統計・誤差・predictor・補助学習）ごとにスコープを分け、モードを持つ段階は `mode` とモードの名前の名前空間で持ち、モードで意味や適した値が変わるキー（待ちの件数、clip）は、被ってもモードごとに持つ**ことを決定する。選ばれていないモードのキーは読んで検証するだけで通知せず、モードの中の「するか、しないか」は列挙にせず真偽で持つ。

## Considered Options

- **今の平らな並びのまま、新しいキーを足す**: 使われないキーの通知が増え、モードを切り替えたときに、前のモード用に書いた値が残る。却下。
- **warm-up を `warmup_mode` で束ねたままにする**: 割らない式を、束の 3 つ目の値として足すことになり、段階をまたぐ設定が残る。PRD123 の決定を、ここで改める。
- **倍率の clip を、誤差の式に依らない独立の段階にする**: 同じ上限が、標準化した値にも生の誤差にも効き、切る対象の単位が変わる。却下。
- **誤差のスコープを、統計のモードの名前空間の下に入れ子にする**: 誤差の式が whiten だけのものであることは形で表せるが、キーが深くなる。段階は横並びにする。却下。
- **新しく足すキーだけを新しい形にする**: 2 つの形が並び、設定と bat を 2 回直すことになる。却下。
