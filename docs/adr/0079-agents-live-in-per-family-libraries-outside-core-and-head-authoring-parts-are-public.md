# Agent は基盤の外の系統ごとのライブラリに置き、Head を書くための部品を基盤が公開する

基盤が具象 Agent を知らない形にするため、Agent を DQN・MuZero・ImageCls の系統ごとのライブラリへ出し、登録は各ライブラリの初期化関数を app が呼ぶ。DQN の Head は基盤の内部の型で書かれているので、Head を書くための型と N-step の経験の組み立てを公開ヘッダへ出し、Head を「基盤の外で書ける拡張点」にする。基盤に Q や分位の名前を持つ Head を残す形は、公開面は増えないが、汎用層が特定のアルゴリズムの名前を持つことになるので採らない。

## Considered Options

- 具象ごとの 5 本のライブラリ: 変更の多い DQN の内部ヘッダが公開面になり、足される強制は今 0 行の依存に対するものなので採らない。
- Agent 全体で 1 本のライブラリ: 系統どうしの独立を機械が守らないので採らない。
