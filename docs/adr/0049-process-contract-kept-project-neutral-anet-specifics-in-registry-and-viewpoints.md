# プロセス契約とレビューエージェントの定義は、プロジェクトに依存しない文面に保ち、anet 固有のことはレジストリと観点に置く

工程の手順を定めるプロセス契約（`docs/process/protocol.md`）とレビューエージェントの定義（`.claude/agents/an-review.md`）は、どのプロジェクトでも使える文面に保つ（PRD 087）。同じ契約をほかのプロジェクトでも使っており、汎用に保てば、どこかで見つけた直しをそのまま持ち寄れるためである。

## Considered Options

- **anet 用に書き換えて持つ**: anet の語彙と工程にそのまま合う。しかし、ほかのプロジェクトの版との差分が追えなくなり、直しを持ち寄れなくなる。
- **anet では一切書き換えない**: 同じ内容であることは保ちやすい。しかし、使っていて気づいた直しを、その場で直せない。直しの入口が anet の外だけになり、依頼と取り込みの手続きが要る。
