# wiki は正本を持たない派生のまとめとし、実験記録の README は要約の部分だけを畳んで独自の分析は正本として残す

`docs/wiki/`（PRD 095）は wiki の外の正本（実験記録・サーベイ・PRD・設計文書・ADR）を題材・機構ごとや実装の部分ごとに束ねたまとめで、主張はすべて wiki の外に出典を持ち、許す重複は「正本 → まとめ」の一方向の 1 段だけにする。実験記録の README の知見には campaign 文書へのリンクの無い記述が多く、要約か campaign 文書に無い独自の分析かは突き合わせるまで分からないので、全部を wiki へ移すと独自の分析だった部分の正本が wiki になる。そこで記述ごとに突き合わせ、要約の部分だけを wiki に畳み、独自の分析は README に正本として残して wiki から引く。

## Considered Options

- **README の知見を全部 wiki へ移す**: 置き場は 1 つになるが、独自の分析だった部分は wiki が正本になり、wiki を派生のまとめとする前提が崩れる。棄却。
- **README の知見を全部残し、wiki が README を引く**: 移す手間は無いが、判断表のような要約の部分が README と wiki の 2 段（まとめ ↔ まとめ）になり、撤回を 2 か所で直すことになる。棄却。
- **README を正とし、wiki はその展開にする**: README のセルの肥大と撤回の取り残しが解けない。棄却。
