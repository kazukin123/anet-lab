# TensorSpec に、値の尺度と stack 軸の 2 つの属性を持たせる

正規化の対象は dtype とクラス数から、stack 軸の有無は次元の数から推し量っていたので、float のまま正規化しないキー（Env が範囲を決めた値、one-hot）や、重ね済みかどうかを表せなかった（[PRD161](../memo/0161_observation_pipeline_10rfd.md)）。**`TensorSpec` に、値の尺度（尺度が決まっている／決まっていない。上下限があるかは表さない）と、stack 軸を持つかの 2 つの属性を足し、キーを作る側（Env、情報を足す部品）が宣言して、加工の部品が通したキーの属性を変える**ことを決定する。重ねるかどうかは形の選択なので設定に残し、属性はデータの状態だけを表す。

## Considered Options

- **値の種類を 4 つ（生の量・尺度つきの量・番号・符号）にする**: その区別を使う箇所が無い。却下。
- **加工ごとのフラグ（正規化しない、重ね済み）を持つ**: spec が加工の名前を知り、加工が増えるたびに欄が増える。却下。
- **設定のキーの一覧だけで外す**: 実装が足すキーを、設定に書き忘れると対象になる。却下。
