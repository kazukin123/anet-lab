# 設定継承は最終値の差分合成とし、個別指定をベースより優先する

[ADR 0040](0040-config-selection-final-value-and-run-profile-tier.md)は、選択元の最終値参照とRunの優先を定める一方、プロファイル・上書き層が運ぶ選択宣言をコピー先で差し替え、旧選択の葉を消す契約を採用した。その実装はドット無しの選択元を上書き層とみなし、Common等も宣言の在処で解決できない。継承を差分適用と読む利用者の意図とは一致しなかった。

`$`はその設定のベースを指定する。全体のベースより部分指定、部分指定より個別葉を強くし、異なるキーの行順で結果を変えない。各選択元の最終値を`A2 > A3`で重ねるときは右側の同名キーが勝ち、右側にない葉は由来によらず残す。同じ入力キー自体の再指定は従来の後勝ちとし、複数項の差分合成と区別する。

上書き層は利用者が差分として使う通常prefixであり、resolverの種類にはしない。名前リスト・ドット数・登録宣言で識別せず、Common自身の`.$`も通常の依存として扱う。葉の削除のための由来追跡は追加しない。

選択元の命令をコピー先で再実行せず、その最終値を継承する。短い`@b`は定義元で解決し、`Env.@a.$ = @b`は使用先がOtherでもEnv.@bを指す。解決記録もEnv.@a.$という定義位置を示す。JSONの構造・schema_version=1・run.$先頭は維持する。

## 維持する契約と移行

ADR 0040の最終値伝播、Run・CLIの同一キーへの優先、1段値参照、未選択プロファイルの休止、依存の検証は維持する。同ADRの直書きを弱くする順位、全体と部分の行順優先、上書き層の識別、宣言のコピー先実体化と削除、コピー先基準の相対参照・記録は本決定で置き換える。

弱い既定値として書いた通常キーは、新規則では強い個別指定になる。チェーン配下の弱い既定値は、現在の競合有無によらずチェーン先頭の通常`@defaults`へ移す。値が異なる24キーだけに限ると、同値・未競合の直書きが将来のE1／A2を押さえ込むため、全面移行を採用する。文字列表記・コメントと実験値を保持し、コピー先の既定葉と選択元の在庫を区別して棚卸しする。既存17入力の値一致を必須とし、解決記録・行順の変更は理由付きで確認する。旧goldenと採取条件は保持し、無断で上書きしない。

予約名による小修正と上書き層の明示登録は、分類を残すため採用しない。旧選択の葉を取り消す仕組みは、差分合成では消す必要がなくなったため採用しない。無関係な整形や互換モードは追加しない。

個別葉が継承値に勝った際の競合WARNは、P2が認める意図的な指定まで警告するため不採用とする。既定値の配置を移し、正当な上書きに診断を追加しない。

`@defaults`は予約名でも暗黙の継承機構でもない。通常設定・Run・bat・設定生成ツールがapp.$やbackend.$等を置き換える各経路に明示する。選択先が現在全キーを持つという条件には依存しない。CLIは指定したそのキーについて最優先であり、実効葉への指定とE1内の葉への指定は異なる。選択キーへのCLIはチェーンだけを置き換え、別キーの個別葉を上書きしない。

仕様・具体例・テスト改訂表・移行条件の正本は[PRD 072](../memo/072_config_selection_final_value_10prd.md)。
