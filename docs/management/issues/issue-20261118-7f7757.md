## 背景

2026-11-18 の定常整備の監査（観点 drift、範囲 docs/design/200_dqn_agents.jp.md）で、DQN 系の ADR が設計文書から参照されているか（入口の有無）を `adr/NNNN` の形で照合して見つかった。開発者には質問していない。設計文書 200 は直近 90 日の変更回数で上位（stats の churn90 で 2,320 ファイル中 13 位）なので、ホットスポット補正で urgency を 2 から 3 へ 1 段上げた。

## 事象

文書 200 の ADR リンクは 0010・0012・0013・0018・0019・0039 の 6 本だけ（767 行、848-852 行）。次の ADR は `docs/design/*.md` のどこからもリンクされていない。括弧は 200 で対応する節。

- 0001 TBO の適用範囲（§7.1）、0031 可塑性（§9.4）、0032 SN（§8.2 の 655 行）、0033 policy churn（§9.5）、0035 Munchausen（§6.3）
- 0036・0075 Q ヒントの列（§9.3 ほか）、0038 Actor カタログ（§6.1・§6.4）、0048 NoisyNet（§7.3。0051 は 130 からだけリンクあり）
- 0053 checkpoint の optimizer options（§8.2 の 647 行）、0054 GNS（§9.8）、0058 近似優先度の列（§6.2）
- 0062 skip の補助 Network（§6.5・§8.2）、0063 可変窓（§6.5）、0064 ProfiledValue の bare 値（247 行）、0065 予定された γ（275 行）
- 0073・0074 価値の分解（§9.10。設計文書 214 にも ADR リンクが無い）

## 影響

決定の理由と、あとで改訂された履歴に設計文書から入れない。0053 は WARN→INFO を ADR 0071 で改めた注記を持ち、0062 は split の注記を持つが、文書からは読めない。

## 対応方針

未定。監査の案は、§11.1 に節ごとの ADR を足す（0073・0074 は 214 側でもよい）。ADR 自身の後発注記の欠けは課題 [[issue-20261118-0fc0d7]] で扱う。
