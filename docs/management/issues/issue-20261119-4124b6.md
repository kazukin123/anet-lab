## 背景

[PRD182](../../memo/182_source_layout_10prd.md)（ソース配置の見直し）のグリルの調査（2026-11-17〜18）で見つかった。同書は挙動を変えないので、エラー文は直さない（同書 §2.2 に事実として書いた）。工程末の候補から開発者が選び、起票した。開発者への質問はしていない。

DQN の共通部品（`dqn_based_agent.*`）は、DefaultDQNAgent と RainbowAgent の両方が使う。RainbowAgent の設定の root は `RainbowAgent` である（`core/anet-core/include/anet/rainbow_agent.hpp` の 27 行）。

## 事象

- `core/anet-core/src/dqn_based_agent.cpp` の次の 4 か所が、エラー文に `DefaultDQNAgent.` で始まる設定キーを固定で書いている（2026-11-19 の行番号）。
  - 904 行: `Invalid DefaultDQNAgent.skip.network_mode=…`
  - 3212 行: `DefaultDQNAgent.learner.noisy_probe requires a resolved sample forward config.`
  - 3244 行: `DefaultDQNAgent.learner.final_feature_branch_key='' is required …`
  - 3248 行: `Unknown DefaultDQNAgent.learner.final_feature_branch_key=…`
- 共通部品のファイル（`dqn_based_agent.cpp`・`dqn_based_agent.hpp`・`dqn_based_heads.cpp`・`dqn_based_heads.hpp`）を `DefaultDQNAgent` で検索すると、当たるのはこの 4 行だけである。
- RainbowAgent がこの 4 つの経路に実際に入るかは、確かめていない。
- 2026-11-21 PRD194: 4 か所は、PRD182 のあと dqn_network_model.cpp の 110 行と、dqn_learner.cpp の 363・395・399 行にある。RainbowAgent から届くのは dqn_learner.cpp の 3 か所で、該当の診断指標を購読した Run に限る。RainbowAgent は、その 3 か所が指す設定を読まない。[PRD](../../memo/194_config_key_full_names_in_messages_10prd.md)

## 影響

RainbowAgent の設定の誤りでこのエラーが出ると、エラー文が、設定に無い `DefaultDQNAgent.…` のキーを指す。直すキーを探す手がかりが外れる。

PRD182 のステージ 3 は、共通部品が具象 Agent を知らないことを検索で確かめる（同書 §6 の S3-4）。その検査が見るのは、ヘッダの include と、ファイルの名前の形（`default_dqn_agent`・`rainbow_agent`）で、エラー文の中の `DefaultDQNAgent` は対象にならない。

## 対応方針

未定。案: 設定を読んだ側（具象 Agent）の root の名前を共通部品へ渡し、エラー文をその名前で組む。

## 対応内容

- 2026-11-21 PRD194: この課題を題材に PRD をグリルした。直し方は、共通部品が利用側の読み口の記録から完全キーを引き、利用側が読んでいない設定は相対キーにその旨を添えて書く形（D1・D4・D5・D24）。確かめ: PRD のレビューが OK。[PRD](../../memo/194_config_key_full_names_in_messages_10prd.md)
