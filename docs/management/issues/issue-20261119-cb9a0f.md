## 背景

2026-11-19 の会話で、開発者が、今の RND の実装を Burda らの論文（[arXiv 1810.12894](https://arxiv.org/abs/1810.12894)）と比べるよう求めた。AI は論文の §2.3・§2.4・§3.3〜3.5 と付録 A.2〜A.5（擬似コードと表 2〜5）を読み、設定で変えられる差と Run の規模の差を除いて、実装に無いか実装の作りが違う要素に絞った。そのうちの 1 つで、開発者が起票を指示した。開発者への質問はしていない。

[PRD123](../../memo/0123_rnd_intrinsic_reward_scale_10rfd.md) の §8 の U2 は、開き直す候補に「観測の正規化の式（除数の ε、乱数行動の前段）」を挙げていた。2026-11-15 に開発者が、warm-up を 200,000 件のまま変えず、観測の正規化の式と 2 ステージの warm-up も開き直さないと決めた（[issue-20261111-77ac3c](issue-20261111-77ac3c.md) の対応内容）。本課題は、論文との差として、この前段が実装に無いことを記録する。

## 事象

- 論文は、学習を始める前に、一様乱数の行動で M step だけ環境を回し、そのつど次観測で観測の正規化の統計を更新する（付録 A.2 の Algorithm 1）。§2.4 も、正規化の統計を "stepping a random agent in the environment" で初期化すると書く。
- anet にはこの前段が無い。whiten の warm-up（`intrinsic.rnd.warmup_mode = learn_predictor`、既定 12,800 件、Atari の `run.@rnd` は 200,000 件）の間は bonus を 0 にし、その間に Train Actor の方策で集めた観測で観測の統計を更新し、predictor も学習する（[212](../../design/212_rnd_lifelong_novelty.jp.md) §3.5）。
- 統計を作る観測を集める行動が、論文は一様乱数、anet は Train Actor の方策（lane ごとの ε など）である。論文の前段では predictor を学習せず、bonus を 0 にする期間も無い。

## 影響

- Burda らの形に寄せた比較では、学習の始めの観測の統計が、論文と違う行動の分布から作られる。論文に無い bonus 0 の期間も残る。
- Train Actor の方策が序盤から特定の場所に偏る構成では、warm-up の間の観測の統計がその偏りを含む。どれだけ結果に効くかは測っていない。

## 対応方針

未定。U2 で開き直さないと決めたので、論文の形との比較をするときに要否を決める。
