## 背景

台帳 F-0024 から移した（2026-11-03）。
観点: drift。分類: サンプル設定。確度: high。

## 事象

nn.txtのサンプルのbodyのうち、@ResNetは未定義のブロックを、@MLP_RESは未登録のtype（Composite）を使っており、どちらも選ぶと起動できない。

- apps/runner/config/nn.txt:241 @ResNetは定義の無いブロックLinear_128とMyReLUを参照する
- apps/runner/config/nn.txt:301 @MLP_RESが使う[ResBlock]のtypeが、登録の無いComposite
- core/anet-core/src/nn_impl.cpp:2575 未登録のtypeはUnknown module typeでANET_SYSTEM_ERRORになる

## 影響

サンプルを試すためにbodyとして@MLP_RESを選ぶ → [ResBlock]のtype=Compositeの解決でUnknown module typeになり、起動できない。@ResNetを選ぶと、未定義のブロック（Linear_128、MyReLU）の参照でエラーになる。

## 対応方針

サンプルを今の記法と登録済みのtypeで書き直すか、消す。
