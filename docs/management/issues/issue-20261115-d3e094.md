## 背景

anet の一生の新しさの推定器は RND だけである（[PRD116](../../memo/116_rnd_lifelong_novelty_10prd.md)、`RndNoveltyEstimator`）。RND の内的報酬の尺度と β は [PRD123](../../memo/123_rnd_intrinsic_reward_scale_10prd.md)（[issue-20261111-77ac3c](issue-20261111-77ac3c.md)）で評価を続けている。内的報酬と方策の組は [PRD173](../../memo/173_intrinsic_reward_novelty_10prd.md)（[issue-20261103-736e39](issue-20261103-736e39.md)）で扱う。

開発者が、RND の改良版として SND（Self-supervised Network Distillation）を見つけた。RND の評価が落ち着いたら対応を検討するために起票した（質問はしていない）。

## 事象

論文は Pecháč・Chovanec・Farkaš「Self-supervised network distillation: an effective approach to exploration in sparse reward environments」（[arXiv 2302.11563](https://arxiv.org/abs/2302.11563)、v1 は 2023-02-22、v4 は 2024-06-10）である。以下は v4 の HTML 版から読んだ。

- **RND との違い**：RND は target を乱数で初期化して固定し、predictor だけを target に合わせて学ぶ。SND は target も自己教師の損失で学ぶ。predictor が target に合わせる誤差を新しさにする点は同じで、論文は SND を RND の一般化と位置付ける。
- **3 つの変種**：
  - SND-V：状態の組を使う対照学習。ノイズ・タイルのマスク・ランダムな畳み込みでデータを拡張する。
  - SND-STD：ST-DIM に正則化の項を足したもの。
  - SND-VIC：VICReg を使い、2 つの view の代わりに連続する状態を使う。
- **学習器**：PPO を使う。critic は外的報酬と内的報酬の 2 つの Head を持ち、advantage の係数は外的 2.0・内的 1.0 である。
- **環境と回数**：Atari 6 本（Montezuma's Revenge、Gravitar、Venture、Private Eye、Pitfall、Solaris）と Procgen 4 本（Coinrun、Caveflyer、Jumper、Climber）。各 9 本を回し、Atari は 128M frame、Procgen は 64M frame、並列の環境は 128 である。
- **主張する結果**：
  - 外的報酬の平均で、最良の SND は 1 本を除く環境で RND を上回った。Venture は差が有意でなく、Pitfall はどの手法も 0 だった。
  - 最良の変種は環境ごとに違う。
  - Montezuma's Revenge の最初の面を終えたと述べる。
- **費用と限界**：
  - 内的報酬の尺度に敏感で、全体では 0.5 がよかった。
  - 変種ごとに損失の重みが増える。
  - SND-STD は特徴の空間が膨らみ続けて発散したので、正則化を足した。
  - target の初期値への頑健さは調べていない。
- **コード**：[Iskandor/SND](https://github.com/Iskandor/SND) と [michalnand/reinforcement_learning](https://github.com/michalnand/reinforcement_learning) が公開されている。

## 影響

- RND で探索が伸びない題材で、ほかの新しさの推定器と比べる手が無い。
  - LunarLander では bonus が採点 5〜10 万件で消えた。
  - Montezuma では Taiga らの式の RND が鍵より先へ進まなかった（[内的報酬による探索の比較](../../wiki/mechanisms/intrinsic_novelty.md)）。
- 論文が改善を主張する題材の Montezuma は、anet でも RND で回している題材である。

## 対応方針

RND の評価（PRD123 の β・warm-up など）が落ち着いてから、試すかを検討する。それまでは手を付けない。

- 2026-11-15 起票: 検討の材料は次のとおり。
  - RND との差は target を学ぶ点だけなので、`RndNoveltyEstimator` の target を自己教師の損失で更新する形で足せる見込みである。target を学ぶ分だけ、学習の計算は RND より増える。
  - 論文の結果は PPO と外的・内的の 2 Head の組のものである。anet は DQN 系で、外的・内的の 2 Head は [PRD121](../../memo/121_extrinsic_intrinsic_value_decomposition_10prd.md) で入れた。
  - 変種が 3 つあり、最良の変種が環境ごとに違うので、まず試す変種を選ぶ必要がある。たとえば SND-VIC は、データの拡張の代わりに連続する状態を使う。
  - 比べ方は、Montezuma で同じ構成の RND と並べる形が候補である。
