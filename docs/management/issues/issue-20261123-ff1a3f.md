## 背景

2026-11-23 の定常整備（anet-audit、観点 drift・範囲 CONTEXT.md）で見つけた。分類は ADR ずれ。直すのは文書だけと見立てた。工程の中で開発者に質問はしていない。

ホットスポット補正: 直す場所の `CONTEXT.md`（churn90 が 63）は、2026-11-18 の定点統計で全ファイルの上位 1% に入るので、`urgency` を 2 から 3 へ 1 段上げた。

## 事象

- [CONTEXT.md](../../../CONTEXT.md) 43 行は、target return を「実報酬の N-step 割引和。ReplayBuffer に保持される値」と書く。
- [ADR 0065](../../adr/0065-scheduled-gamma-recomputes-return-at-sample.md) は、γ が schedule のときは抽選時に保存済みの step 報酬から収益を作り直すと決め、[ADR 0073](../../adr/0073-replay-keeps-reward-components-and-builds-returns-per-component-discount.md) はそれを報酬の成分ごとに当てる。
- [150](../../design/150_replay_buffer.jp.md) の 62・273 行（`needs_return_recompute`・`FinalizeReturns`）も作り直す形である。
- 出荷の設定に γ の schedule は無い。

## 影響

割引率を時間で変える RFD をグリルするときに、用語集から「Push で確定する値」と読み、ADR 0065 が消した学習の target のずれ（保存時の γ と学習時の γ の 2 時点）を設計に戻すおそれがある。

## 対応方針

文書だけを直す見立て。「γ が定数の成分は Push で保存した値、schedule の成分は抽選時に保存済みの 1 step の報酬から作る値」と書く。

## 対応内容

- 2026-11-27 target return の定数割引と schedule 割引の扱いを ADR 0065・0073 に合わせた。 [RFD0205 実装メモ](../../memo/0205_design_doc_and_glossary_alignment_20impl.md)
