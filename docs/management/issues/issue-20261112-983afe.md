## 背景

KFM（kung_fu_master）では、1 階を左へ進み続けた先にボスがいる。RND の内的報酬（PRD116・PRD123）を足した Run を見た開発者が、2026-11-11 の会話で「ボスを叩くところが偶然だより」と指摘し、エピソード内の新しさで変わるか、ボスまで左へ進む行動を偶然に頼らず誘発できるかを問うた。その場で ALE を使って 1 階の画面を確かめ、案を挙げた。起票は 2026-11-12 の開発者の指示による。PRD173 の記述はまだ直していない。

## 事象

- PRD123 の新しい RND（warm-up 200,000、β 0.1）の KFM 10M（サブ機、seed 4、`run_20261111-141737_kfm_10m_r123_s04`）でも、ボスに当てたゲームは 10M までに 2 本で、撃破は 0 だった。同じ seed の RND なしは 11 本、旧い RND（β 0.1）は 345 本（0.5M 窓のピークで 45%）だった。
- ALE で自機を無敵にし（体力とタイマーを毎フレーム書き戻す）、1 階を左へ 1,500 step 歩かせて画面を記録した。
  - 人物以外の背景は 32 通りの模様の繰り返しだけだった。歩き始めと同じ背景が 489〜497・753〜761・800〜802 step に再び出た。
  - 画面の上部はタイマー・点・残機・体力バーで、階の中の位置を示すものは無い。
  - ボスが画面に入るまで（この歩き方で約 900 step）、新しい画面は出なかった。
- 以前の調査では、攻撃せずに歩くと約 250 フレームでやられた。

## 影響

- 廊下のどこにいても同じ画面なので、Q は廊下で 1 つの方策しか持てない。左へ寄るかは学習の偶然で決まる（見立て。未検証）。
- 一生の新しさ（RND）も、画面で測るエピソード内の新しさも、ボスまでの廊下ではボーナスを出せない。PRD173 の §1 ゴール 2 と §2.5 の「ボスへの道は毎ゲーム初めて見る画面なので、ボスに行かない Run にも効く」という前提は、上の事実と食い違う。
- 放置すると、内的報酬の比較（PRD123・PRD173）の KFM での効果が、ボスへ行き着く偶然に埋もれて読めない。

## 対応方針

未定。2026-11-11 の会話で挙げた候補（ゲームの知識、たとえば RAM の位置で報酬を足す形は使わない）:

- 見えるようにする
  - A1: エピソード内の行動ごとの回数を NN の入力に足す。PRD142 の観測パイプラインの段として置ける。安く作れ、ゲームの知識も要らない。掴まれている間や壁の前で押した LEFT も数えるので、左右の打ち消しは NN が学ぶ必要がある。
  - A2: 記憶を持つ NN（RNN・Transformer）で位置を推定する。重い。PRD173 §4.1 は別の軸として扱っている。
- 探索の的にする
  - B1: 一生の新しさ（RND）の入力に A1 を入れ、「これまでのゲームでここまで来たことがない」にボーナスを付ける。
  - B2: エピソード内の新しさの基準に A1 を入れる。累計は増える一方で毎 step が新しくなるので、効かない。
  - B3: εz-greedy（ランダムな行動を長く続ける）。左へ長く歩く確率が上がるだけ。
- 推しは A1＋B1。ただし、意味の無い珍しい行動の組み合わせ（しゃがみ続けるなど）にもボーナスが付く。クリップ後はボス撃破が雑魚 1 体と同じ +1 なので、行き着いても稼ぎに戻るおそれは残る（勝つ・続けるの壁は PRD173 §2.5・§2.6 と PRD121 が扱う）。
- PRD173 の再グリルで、§1 ゴール 2 と §2.5 の前提を直すか、この課題を別の PRD にするかを決める。
