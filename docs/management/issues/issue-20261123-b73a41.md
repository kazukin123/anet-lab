## 背景

2026-11-23 の定常整備（anet-audit、観点 process・範囲は全体）で、AGENTS.md の規約の守られ方を抜き取りで見た。2026-11-09 以後に変更した実験記録 22 本の本文から Run 名を拾い、同じ env の `config/` に同じタイムスタンプのファイルがあるかを数えた。Run 名の語で評価専用（`ev_` など）・`tmp` を除いたが、評価専用かを本文まで読んで確かめたのは下の 2 本だけである。工程の中で開発者に質問はしていない。

## 事象

- [AGENTS.md](../../../AGENTS.md) の「実験記録と実効 config の保存ルール」は、実験記録の本文に Run 名が出る学習 Run の実効 config を、`docs/experiments/<agent>/<env>/config/<Run フォルダ名>.txt` へ複製すると定める。評価専用 Run と `tmp` の Run は除く。タイミングは実験記録を更新するコミットと同じとする。
- [2026-11-11_kfm-rnd-error-scale.md](../../experiments/default-dqn/atari/2026-11-11_kfm-rnd-error-scale.md) は、10M の学習 Run を群ごとに seed s04〜s11 で挙げ、表のリンクは群ごとに s04 の config だけを指す。本文に名前の出る学習 Run のうち 13 本（`run_20261111-211711_kfm_10m_r123_s05`、`run_20261114-211458_kfm_10m_b003w1m_s07` ほか）の config が `docs/experiments/default-dqn/atari/config/` に無い。
- [2026-10-28_temporl-split-kmax-epsilon.md](../../experiments/default-dqn/lunarlander/2026-10-28_temporl-split-kmax-epsilon.md) は、本文に名前の出る学習 Run のうち 12 本（`run_20261026-020453_t98_ll_mrg_s1`、`run_20261028-132859_t103_ll_spl_s1` ほか）の config が `docs/experiments/default-dqn/lunarlander/config/` に無い。
- 同じ数え方で、22 本のうち 8 本の記録に、config の無い Run 名が合わせて 100 件出た（評価専用を語で除き切れていないものを含む）。
- KFM の記録の 13 本の Run は、このリポジトリの `data/workspaces/` の下に無い。
- 規約には、seed だけが違う Run を群の代表で済ませる例外は無い。

## 影響

`data/workspaces` は `.gitignore` 済みで、Run の artifact が消えると、その Run の実効設定を記録側から引けなくなる。seed のほかに違いがあったか（bat の引数の重ね合わせなど）を後で確かめられない。

## 対応方針

未定。足りない config を Run の置き場から複製する、または seed だけが違う Run を群の代表で済ませてよいと規約に書く、のどちらかを開発者が決める。
