## 背景

[RFD0202](../../memo/0202_wiki_accumulate_and_lookup_10rfd.md) で、wiki に `docs/wiki/summary/` を足し、材料 1 本に 1 ページのサマリを置く形にした。その実装の途中（ステージ 2。実験記録と報告の 94 本を取り込む）の 2026-11-26 の会話で、開発者が、サマリのページを人が確かめるための一覧がどこかで作られるかを尋ねた。RFD0202 は「サマリのページは目録に載せない」と決めていて（§8.11）、一覧を作るステージは無い。

開発者は「インデックスページだと限界があるので、Obsidian でよい感じに一覧を見られるようにしたい」「今の対応が終わってから改めてでよい」と述べ、課題として記録することを選んだ。

## 事象

- サマリのページに YAML ヘッダが無い。ページは `# 題名` で始まり、「元の材料」（リンクと blob）・「要点」・「内容」・「主要な概念」の節を本文に持つ（RFD0202 の S6）。2026-11-26 の時点で 94 本ある（`docs/wiki/summary/experiments/` に 49、`docs/wiki/summary/reports/` に 45）。
- 目録（`docs/wiki/index.md`）に、サマリのページへの行は無い。
- 課題記録は、YAML ヘッダに `title`・`status` などを持つ。
- Obsidian の一覧の仕組み（標準機能の Bases と、コミュニティのプラグインの Dataview）は、列を、YAML ヘッダのプロパティと、ファイルの属性（名前・フォルダ・更新日時・大きさ・リンク）から作る。この行は AI の記憶によるもので、試して確かめていない。
- Git が追跡するファイルに、Obsidian の一覧の定義（`.base`）は無い。

## 影響

- Obsidian でサマリを一覧にしても、列に出せるのは、ファイル名・フォルダ・更新日時・大きさ・リンクに限られる。題名（本文の見出しにある）、材料の日付（RFD と ADR はファイル名に無い）、要点、取り込んだ概念だけの列、材料が変わってサマリが古くなったかは、列にも絞り込みにも使えない。
- サマリは、RFD0202 のステージ 3 のあと 408 本になる見込みである。人が出来を確かめる手がかりは、フォルダと、作業の記録（`docs/wiki/log.md`）の `ingest` の行だけで、本数が増えるほど手間がかかる。

## 対応方針

未定。RFD0202 の実装（ステージ 3 まで）が終わってから扱う（開発者の発言、2026-11-26）。RFD0202 は、ステージ 2 の始まりからステージ 3 の終わりまで、wiki のページを書くのをステージの担当だけにしているので（§9.10）、それまでサマリのページの書式は変えない。

次は AI の案と材料で、決定ではない。

- サマリのページに YAML ヘッダを足し、題名・材料のパス・材料の日付・blob・主要な概念などを持たせる。題名・材料のパス・blob・概念のリンクは、今の本文とパスから機械的に取り出せるので、408 本がそろったあとでも道具で一括して足せる。要点の 1 行のように、本文から決まらない欄を入れるなら、書き足す作業が要る。
- 決めること: 本文の「元の材料」「主要な概念」の節と YAML の、どちらを正とするか（道具 `reports/tools/wiki_support.py` は、本文の blob を読んでサマリが古くなったことを見つける）。YAML の中のリンクの書き方（課題の `rfd` 欄と同じ `"[[ページ名]]"` の形でないと、Obsidian がリンクとして扱わない）。持たせる欄。一覧の定義を Git に入れるか。概念のページにも足すか。
- サマリの書式（RFD0202 の S6）を変えるので、RFD0202 の改訂か、別の RFD になる。「サマリのページは目録に載せない」（§8.11）は変えない。Obsidian の一覧は表示で、目録のページではないためである。
- 目録か `summary/` に一覧のページを置く案は、開発者が「インデックスページだと限界がある」と述べた。
- 2026-11-27 追記: [RFD0203](../../memo/0203_wiki_page_yaml_header_10rfd.md) のグリルで、サマリのページだけでなく、概念のページを含む wiki のページの全部に YAML ヘッダを付けると決めた（開発者の指示、2026-11-26）。上の「決めること」は RFD0203 の確定事項で決まった。
