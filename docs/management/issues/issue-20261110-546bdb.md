## 背景

PRD158 の実装確認で、追加した設定検査と既存の hidden 検査 `[prd103-config]` を同時に実行した際に見つかった。PRD158 の工程末で、新規課題として記録することを開発者が選んだ。指標名をどちらへ合わせるかという修正方針の判断は、まだ質問していない。

検査の起点となった契約は [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)。発見時の実行条件と結果は [PRD158 の実装記録](../../memo/158_eval_schedule_first_fire_20impl.md) の「旧 hidden 検査との同時実行」に残した。本件は PRD158 の初回発火の抑止・offset の変更とは別の既存の不整合で、PRD158 の残件には含めない。

## 事象

- [config_baseline_test.cpp](../../../src/core/base/src/config_baseline_test.cpp) の `PRD103 skip profiles expose greedy session and padded metric tags` は、`metrics.scalar.[50_agent_skip/19_primary_clip_ratio_ema]` が空でないことを断定する。
- [metrics_scalar.txt](../../../apps/runner/config/metrics_scalar.txt) の現用定義は `metrics.scalar.@skip : [50_agent_skip/19_skip_primary_clip_ratio_ema] ?= skip_primary_clip_ratio @learn $learn_step $update_result $ema` で、検査が要求する `19_primary_clip_ratio_ema` の定義はない。
- GridMaze・LunarLander・Atari・DropMerge の4環境で同じ断定が失敗した。同時実行は2テスト中 PRD158 が成功、PRD103 が失敗し、9867 assertions 中4件が失敗、終了コードは42だった。証跡は `.scratch/prd918/green-config-only.log` と `.scratch/prd918/prd103-config/` の解決結果。
- PRD158 で更新した schedule の断定は成功している。通常の既定スイートと `[shipped_config]` も成功しており、本件は hidden 検査を明示的に選んだときに表面化する。
- 2026-11-21 PRD194: 出荷定義の tag は群名と / を含めて 44 文字、テストの名前は 39 文字である。設計文書 140 の 431 行も、テストと同じ名前を書いている。出荷定義の名前は、実験記録の設定の写し 36 本にある。[PRD](../../memo/194_config_key_full_names_in_messages_10prd.md)

## 影響

既存の検証資材を使うと、発火スケジュールなどの変更と関係のない失敗が混ざり、設定移行の回帰判定を妨げる。検査の期待と出荷定義の食い違いを残すと、同じ検査を行うたびに切り分けが必要になる。

## 対応方針

PRD103 と現用の指標定義を照合し、期待キーと出荷定義をどちらへそろえるべきかを確認する。その結果に沿って検査または定義を直し、`[prd103-config]` の4環境の断定を通す。PRD158 の初回発火の抑止と offset の契約は変更しない。

確認コマンドは、リポジトリルートの PowerShell で次を使う。

```bash
$env:ANET_PRD158_OUTPUT = Join-Path (Get-Location) '.scratch/prd158/config-check'; $env:ANET_PRD103_OUTPUT = Join-Path (Get-Location) '.scratch/prd158/prd103-config'; & core\anet-core\bin\Debug\anet-core-test.exe '[prd158-config],[prd103-config]' > .scratch\prd158\green-config-only.log 2>&1
```

## 対応内容

- 2026-11-21 PRD194: この課題を題材に PRD をグリルした。直し方は、テストと設計文書を出荷定義の名前 19_skip_primary_clip_ratio_ema に合わせる形（D11）。確かめ: PRD のレビューが OK。[PRD](../../memo/194_config_key_full_names_in_messages_10prd.md)
