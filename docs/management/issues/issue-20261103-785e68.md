## 背景

anet-core の外（同じリポジトリの別ターゲット）で何を実装できるかを、拡張点ごとに 1 行で答えられるようにする。そのために、公開ヘッダと内部ヘッダの置き場の規約を 1 つ決め、今の配置をその規約に照らして表にし、ずれているところを最小限で直す。

## 事象

対応するPRD: [169_outside_core_extension_layout_10prd.md](../../memo/0169_outside_core_extension_layout_10rfd.md)
- 2026-11-21 監査で確認。[PRD169](../../memo/0169_outside_core_extension_layout_10rfd.md) 冒頭で全項目を PRD182 に統合。公開ヘッダの配置規約は AGENTS.md、Agent 登録口と NN Head の部品は [設計010 §4.3](../../design/010_framework_overview.jp.md) と現行ヘッダ、実装・検証は [PRD182 の記録](../../memo/0182_source_layout_20impl.md) で確認した。
- 2026-11-27 RFD0202 段 4: Agent の系統のライブラリ（DQN）は、基盤の公開ヘッダの部品（`anet/tensor_store.hpp` の `LaneTimeTensorStore`、`anet/stacker.hpp`、`anet/tensor_util.hpp`、`anet/transfer.hpp`、`anet/scaler.hpp`）を使う（`src/algo/dqn/src/default_dqn_agent.cpp` の include と `IntrinsicLearnRolloutBatcher`、`dqn_actor.hpp`・`dqn_learner.hpp` の include）。これらは設計文書 010 §4.3 の拡張点の表に無く、公開ヘッダに置くものを「拡張点の interface・部品・登録口」とする決まり（AGENTS.md の基本方針、RFD0182 §5.6）に当たるかは、文書から決まらない（過去の質問 Q28 を書くときに見つけた）。[出典](../../memo/0202_wiki_accumulate_and_lookup_22impl.md)
