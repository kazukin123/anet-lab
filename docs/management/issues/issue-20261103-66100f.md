## 背景

台帳 F-0042 から移した（2026-11-03）。
観点: drift。分類: 死にキー。確度: high。

## 事象

設定ファイルがmarginをmerginと綴っているため、書いた値が読まれず、既定値で動いている。

- apps/runner/config/common.txt:75 mergin_x・mergin_yと書いている
- apps/runner/config/metrics_image.txt:96 image.@conv2d側も同じ綴り
- apps/runner/src/Conv2dPanel.cpp:22 読む側はconv2d.margin_x

## 影響

Conv2dPanelや画像メトリクスの余白を設定で変えても効かない。設定の値と実際の表示が食い違う。

## 対応方針

設定ファイルのmerginをmarginに直し、値が効くことを確かめる

2026-11-07 追記: [PRD117](../../memo/117_warn_policy_and_unread_config_10prd.md)（暫定）の受入（正常な Run の WARN を 0 件にすること、D2）は、この綴りの直しに依存する。PRD117 の「読まれない葉の一覧」（D3(b)）と、遅れて作る panel の設定を構築時に読む決まり（D5）を入れると、`Conv2dPanel.conv2d.mergin_x`・`mergin_y` が毎回の Run で一覧に出るため（PRD117 §10）。この課題を PRD117 に取り込む（親を索引の [issue-20261107-c17068](issue-20261107-c17068.md) にする）かは、PRD117 §9 の 14 で決める。
