## 背景

ImageCls は、Food-101 をスクラッチから学習する題材として、データ拡張・GAP・Mixup/CutMix・cosine・BF16 などを順に入れてきた（[wiki の ImageCls](../../wiki/concepts/subjects/imagecls.md)、[実験記録](../../experiments/image-cls/imagecls/2026-06-25_food101-scratch.md)）。

開発者の TODO メモの「直近」の項に「Food101以外のデータセット対応」が残っていた。開発者がこれを課題として起票するよう指示した。例として CIFAR-100 と ImageNet を挙げ、優先度は低いと述べた。この起票では質問をしていない。

## 事象

- ImageCls の Run は、Food-101 だけで回している。設定は、学習と評価のデータセットの key を `food101_train`・`food101_eval` にしている（[ImageCls.txt](../../../apps/runner/config/ImageCls.txt) の 620〜648 行）。
- データセットの読み込み（`ImageDataset`）は、catalog の設定で 1 つのデータセットを決める。設定キーは `root_dir`・`classes_txt_path`・`list_txt_path`・`suffix`・`image_width`・`image_height` である（[ImageData.cpp](../../../src/env/imagecls/src/ImageData.cpp) の 170〜204 行）。
  - リストの 1 行は「クラス名/ファイル名」で、最初の `/` の前をクラス名として `classes.txt` の順の番号に引く（同 129〜146 行）。Food-101 の `meta` の形である。
  - 画像は 1 枚ずつのファイルを wxImage で読み、設定の大きさへ縮めて `[3,H,W]` の uint8 にする（同 394〜412 行）。
  - クラス数は `classes.txt` の行数で決まる（[ImageClsEnv.cpp:87](../../../src/env/imagecls/src/ImageClsEnv.cpp)）。
  - この形に合う置き方（クラス名のフォルダの画像、リスト、`classes.txt`）なら、ほかのデータセットも catalog の設定を足すだけで読める作りである。試したことは無い。
- ImageCls.txt の Body は 224×224 の入力に合わせてある。ConvNeXt の stem の注記は 224 → 112 を前提にし（同 218・221 行）、ResNet18ish_hr は最終の解像度を 14×14 にする形である（[wiki の ImageCls](../../wiki/concepts/subjects/imagecls.md)）。
- 公開の配布物の形:
  - CIFAR-100 は 32×32・100 クラス（train 50,000、test 10,000）で、1 枚ずつの画像ファイルではなく、まとめたバイナリ（Python 版・バイナリ版）で配られる。
  - ImageNet（ILSVRC2012）は 1,000 クラスで、train 約 128 万枚はクラスごとのフォルダに入る。val 50,000 枚は 1 つのフォルダに入り、ラベルは別のファイルで配られる。
- Food-101 の train でも、メモリが厳しいので画像の cache を切り、都度デコードしている（ImageCls.txt の 628〜629 行）。

## 影響

- ImageCls の手法の知見（Body の比較、拡張・Mixup・cosine の効き方）が Food-101 の 1 つに閉じ、ほかのデータセットで同じ傾向かを確かめられない。
- 公表値の多い CIFAR-100 や ImageNet の到達点と、anet の実装の成績を並べて比べられない。
- 小さなデータセット（CIFAR-100）で手早く試す道が無く、試しにも Food-101 の Run の実時間がかかる。

## 対応方針

未定。

- 今の catalog の形に合わせて変換するだけで足りるかを、データセットごとに確かめる。CIFAR-100 は画像ファイルとリストへ書き出す道具、ImageNet は train のリストと、val をクラスのフォルダへ分けるかリストを作る道具が候補になる。変換で足りなければ、読み込みの形（バイナリ・ラベルのファイル）を足す。
- 32×32 の入力に合う Body と拡張の設定を ImageCls.txt に足す。
- ImageNet は、デコードの速さとメモリ（cache）の見積もりを先に行う。
