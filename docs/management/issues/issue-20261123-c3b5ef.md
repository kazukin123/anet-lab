## 背景

2026-11-23 の定常整備（anet-audit、観点 architecture・範囲 318_rl_core）で見つけた。観点は同じ規則の写しと浅い公開の口で、変更のまとまりとテストのしやすさが付随する。工程の中で開発者に質問はしていない。

ホットスポット補正: 直す場所の `replay_buffer_impl.cpp`（churn90 が 16）は、2026-11-18 の定点統計でコードのファイルの上位 5%（churn90 が 15 以上）に入るので、`urgency` を 3 から 5 へ 1 段上げた。

## 事象

- Replay 側: `ProcessQueue`（[replay_buffer_impl.cpp](../../../src/core/base/src/replay_buffer_impl.cpp) 1685〜1704 行）が、割引を `pow(gammas.front(), n)`、成分ごとに `pow(gammas[c], n)` で作る。`InitialPriorityCompleter::CompleteReady`（364〜469 行）が n 先を待ち（423〜428 行）、hint を `ValidateHint` で確かめ（404・429 行）、`Estimate` を呼ぶ（441〜450 行）。
- DQN 側: `DqnAgentStepDiagnosticsProvider::Observe`（`src/algo/dqn/src/dqn_assembler.cpp` 105〜237 行）が、公開ヘッダ replay_experience.hpp の queue・controller・builder を使い、`QueueRecord` の time_idx と logical_time_idx に lane の step を入れ（218 行）、自前の pending で n 先を待ち（209〜216 行）、割引を作り（184〜192 行）、`Estimate` を呼ぶ（187〜196 行）。`ValidateHint` は呼ばない。
- 2 つが一致することは、テスト用の口 `anet::test::CompleteReferenceInitialPriority`（`src/core/base/src_testing/replay.cpp` 23〜49 行。Replay の内部型を組み立てる）で確かめる。ただし、それを呼ぶ dqn_concrete_test.cpp 3391〜3405 行は、収益と割引を自分で計算して渡している。
- ADR 0058 が共有すると決めたのは、n step の組み立てと推定器までである。
- hint が非有限のときの扱いが、2 つで違う（Replay は `ValidateHint` を通す、step 診断は通さない）。

## 影響

SMDP（issue-20261103-124da5、RFD0167）で Replay の bootstrap の割引を経過時間の積に変えると、step 診断の 184〜192 行も直す必要がある。テストは割引を自分で計算して渡すので、片方だけ直しても通り、Evaluation Trace の approx_priority の列が Replay の初期優先度と黙って食い違う。n-step の目標値の補正（issue-20261103-75b8da）と、内的の価値を非エピソードにするときの n-step の区切り（issue-20261119-497fce）も同じ規則に触れる。

## 対応方針

「確定した系列と開始の hint から、n 先の hint を待って Estimate の入力を作る」部分を replay_experience.hpp の公開の部品にし、Replay と step 診断の両方がそれを使う。mode・fallback・source・counter は Completer に残し、ADR 0012 が退けた「completion を判断だけにして適用を Facade に戻す」形にはしない。テスト用の口 `CompleteReferenceInitialPriority` は部品の口のテストに置き換えて消す。Replay の Push の経路に触るので、perf-neutral と同 seed の再現性を確かめる（性能の区分は中立の見込み）。確かめは、トピック別まとめの「変えるときの条件」の RFD0094 §4.2 D6・D7・§8 の 3（actor_approx の checksum を一致させ、通知の時機を変えない）、RFD0078 6.2（公開 API・item key・抽選の分布・ready の基準を変えない）、RFD0121 §8.2・§9.2 の 2（成分が 1 つなら今と同じ）による。
