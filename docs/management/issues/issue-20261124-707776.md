## 背景

2026-11-24、開発者が、AGENTS.md を整理し、最終的には状況別にファイルを分けて必要な内容だけを見るようにしたいと述べた。同じ会話で、節を「いつ要るか」の 4 群（毎回守ること・設計と契約を変えるとき・ビルドと検証・Run と実験）の順に並べ替えた（段階 1）。ファイルの分割（段階 2）は、開発者の選択で暫定 RFD として起票した（[RFD0199](../../memo/0199_agents_md_split_by_situation_10rfd.md)）。起票の時点で、開発者に質問はしていない。

## 事象

- AGENTS.md は 28 節・770 行・75,769 バイトあり、Claude Code は CLAUDE.md の指示で、Codex も毎回、全文を読む（[RFD0199](../../memo/0199_agents_md_split_by_situation_10rfd.md) §1.1・§5.1）。
- ビルドと検証（6,170 バイト）、Run と実験（14,487 バイト）、コミットメッセージの書き方と Topic の表（6,246 バイト）は、その状況に入ったときだけ要る決まりだが、毎回の読み込みに入っている（同 §5.1）。

- 2026-11-28 監査（test-gap）: 現行の [AGENTS.md](../../../AGENTS.md) には「ビルドと検証」「Run と実験」の本文と、コミットメッセージの規約が引き続き同居している。

## 影響

- どの会話でも、使わない決まりの分だけ文脈を使う。
- 決まりを足すたびに、毎回読む量が増える。

## 対応方針

[RFD0199](../../memo/0199_agents_md_split_by_situation_10rfd.md)（暫定）の再グリルで決める。
