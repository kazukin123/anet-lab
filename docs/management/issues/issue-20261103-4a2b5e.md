- 2026-11-11 リファクタリング候補の抽出: PRD937 の題材の Head に、次の写しがある。(1) 分布の表し方 3 種と Dueling の有無の組を、6 つの Head クラス（dqn_based_heads.cpp:171、229、345、429、572、659）と 6 つの Factory（dqn_based_heads.hpp:26、50、57、66、75、82）で書き分けている。コンストラクタの骨格が 6 クラスに同じ順で並び、Dueling の合成 `v + (a - a.mean(...))` は 6 か所にあり、Dueling の 3 つの Factory の `CreateHead` は value_feature と adv_feature の同じ解決を書く。同じファイルの SkipHead は、同じ軸を 1 クラスの中の分岐で表している。(2) 各 Head の `GetTensorDictFunction` は、同じ意味のキーを 2〜3 個ずつ受け（キーの条件 16 行、ラムダ 16 個）、Dueling と Quantile 系のラムダは Forward と同じ射影と合成を書き直している。(3) nn_heads.cpp の PassThroughHead と LinearHead も、Forward とラムダが同じ本体を別々に書き、キーが無いときの例外が入口によって違う（`At` と `GetOrFail`）。PRD937 の本文は `GetTensorDictFunction` のラムダに触れていないので、実装で拾うなら PRD の改訂が要る。確かめ: クラスと Factory の位置を今のコードで確かめた。
