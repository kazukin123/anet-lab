## 背景

[RFD0195](../../memo/0195_document_term_rfd_and_4digit_numbers_10rfd.md)（文書の呼び名を RFD に改め、番号を 4 桁にする）の実装で、2 回のコミットを当てた使い捨ての clone で受入を確かめたところ、A2・A3・A5・A13 を満たさなかった。残ったものは、RFD0195 の範囲（名前と番号の形）の外のものか、P4・D15 で名前を残すと決めたもの（Run のフォルダ、ADR など）を指す行で、受入の条件にそれらを許す種類が無い。[実装記録](../../memo/0195_document_term_rfd_and_4digit_numbers_20impl.md)の「検証の結果」に判定を書き、工程末に起票の候補として示し、開発者が起票を選んだ。

## 事象

- A2: [memo README](../../memo/README.md) の「リンクの注意」のリンク切れ検査が何も出さないことを求めるが、実装の前から 268 件のリンク切れがあり、実装のあとも 258 件残る（[issue-20261123-98baff](issue-20261123-98baff.md)）。リンクの丸括弧の中に `prd` が残るのは、A1 の 51 本（ADR 3 本、実験記録 38 本、Run の設定の写し 10 本）を指すものと、保管場所の実装計画の中で追跡していないビルド出力（`apps/metrics-viewer/target/prd089-validation/`・`out/test-tmp/prd069/`）を指す 17 本である。
- A3: 現用の検索で 470 行が残る。受入の (a)〜(f) の種類に当たらないのは、名前を残すファイル（A1 の 51 本）を指すリンクのパスと過去の Run 名の 3 行と、走行中で当てられなかった 12 番の bat の 11 行である。12 番の bat の行は、bat が終わってから当てると 0 になる。
- A5: 56 行が残る。許す種類に当たらないのは、名前を残す ADR を指すリンクと ADR の名前の 9 行と、過去の Run 名の 1 行である。A5 の検索はリンクの丸括弧の中も拾うので、A2 が許す ADR へのリンクも挙がる。
- A13: リンク切れ検査が空でないこと（A2 と同じ）で満たさない。
- いずれも 2026-11-23 の使い捨ての clone（`9183b046` → 1 回目 `242e083b` → 2 回目 `5edc774a`）での結果。

## 影響

- 範囲どおりに実装しても受入の判定が「満たさない」のまま残り、[issue-20261121-529662](issue-20261121-529662.md) の判定を残件無しにできない。
- 実リポジトリで 2 回コミットしたあとに受入を確かめ直しても、同じ行が挙がる。

未定。
