## 背景

- anet-lab のレビューは anet-review で出す。Claude Code では `anet-review-agent` のサブエージェント、Codex では同名のエージェントを呼ぶ。手順はどちらも「レビューエージェントを呼ぶときに、モデルを指定しない」と定める。
- これとは別に、開発者の個人の設定で、同じ依頼を Claude と Codex の両方に出す 2 モデルのクロスレビュー（cc-review）を試している。Claude Code 版は `~/.claude/skills/cc-review/`、Codex 版は `~/.agents/skills/cc-review/` にあり、リポジトリには入っていない。Claude 側は `.scratch/cc_review/cc_review.py`、Codex 側はアプリ同梱の `codex.exe`（読み取り専用）で呼ぶ。
- 2026-11-22 に、開発者の「指定するのが面倒なので、使えるときは聞かずにクロスレビュー」を受け、個人の `~/.claude/CLAUDE.md` と `~/.codex/AGENTS.md` に、レビューの場面を cc-review へ回す節を足した。使える条件は、スクリプトと API キーのファイルがあることと、API のプロモーションのクレジットの期限（2026-11-27 9:00）より前であることだった。
- 本課題は、2026-11-23 の会話で切り替えを何度か行ったあと、開発者が「ハーネスをまたぐレビューを使うか使わないか、クロスレビューで API とサブスクのどちらの枠を使うか、どのモデルを使うかなどを、設定で切り替える仕組みが必要そう」と述べ、起票を指示したもの。

## 事象

- 2026-11-23、API のクレジットが期限の前に尽き、Claude 側が `Credit balance is too low` で失敗した。使える条件は日付とファイルの有無だけを見ていたので、尽きたあとも条件を満たし続け、レビューのたびに Claude 側が失敗して Codex 側だけで進んだ（RFD0195 の実装のレビューでは 8 往復）。
- 自動の切り替えを止めるのに、`~/.claude/CLAUDE.md` と `~/.codex/AGENTS.md` の節を消し、Claude Code 版スキルの説明・使える条件の節・工程の中から使うときの節と、両方のスキルの課金先の説明を書き換えた。
- 同じ日に、Claude 側の課金先を API からサブスクの枠へ替えた。`cc_review.py` の呼び先を Agent SDK（API キー）から `claude -p`（Claude Code 本体のヘッドレス実行、claude.ai のログイン）へ書き換え、API の経路は `--api` を付けたときだけにした。合わせて、両方のスキルと README の課金先・失敗時の案内を書き直した。どちらで呼ぶかは、スキルの文面（「`--api` はユーザーが言ったときだけ」）で決まっている。
- モデルは経路ごとに別の場所で決まっている。通常の anet-review は指定しない（呼び出し元の既定）。cc-review の Claude 側は `cc_review.py` の既定（`claude-fable-5-2`）、Codex 側はアプリの既定である。変えられる口は `cc_review.py` の `--model` だけである。
- 自動の切り替え（個人の CLAUDE.md・AGENTS.md の節）は、2026-11-23 の時点で外したままになっている。

## 影響

- 課金の事情（API のクレジットの付与と枯渇、サブスクの 5 時間・週の枠のリセット）が変わるたびに、複数のファイルの文面を書き換える手間がかかる。書き換え漏れがあると、スキルどうしやスキルと README の説明が食い違う。
- 使える条件が残高や枠の実態を見ないので、尽きた経路を毎回試して失敗するか、気づかないまま購入した API 残高から引かれる。
- どのモデルでレビューしたかが経路ごとの既定で決まるので、レビューの結果を比べるときに条件が揃っているかを確かめにくい。

## 対応方針

未定。

- 2026-11-23 会話: 案として、レビューの出し方（クロスレビューを使うか、Claude 側の課金先（サブスク／API）、各側のモデル）を 1 か所の設定にまとめ、anet-review と工程の中のレビューがそれを読んで呼び分ける形がある。課金先やアカウントの事情は開発者ごとに違うので、個人の設定とリポジトリの手順をどう分けるかを先に決める。2 モデルのクロスレビュー自体をリポジトリの手順（anet-review の「3. 呼ぶ」）に入れるかも、合わせて決める。
