## 背景

2026-11-23 の定常整備（anet-audit、観点 drift・範囲 CONTEXT.md）で見つけた。分類は文書 stale・用語ずれ・死にキー。コードは RFD0116・RFD0121 と設計 200・212 のとおりで、直すのは文書だけと見立てた。工程の中で開発者に質問はしていない。

ホットスポット補正: 直す場所の `CONTEXT.md`（churn90 が 63）は、2026-11-18 の定点統計で全ファイルの上位 1% に入るので、`urgency` を 2 から 3 へ 1 段上げた。

## 事象

- [CONTEXT.md](../../../CONTEXT.md) 518〜524 行は、Agent checkpoint の DefaultDQN の中身を「header、保存時の Config 文字列、online/target Network、optimizer」とし、「Run 全体（Replay、step、RNG）は含まない」と書く。checkpoint 引き継ぎは「Network と optimizer を読み込む操作。Replay・step・RNG は新しい Run のもの」と書く。
- `src/algo/dqn/src/default_dqn_agent.cpp` の `DefaultDQNAgent::Save`（675 行から）は、Network と Learner のあとに `intrinsic_->Save` を書く。中身は RND 本体、補助学習の credit、lane の抽選の乱数（mt19937_64 の状態）、成功回数、内的報酬スケーラである（304〜319 行）。拡張形式では外的の報酬スケーラも書き、Load（321〜345 行）で戻す。
- [200](../../design/200_dqn_agents.jp.md) の 645〜652 行の注記は「動的RewardScalerとRND専用統計は保存する」と書き、654 行は「NetworkとOptimizerを引き継ぐ操作」のままである。[212](../../design/212_rnd_lifelong_novelty.jp.md) の 408 行は、credit・抽選の乱数・成功回数・内的報酬スケーラを復元すると書く。
- 用語集が checkpoint 引き継ぎの避ける語とする「再開」を、212 §9.7 の見出し「保存と再開」（404 行。200 の 635 行からアンカーで参照）と、212 の 228・269・408 行、200 の 173・816 行が使う。
- [020](../../design/020_user_guide_run.jp.md) §6.4（534 行）は、引き継ぎの現行例を「`DefaultDQNAgent.auto_load_file` の alias である `R.auto_load_file`」と案内する。R は用語集で旧名とされた上書き層で（CONTEXT.md 292 行）、出荷の設定の選択チェーンは `... > A2 > A3`（DropMerge.txt 21 行）、bat は `A3.auto_load_file`（apps/11_batch_run.bat 121 行ほか）を使う。

## 影響

RND を有効にした Run を `auto_load_file` で引き継ぐとき、用語集を読んだ人と AI は、一生の新しさの統計・スケーラ・補助学習の抽選が 0 から始まると見立て、継続した Run の内的報酬を読み違える。020 のとおりに `R.auto_load_file` を書くと、読まれない設定キーの WARN が出るだけで、重みを読まずに Run が始まる。

## 対応方針

文書だけを直す見立て。CONTEXT.md の 2 語に、RND とそのスケーラ、動的な報酬スケーラ、補助学習の抽選の乱数を含むことを足し、含まないものを Replay・step・Actor と Replay の乱数と書き直す。212 の「再開」を「引き継ぎ」にし、200 の 635 行のアンカーも合わせる。200 の 654 行を直す。020 の 534 行は `A3.auto_load_file`（または完全キー）にする。観測の正規化の統計を保存する仕事（issue-20261113-b96b2c）が入ると、列挙がまた変わる。

## 対応内容

- 2026-11-27 checkpoint の保存・引き継ぎを用語集と設計 020・200・212 で統一し、保存処理と 212 へのアンカーを照合した。 [RFD0205 実装メモ](../../memo/0205_design_doc_and_glossary_alignment_20impl.md)
