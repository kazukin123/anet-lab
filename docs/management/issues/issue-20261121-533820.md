## 背景

サブ機で、Taiga ら（Rainbow＋RND）との差を調べる一環として、Breakout で anet の IQN を Dopamine の IQN の公開値と比べている。padding（ステージ 55・58）と τ を混ぜる位置（ステージ 56）は効かず、全層の初期値を torch の既定にしたステージ 59 だけが、同じ seed のステージ 57 より it 15〜19 の平均で 30 高かった。2026-11-21 の会話で、開発者が、Dopamine と同じ幅の初期化を先に実装して流れで確かめたいとし、課題と暫定の PRD の起票を指示した。

## 事象

- Dopamine（e7d780d）の IQN と Rainbow の Network は、conv 3 層・τ の射影・Linear 512・出力のすべての重みを VarianceScaling(scale=1/√3, mode=fan_in, distribution=uniform) で初期化し、bias は 0 である。重みの分散は 0.577/fan_in になる。
- anet の初期化方式（`default`・`xavier`・`he`・`orthogonal`・`constant`・`trunc_normal`）では、この初期値を作れない。`default`（torch の既定）は重みの分散が 1/(3·fan_in)（標準偏差は Dopamine の 0.76 倍）で、bias も一様乱数のまま残る。`he` は正規分布の fan_out、`xavier` は fan_in と fan_out の両方を使う。
- Breakout の学習側の it 15〜19 の平均は、ステージ 59（torch の既定）89.6、ステージ 57（he・xavier）59.6、Dopamine の IQN の 5 本 119.7〜177.3。seed だけが違うステージ 50 とステージ 57 の差は 10.7 だった。

## 影響

- Breakout で Dopamine の IQN に残る差が初期値の幅によるものかを確かめられず、Taiga らとの比較（Q 側の確かめ）が初期値の所で止まる。
- Dopamine に寄せた構成（`run.@rainbow_like` など）を、Dopamine と同じ初期値で流せない。

## 対応方針

PRD193 で、分散を倍率÷fan_in にする一様分布の初期化方式と、その倍率の設定キーを足す（暫定）。実装のあと、サブ機でステージ 57 と同じ構成・seed 2 に全層の初期値を Dopamine と同じにした Run を流し、ステージ 59 と並べる。

## 対応内容

- 2026-11-21 PRD193: グリルで暫定の印を外した。方式は `variance_scaling`、倍率は設定キー `variance_scale`（分散の倍率、既定 1.0）、形は fan_in・一様分布・bias 0 に決めた。受入は、Dopamine と同じ初期値の Breakout の Run を流せることの確認までとし、5M の Run の段取りと読みは Atari の枠で行う。初期化の設定の読み取りを 1 つの口にまとめる分は、別の課題で覆う。確かめ: PRD のレビューが 2 往復目で OK。[PRD](../../memo/0193_variance_scaling_weight_init_10rfd.md)

- 2026-11-21 PRD193 実装: `variance_scaling` を追加し、fan_in に応じた一様分布と bias 0 を設定から指定できるようにした。確かめ: Linear と Conv2d を両倍率で検証し、グループ畳み込みでも分布が一致した。重みの型で扱えない半幅を診断付きで拒否し、出荷設定テストも通過した。従来方式の LunarLander と Breakout は scalar が前後一致し、Dopamine 倍率の Breakout は30,000 exp stepで正常終了して設定12行を確認した。[実装記録](../../memo/0193_variance_scaling_weight_init_20impl.md)
