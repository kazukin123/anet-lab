## 背景

PRD127（Evaluation Trace の内的報酬列）の §2.4・D4・§8 で、既存の EvalPanel の同期が UI スレッドから学習のロックを取ることを、同期全体を見直す別課題の候補にした。2026-11-13、開発者が候補3「EvalPanel の同期で UI が学習を待つ問題」だけを起票するよう指示した。

実装の規約は、UI スレッドから学習が更新中に保持するロックを取らず、学習側で用意した写しや公開値を通して読むことを基本としている。既存のモデル同期はこの規約より前からあり、PRD127では、network と同じ時点の RND 推定器・β を同じ同期の中で写すことを、開発者が承認した例外として維持した。本課題はこの同期全体を対象とする。

[issue-20261111-15ba39](issue-20261111-15ba39.md) は、同期 mode の文字列の再解釈や pane の active_ の問い合わせを整理する課題である。本課題の学習ロック待ちとは原因と直す範囲が異なり、独立に扱う。

## 事象

- `apps/runner/src/EvalPanel.cpp` の `OnTimer` からモデル同期へ進み、`SyncModel`（239行付近）が UI スレッドで `runner_->Sync(source_counts)` を呼ぶ。標準の time モードは10秒間隔である。
- `core/anet-core/src/trainer.cpp` の `EvalRunner::Sync`（250行付近）から Actor を同期する。DQN Actor の `CopySourceNetwork`（`dqn_based_agent.cpp` の2364行付近）は、Learner と同じ Agent mutex の読み取りロックを取って network と skip network を写す。学習側が書き込みロックを保持していれば、この取得は待つ構造である。
- PRD127の内的報酬列を要求している間は、このロックの中で `ActorSyncFollower` も呼び、診断部品が RND 推定器と直近の β を写す（`default_dqn_agent.cpp` の `IntrinsicSnapshot::OnActorSync` と `CreateStepDiagnosticsProvider`）。
- Trace を開いたときに推定器の写しが無ければ、同じ `EvalPanel::SyncModel` を前倒しで1回呼ぶ。通常の周期同期に加えて、pane を開く操作も学習ロックを待ち得る。
- 本起票では構造をコードとPRDへ照合した。UI の停止時間・頻度、同期中の複製時間の定量測定は行っていない。

## 影響

- 学習更新に時間がかかる構成では、同期のロック待ちと複製の間、同じ UI スレッドで処理する画面の更新やメニューなどの操作応答が遅れ得る。
- 同期の読み取りロックを保持して写している間は、学習側の書き込みも待つ。RND の列を使う場合は推定器と β の複製もこの区間に含まれる。
- RND だけを別の仕組みへ移すと、network 側の UI の待ちが残り、同じ行の Q と内的報酬の時点もずれ得るため、一式として扱う必要がある。

## 対応方針

具体的な方式は未定。UI が学習の可変状態をロックして読み出す同期全体を見直す。学習側などで一式の写しを用意して渡す方式を含め、実行スレッド・所有者・公開の時点と寿命を設計する。

設計と受入では、次を保つ。

- 学習が書き込みロックを保持している間も、同期の要求によって UI がそのロックを待たないこと。
- primary network・skip network・RND 推定器・β の写しの時点を揃え、同期元の step を時間依存値の評価へ渡す現行の契約を保つこと。
- 学習の停止後と `learner.enabled=false` の評価専用 Run でも同期できること。
- 同じ Actor の `MakeAction` と `Sync` を並行に呼ばない契約、および診断部品の休止・再開・破棄時の寿命を守ること。
- Trace 再表示後の最初の行、過去の行の不変性、同期の周期を回帰で確認すること。

PRD127の Atari の2構成での費用測定と既定3列の採否（U1）は、[issue-20261107-1226e5](issue-20261107-1226e5.md) に残している。本課題の同期全体の見直しとは分ける。

起票時の見立ては、操作応答への効果5、期日のない改善として緊急性3、既定で有効な同期を守るリスク5、スレッド・寿命・同期契約の設計が必要な手間8とした。WSJFは `(5 + 3 + 5) / 8 = 1.625` を小数1桁へ丸めた1.6である。
