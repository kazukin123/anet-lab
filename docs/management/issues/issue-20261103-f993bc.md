## 対応内容

- 2026-11-11 リファクタリング候補の抽出: PRD936 の題材の AMP まわりに、次の写しと名残がある。(1) 「Autocast を切り、入力を FP32 にして forward する」が 4 つの module に別々に書かれている（nn_modules.cpp の LinearModule の RunForward（562 付近、`std::optional<anet::Autocast>` の形）、BatchNorm2dModule（1120）、LayerNorm2dModule（1192）、LayerNormModule（1968）。3 つの norm は `if (force_fp32_)` で早く返す形で、書き方が 2 通りある）。初回の dtype の選び方も 3 か所に写されている。(2) GradScaler に呼ばれない口と、同じことを表す 2 つの状態がある。2 引数の `Step(optimizer, found_inf)`（nn_util.cpp:371）と `Update` の引数 `found_inf_override`（383）を使う呼び出しは無く、非有限の検出結果を `found_inf_tensor_` と `found_inf_` の 2 つで持つ。2 引数の Step のコメントは、そこに無い検査を説明している。PRD936 の本文がこれらに触れているかは確かめていないので、実装で拾うなら PRD の改訂が要るかを確かめる。確かめ: 4 か所の Autocast と GradScaler の関数の位置を今のコードで確かめた。
