## 背景

2026-11-25 の監査（観点 drift、範囲 `docs/design/140_observability.jp.md`）で、§6・§7 の記述を `ObserverFactory` と `MetricsLogger` のコードに突き合わせて見つけた。分類は未文書である。開発者には質問していない。`src/core/base/src/observers.cpp:1445` のコメントは「記法の正本は docs/design/140_observability.jp.md §6」と書く。

ホットスポット補正: 140 は 90 日の変更回数が 38 回で、設計文書（jp）の中で 200・160 に次いで多い。urgency を 2 から 3 へ 1 段上げた。

## 事象

- `$target` の省略: §6 は event と step 軸の省略時だけを書き、target の省略を書かない。実装（`MetricsLogObserverBase::GetMetricsDataList`、`observers.cpp:973-1044`）は、UpdateResult → Agent → Experience（通知にあるとき）→ Runner → Env の順に、キーを知っている最初の source から読む。出荷設定（`apps/runner/config/*.txt`）の scalar の宣言 771 件のうち、57 件が target を省いている（`DropMerge.txt:1363`・1374・1376〜1381 など）。解決済みの定義の JSON では target が `null` になる（1339 行）。
- 属性の既定: `interval` の既定は 1、`ema_alpha` の既定は 0.01（1394・1396 行）だが、§6 の表に無い。
- `ema_alpha:A` は、`$ema` が無くても EMA を有効にする（1436 行）。§6 は「EMAが新しい値へ寄る係数を指定する」とだけ書く。出荷設定には、`ema_alpha` だけを書く宣言は無い。
- event との組み合わせの制限: `$action_info` は `@train` だけで使える（1476〜1479 行）。`$exp` と `$update_result` は `@episode_end`・`@session_end` で使えない（1480〜1484 行）。§6 は Eval scope の制限と `$env_step` の制限だけを書く。
- 同じ意味の別の書き方（`$action`・`$result`・`$batch_update_result`・`$batch_experience`、属性形 `event:`・`step:`・`step_axis:`・`target:`、`key:`）を §6 の表が書かない。受け付ける語そのものの整理は [issue-20261111-645ecc](issue-20261111-645ecc.md) が扱う。
- 動画: §7 は `videos/<tag>.mkv` の行で幅と高さの扱いを書くが、`app.metrics_logger.video_codec`（`auto`・`libx264`・`h264_nvenc`。`auto` は大きさが合えば NVENC、合わないか開けないときは libx264）と `app.metrics_logger.video_fps` は、どの設計文書・ユーザーガイドにも出てこない（検索語 `video_codec`・`video_fps`、0 件）。出荷設定は 5 つのファイルで書く（`common.txt:154-158` ほか）。`use_png_dump` は 140 と 020 にある。

## 影響

- 宣言を書く人が、target を省くとどこから読まれるかを設計文書から知れない。同じ名前のキーを Agent と Runner の両方が返すときに、どちらの値かを取り違える。
- `ema_alpha` だけを書いて、EMA でない値を記録したつもりになる。
- 動画の codec の選び方を知るには、コードか設定のコメントを読むしかない。

## 対応方針

- §6 の表に、target の省略時の探索順、`interval`・`ema_alpha` の既定、`ema_alpha` が EMA を有効にすること、`$action_info`・`$exp`・`$update_result` の event の制限を足す。別の書き方を載せるかは、645ecc の直し方（同じ意味の語を減らすか）と合わせて決める。
- §7 に動画の codec と fps の設定キーを足す。詳しくは 020 に置くかを決める。
- 英訳も同じに直す。コードは変えない。
