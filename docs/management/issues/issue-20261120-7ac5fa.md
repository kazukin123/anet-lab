## 背景

PRD192 の受入 A14 で、学習中に Runner の HeatMap を開閉する操作を確認するために見つけた。A14 の実画面確認には GridMaze の通常 DQN を用いた。再現時の Run 名は[実装記録](../../memo/0192_concurrency_and_boundary_defect_fixes_20impl.md)に記載した。

## 事象

LunarLander の IQN で学習を始め、`View > HeatMap` からダイアログを開く。既定の `policy-net`、`forward`、出力 `q`、集約 `mean` を使って表示を開始すると、`tau_embedding` が入力 `taus` の不足を報告し、Run が停止する。PRD192 の修正前後の Runner で同じ設定と操作による停止を確認した。

## 影響

学習途中に既定の HeatMap を確認しようとすると、その Run の学習が中断される。

未定。
