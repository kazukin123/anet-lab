## 背景

台帳 F-0032 から移した（2026-11-03）。
観点: drift。分類: fail-fastの方針。確度: high。

## 事象

PRD070 D5の一括エラーは、cudaを指定しているキーの一覧とautoへの直し方を出すが、各キーに何を書いたか（cuda・cuda:1など）を出さない。エラーに指定値を含める方針に足りない。

- core/anet-core/src/init.cpp:118 CUDA is unavailable for explicit device settings: の後ろにキー名だけを並べる（118〜119）
- AGENTS.md:193 エラー・WARNには対象の識別子と指定値を含める方針

## 影響

CPU機でagent.device = cuda:1、run.eval_device = cudaの設定を起動する → エラーはagent.device, run.eval_deviceとだけ言う → どちらに何を書いたかは、設定の継承をたどって自分で確かめることになる。

## 対応方針

キー=指定値の形で並べる。
