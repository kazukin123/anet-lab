## 背景

[RFD0195](../../memo/0195_document_term_rfd_and_4digit_numbers_10rfd.md)（文書の呼び名を RFD に改め、番号を 4 桁にする）の実装のレビューで、[実装 品質確認観点](../../quality/impl.md)の項番 66（リテラルの定数化）・72（重なる文字列リテラル）が当たった。当たった文字列は、実装の前から同じ文字列を重ねて書いていたもので、RFD0195 は名前（`PRD094_UI_DARK` → `RFD0094_UI_DARK`、`prd099` → `rfd0099`）だけを置き換えた。定数にするのはコードの形を変える別の関心で、実装の時点では正式 Run が走っていてビルドを回せなかったので見送り、工程末に起票の候補として示し、開発者が起票を選んだ。

## 事象

- 環境変数の名前 `RFD0094_UI_DARK` を、[EvalTracePanel_test.cpp](../../../src/apps/runner/src/EvalTracePanel_test.cpp) の 1021 行・1612 行と、[LogPanel_test.cpp](../../../src/apps/runner/src/LogPanel_test.cpp) の 193 行で、それぞれ文字列で書いている（LogPanel_test.cpp の 191 行のコメントにも名前がある）。
- 検証資材のパス `src/core/base/testdata/rfd0099/frames_210x160.u8` を、[AtariEnv_test.cpp](../../../src/env/atari/src/AtariEnv_test.cpp) の 2052 行・2095 行で、それぞれ文字列で書いている。
- 行番号は 2026-11-23 の作業ツリー（RFD0195 の 1 回目のコミットの状態）による。

## 影響

- 名前やパスを変えるとき、同じ文字列を全部の箇所で直す必要があり、1 か所でも漏れると、テーマの切り替えや検証資材の読み込みを確かめないテストになりうる。RFD0195 では、同じ置き換えを全部の箇所に当てて揃えた。

## 対応方針

未定。

- 2026-11-23 RFD0195: 案として、ファイルごとに名前つきの定数（環境変数の名前と、検証資材のパス）を置き、使う箇所はその定数を参照する。Runner の 2 ファイルで共有するかは、テストの共通のヘッダの有無で決める。直したら Runner と Atari のテストをビルドして通す。[実装記録](../../memo/0195_document_term_rfd_and_4digit_numbers_20impl.md)
