## 背景

[PRD182](../../memo/0182_source_layout_10rfd.md)（ソース配置の見直し）は、基盤のテスト用の口に、何もしない代役の Agent（`anet::test::StubAgent`）を足す（同書 §4.1 の D13・D14、§5.8）。テストがすでに持つ代役をそこへ寄せることは、同書 §7 で先送りにした。作る条件は「テスト用の口ができたあと」である。工程末の候補から開発者が選び、起票した。開発者への質問はしていない。

## 事象

- テストのファイルが、`Agent` を継承する代役を 8 個、自分で定義している（2026-11-19 の行番号）。
  - `core/anet-core/src/trainer_test.cpp` の 358 行: `TestAgent`
  - `core/anet-core/src/observers_test.cpp` の 289 行: `TestAgent`
  - `core/anet-core/src/episode_end_test.cpp` の 353 行: `TestAgent`
  - `core/anet-core/src/metrics_test.cpp` の 64 行: `DiagnosticAgent`
  - `core/anet-core/src/dqn_based_agent_test.cpp` の 1395 行: `TraceAgent`
  - `apps/runner/src/RunnerApp_test.cpp` の 57 行: `SlowInitTestAgent`、164 行: `CloseDrainTestAgent`
  - `apps/runner/src/EvalTracePanel_test.cpp` の 98 行: `TraceUiAgent`
- ほかに、Agent を作らない代役の factory が 1 つある（`core/anet-core/src/config_inventory_test.cpp` の 9 行: `InventoryAgentFactory`）。
- 8 個のうち、何もしない代役で足りるものと、固有の振る舞い（初期化を遅らせる、close を待つ、Trace や診断の値を返す）を持つものの内訳は、調べていない。
- 2026-11-23 監査（backlog）: 依存先 2dd820 は解決した。テスト用の口 `anet::test::StubAgent`（`src/core/base/include/anet/test/agent.hpp:15`、実体は `src/core/base/src_testing/agent.cpp`）ができ、使うのは今 metrics_logger_test と GridMazeEnv_test だけ。代役 8 個は残る。

## 影響

Agent の interface を変えるたびに、8 か所の代役を直すことになる。同じ名前（`TestAgent`）の代役が、3 つのファイルにある。

## 対応方針

未定。テスト用の口ができたあとに、8 個を、何もしない代役で足りるものと、固有の振る舞いを持つものに分ける。前者は `anet::test::StubAgent` に替える。後者は、そのテストに残すか、代役に口を足すかを決める。
