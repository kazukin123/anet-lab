## 背景

2026-11-18 の定常整備の監査（観点 drift、範囲 docs/design/200_dqn_agents.jp.md）で、文書 200 の §11.1 が載せる ADR の後発注記を確かめて見つかった。直すのは ADR 側で、設計文書 200 のホットスポット補正は当てていない。開発者には質問していない。

## 事象

- `docs/adr/0013-actor-network-resource-policy.md:3` は「`Agent::CreateActor()` は `std::optional<bool> clone_model_override` を受け取る」と決めているが、後発の注記が無い。実装は `core/anet-core/include/anet/rl.hpp:814` の `CreateActor(const ActorRequest& request)` で、`clone_model_override` は src・include・apps に 0 件。置き換えたのは ADR 0038（Agent インタフェースは RunMode・`clone_model_override`・device 引数を持たない）。文書 200 の 848 行は 0013 を関連 ADR に載せ、0038 は載せていない。
- `docs/adr/0010-actor-priority-mean-q-approx.md:4` と `docs/adr/0012-replay-initial-priority-hint-completion.md:3` の最新の注記は「0036 で 3 列（K=3）へ改訂」で止まり、5 列にした ADR 0075 は 0036 の注記からしかたどれない。実装は `dqn_based_agent.hpp:335` の `kActorQHintColumnCount = 5`。0010 は「UQE 再現見送りは不変」と注記するが、後の ADR 0019 は IQN+UQE の Actor Q ヒントを risk-biased score から作ると決めた（文書 200 の 269 行は 0019 側で書く）。

## 影響

文書のリンクから ADR に入った読者が、存在しない引数 `clone_model_override` を現役の契約と受け取り、Q ヒントを 3 列、IQN+UQE の初期優先度を平均 Q と誤解する。

## 対応方針

未定。監査の案は、0013 の冒頭に 0038 で置き換えた旨、0010 と 0012 の冒頭に 0075 と 0019 への後発注記を足す。設計文書からの入口は課題 [[issue-20261118-7f7757]] で扱う。
