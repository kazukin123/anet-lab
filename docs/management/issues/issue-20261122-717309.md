## 背景

2026-11-22、ユーザーが、Atari の枠の会話で対策案に記号（A〜G）を振ったあと、記号だけで話が進み、案の中身を見返すためにスクロールするのがしんどいと述べた。記号を出すたびに短い名前を添える決まりはその場で直し、案・決定・未決をまとめたページを随時更新する形は、ユーザーの指示で暫定 PRD として起票した（[PRD197](../../memo/0197_conversation_options_summary_page_10rfd.md)）。起票の時点で、ユーザーに質問はしていない。

## 事象

- 会話で案・選択肢・論点に記号を振ると、そのあとの会話は記号で進む。案の全体（いくつあり、どれを試し、どうなったか）と、決まったこと・未決は、会話を読み返さないと一覧できない。
- PRD161 のグリルの会話では、AI がまとめの HTML を作って更新した前例があるが、決まりには書かれていない。AGENTS.md・skill・プロセスの文書に、会話のまとめページを定める記述は無い（[PRD197](../../memo/0197_conversation_options_summary_page_10rfd.md) §5）。

## 影響

- 案が多い会話ほど、ユーザーは元の応答を探して会話を遡る。スマホではとくに手間がかかる。
- まとめページが作られるかは、その会話の AI しだいになる。

## 対応方針

[PRD197](../../memo/0197_conversation_options_summary_page_10rfd.md)（暫定）の再グリルで決める。
- 2026-11-22 PRD197: 再グリルで方針を決めた。まとめページは会話の枠ごとに 1 枚で、中身は議論・整理の助けに進捗と残件を加える。Claude Code は非公開ページ、Codex は ChatGPT Sites の非公開ページに置き、どちらの会話でもスマホから開ける。手順は skill `anet-summary-page`、始める条件は AGENTS.md の 1〜2 行、場面ごとの指針とひな形は `docs/process/summary-page/` に置く。[PRD197](../../memo/0197_conversation_options_summary_page_10rfd.md)（§1.2・§6 D1〜D28）
