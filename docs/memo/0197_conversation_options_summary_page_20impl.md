# 会話のまとめページ 実装メモ

## 概要

[PRD197](0197_conversation_options_summary_page_10rfd.md) と [issue-20261122-717309](../management/issues/issue-20261122-717309.md) に対応する。ユーザーが会話の記号、進捗、判断、残件をスマホから見返せるよう、会話の枠に対応するまとめページを必要なときに作り、その後は同じ URL で更新する。

## 主な変更

- Codex と Claude Code の両方に `anet-summary-page` を登録し、PRD197 §6 の優先順で開始・続行を判断する手順を置く。中身が変わった応答での更新、手元の HTML と目印ファイル、同じ面での再開、面をまたぐ引き継ぎ、ファイル名の衝突回避、終了、公開できなかった場合の再試行を扱う。
- `docs/process/summary-page/` に、場面の一覧と共通の型、グリル・実験・一般の指針、スクリプトのない HTML ひな形を置く。ひな形では狭い画面と明暗の両方に対応し、端末の日本語フォント、同じ体裁の進捗欄、折り畳み、先頭へ戻るリンクを使う。
- `AGENTS.md` の概念説明ルール、両方の `anet-create-prd` の goal anchor、両方の skills README に入口を足す。
- 課題に実装内容と検証結果を記録する。実際の会話でしか確かめられない項目は、PRD §10 の受入番号と確認の時機を記録する。

## テスト

- 対象はユーザーが使う skill、会話からの起動条件、HTML の表示、各面の非公開ページへの発行手順。
- PRD197 の受入 A1〜A8 を、実ファイルの比較・一覧・検索と手順の照合で確認する。ひな形は、幅の狭い表示、明暗、進捗欄、折り畳み、先頭へ戻るリンクをローカルで確認する。
- skill と文書、HTML/CSS のひな形を追加する。実行コードや設定契約を変更しないため、TDD の対象外。
- 実際の会話で確認する受入 A9〜A19 は、条件に当たる会話が来た時点で確認する。未確認の項目はこの計画と課題に残す。U1（Codex の更新費用）・U2（会話の文脈に占める費用）は、PRD §7 の条件で測る。

## 検証

- `git diff --no-index -- .agents/skills/anet-summary-page .claude/skills/anet-summary-page` と、変更した既存の skill・README の両側で差がないことを確認する。
- `rg --files --hidden .agents/skills/anet-summary-page .claude/skills/anet-summary-page docs/process/summary-page` で、PRD §9.1 の追加ファイルを確認する。
- PRD §9.1・§9.2 の全ファイルを対象に、受入 A8 の正規表現で非公開 URL を検索する。ひな形はスクリプトがないことを確認し、すべての変更ファイルについてリンク、改行と既存ファイルの BOM の有無を検査する。
- `./.venv/Scripts/python.exe reports/tools/wiki_support.py maps` で課題の記録を検証し、派生一覧を更新する。
- 使用したコマンド、確認結果、レビュー応答の保存先、未確認の項目をここへ追記する。

## 前提

- 実装判断を要する未決は 0 件。PRD の起票は暫定だったが、再グリルとレビューを終え、暫定の印は外れている。
- 両方の `anet-create-prd` と skills README は編集前に一致していた。フレームワークの新しい用語はなく、既存 ADR 0061 の細則の配置方針に沿う。
- Claude Code では Artifact、Codex では所有者限定の ChatGPT Sites を使う。元の HTML は両方で共用し、外枠とホスティングの設定は Codex で出すときに組み立てる。作成済みの非公開ページは今回の変更に含めない。
- グリル、実験、一般の起動条件は PRD のとおりとする。実際の会話での効果、利用費用、スマホからの確認は、該当する会話での確認事項とする。
