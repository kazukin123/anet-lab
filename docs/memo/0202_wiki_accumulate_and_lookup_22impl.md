### (2) 会話の記録を引く道具

- `reports/tools/chat_utterances.py` を足す。読み取りだけを行う。

## テスト

- Public interface / surface: `reports/tools/chat_utterances.py` のコマンドライン（引数、標準出力の JSON Lines、終了コード）。検証資材は、一時フォルダに記録の見本を置き、コマンドラインを通して確かめる。`wiki_support.py` は変えない。
- 優先 behavior:
  1. Claude Code の形の記録から、語に当たる開発者の発言だけが、日付・会話の識別子・道具の回数とともに返る。
  2. Codex の形の記録から、同じように返る。サブエージェントの会話の行は返らない。
  3. 期間を渡すと、始まりの日と終わりの日の発言は返り、外の日付の発言は返らない。日付は日本時間で数える。
  4. 語と期間の両方を渡すと、期間の中で語に当たる行だけが返る。
  5. どちらの形にも当たらないファイルと壊れた行は、飛ばした数に数えられ、ほかの行は返る。
  6. 語も期間も無い、期間が日付として読めない、始まりが終わりより後、置き場が無い、のそれぞれで、終了コードがエラーになり、行が出ない。
- TDD 順序: 1 を、見本 1 ファイルからコマンドラインの出力までを通す最初のテストにする。失敗を見てから最小の実装で通し、2〜6 を 1 つずつ、テスト → 失敗 → 実装 → 再実行で進める。整理は、全部が通ってから行う。
- `wiki_test.py` の `query` の行の見本の直しは、断定を変えない。直す前とあとで通ることを確かめる。
- (1) と (3)〜(6) は文書と wiki のページだけを変えるので、TDD の対象外である。
