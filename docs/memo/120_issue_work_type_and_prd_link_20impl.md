# 課題の種類と prd 欄 実装メモ

## 概要

[PRD120](120_issue_work_type_and_prd_link_10prd.md) を実装する。課題の `type` を仕事の種類（D1）にし、PRD との結び付けを各課題の `prd` 欄（D2・D3）に替え、PRD の実装済みを課題から導く（D4・§5.2）。`parent`・`depends`・`prd` は Obsidian のリンクの形で書く（D5）。`domain`・`tags`・`resolution` を足す（D6〜D8）。道具・テスト・skill・文書・課題の移しは、1 回で入れる（PRD §9）。
