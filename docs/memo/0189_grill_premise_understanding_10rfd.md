## 1. 目的と問題

### 1.1 問題

グリルの問いに答えるには、その判断に要る前提（事実・用語・既存部品の働き・過去の判断・守る線）を、開発者が理解している必要がある。今の `anet-create-rfd` には、前提を示す段（既存 RFD の要点提示など）はあるが、次の 3 つが無い（§3.1）。

- 論点ごとに要る前提を洗い出す手順。
- 前提が欠けている（測定・試作・調べものの結果が無い）ときに、グリルより先にそろえる段。
- 示した前提を開発者が理解したかを確かめる手順。今は、開発者からの質問を待つ形だけである。

そのため、前提をそろえる段取りを、開発者がグリルのたびに自分で決めて指示している（RFD0130。§3.2）。指示しなければ、前提が欠けたままグリルが始まる。前提を理解しないまま問いに答えると、説明を求める往復とその前の待ちが増えるか（P1）、浅い理解のまま推奨を選び、あとの再グリルで開き直すことになる。

### 1.2 ゴール

- **G1**: グリル（新規・改訂・再グリル）で最初の個別の問いを出す前に、AI が要る前提を洗い出し、開発者に示す。
- **G2**: 前提が欠けていると分かったら、AI がそれを示し、グリルの前にそろえる段を、開発者の指示を待たずに提案する。
- **G3**: 開発者が前提を理解した状態にあることを、問いに入る前に確かめる手順がある。
- **G4**: 題材の課題が片付く。課題の「決めること」4 点（前提の洗い出し、前提をそろえる段、理解の確かめ方、置き場所）を決め、skill・レジストリ・観点に入れる。

### 1.3 非ゴール（退けた案と、本当の制約か）

- **NG1**: 理解を深める往復（説明や具体例を求める返答と、その答え）を、減らす対象にしない。RFD0087 の NG9 のままである（P2）。これで退けるのは「確かめの往復を省いて問いを短くする」形で、本当の制約である（理解の往復は品質の源という開発者の判断）。
- **NG2**: プロセス契約を anet 向けの文面にしない（P3）。中立の文面のまま良くなる直しは、してよい。これで退けるのは「プロセス契約に anet の手順を書き込む」形で、本当の制約である（プロセス契約は anet の外でも同じものを使う。P8）。プロセス契約へ中立の文面で上げる形は、NG2 では退けず、D7 で先送りにした（§9）。
- **NG3**: 実装の工程（`anet-impl-rfd`）の、着手前に未決を確かめる段は変えない。課題が範囲を `anet-create-rfd` のグリルに限っているためで、本当の制約ではなく範囲の選び方である。前提をそろえるために止めた RFD に実装の入口が当たったときの扱いは、§10 の U1 に残す。別モデルの検討は、この穴は本 RFD の止め方から生まれるとして、入口のレビューの範囲に止めた RFD を足す案を推したが、開発者は範囲を保ち、課題に残すことを選んだ（§4）。

## 5. 用語

本 RFD の語は、グリルの手順の語である。[CONTEXT.md](../../CONTEXT.md) は、フレームワークの領域の語を持つ用語集で、グリルや RFD の手順の語を持たない（`グリル` で検索して 0 件）。そのため、本 RFD の語は CONTEXT.md に足さない。

| 語 | 意味 |
|---|---|
| 前提 | グリルの論点を判断するのに要る、事実（コード・文書・測定）、用語、既存部品の働き、過去の判断（ADR・選ばなかった形）、守る線（規約・非ゴール） |
| 共通の前提 | 複数の論点にまたがる前提と、全体の流れの前提 |
| 共通の前提の一覧 | goal anchor の応答（既存 RFD では要点提示の応答）に並べる、共通の前提の一覧。末尾に確かめの文言を置く |
| 欠けた前提 | コードや文書を読んでも分からず、測定・試作・調べものの結果が要る前提 |
| 前提をそろえる段 | 欠けた前提を、問いの前にそろえる段取り。そろえるのに時間がかかるときは、グリルを止めて RFD に書く |
| 前提の表 | RFD の「前提」の節に置く、番号・種類・内容・出典・確かめの列を持つ表 |
| グリルの材料 | グリルの前後の、開発者の発言と AI の案を分けて書いた RFD の節。決定としては扱わない |

### 6.3 細部（開発者の選択で、推奨の既定を採った）

S5 と S12 は、起草のあとの別モデルの検討を受けて、開発者が選び直した。S4 と S8 の後半（リンクにできない出典、止めた時点の自己点検の範囲）は、自己点検のあとに残った未決（U2・U3）を、開発者が推奨の既定で埋めた。

| # | 事項 | 既定 | 理由 |
