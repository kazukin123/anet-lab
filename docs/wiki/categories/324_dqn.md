## 概要・責務

- DefaultDQNAgentとRainbowAgentが共通DQN componentを合成する具象実装を扱う。方式の概要と本実装の対応は§2.1、部品の合成は§2.2を参照する。（出典: [DQN系Agent](../../design/200_dqn_agents.jp.md)、§1.3・§2.1・§2.2）。
- DefaultDQNの内的報酬は、外側Agentが次観測の新しさを採点し、スケール済み外的報酬へ加えてReplayへ渡す。RNDの採点と補助学習は独立した部品が担い、補助学習のcreditとlane抽選は外側Agentが持つ。（出典: [DQN系Agent](../../design/200_dqn_agents.jp.md)、§6.2・§7.2）。

## 選ばなかった形

- ImageClsのTrain Actorにも遅延snapshotを適用する形 — 不採用: episodeを持たず、shared networkの即時反映を維持する（出典: [PRD036](../../memo/done/036_train_actor_periodic_snapshot_10prd.md)、対象範囲）。
- ObservationPipelineクラスと専用ファイル・テストの追加 — 範囲外: 固定3段の観測加工はActor本体で満たせ、段の要件が揃う前のクラス化は作り直しになる。再開条件: 段の要件が揃う後続PRDで導入する。（出典: [PRD083](../../memo/done/083_action_context_retire_10prd.md)、複雑さ監査）。
- 独立した公開NoisyLinearブロック型 — 不採用: 既存LinearとHead最終射影へ対応する形を採る（出典: [PRD084](../../memo/done/084_noisynet_10prd.md)、§4.1）。
- AMPの実行設定への集約とノイズ込み重みのSN — 範囲外: 精度は用途ごとに異なり、ノイズ込みSNの推定・保持・比較契約も別の暫定PRDで裁定する（出典: [PRD084](../../memo/done/084_noisynet_10prd.md)、§8.1・§8.2・§14.2）。
- εを引き直す総ノイズ測定と曲率を含む臨界batch測定 — 先送り: 追加forward・専用乱数やヘッセ行列との積が要る。再開条件: 分岐の結果が条件付き値の読みと食い違いNoisy probeのQ差が大きいとき、または単純版とBの効き目が食い違ったとき（出典: [PRD092](../../memo/done/092_gradient_noise_scale_10prd.md)、§8）。
- 購読間隔ごとの別EMA — 不採用: 状態と系列が増える。独立した時間幅はrawの利用側での再平滑化に任せる（出典: [PRD092](../../memo/done/092_gradient_noise_scale_10prd.md)、§10.2）。
- head単位統計とattention entropy最小値 — 先送り: 層平均で足りる間は公開値と保持データを増やさない。再開条件: 層平均が下がったRunで内訳が必要になったとき。最小値は6層構成で読みにくくなったとき（出典: [PRD093](../../memo/done/093_attention_entropy_diagnostics_10prd.md)、§5・§7）。
- TQLのattention entropy正則化 — 先送り: anetでは本指標で集中の進行をまだ観測していない。再開条件: 層平均の集中と成績の頭打ち・下降が時期として重なったとき。因果は別途判断する（出典: [PRD093](../../memo/done/093_attention_entropy_diagnostics_10prd.md)、§7 1）。
- 学習側の厳密な優先度の列 — 不採用: EvalPanelには単一networkのforwardしかなくreplayも無いため学習側のonline/targetによる値は得られない（出典: [PRD094](../../memo/done/094_evalpanel_step_history_10prd.md)、§6）。
- ReplayBufferから別に一様抽出する勾配ノイズprobe — 不採用: 実更新と抽選分布・IS重みが違い、forwardも増える（出典: [ADR 0054](../../adr/0054-gradient-noise-scale-in-band-microbatch-split-includes-bf16.md)、Considered Options）。
- 未成立理由ごとの追加状態指標 — 不採用: 記録から理由を一意に復元できない場合も含め、追加公開契約を増やさない（出典: [PRD092](../../memo/done/092_gradient_noise_scale_10prd.md)、§10.2）。
- attention entropy専用のfeatureキー — 先送り: 今の構成ではTransformerがfeature閉包内にある。再開条件: Transformerがfeature閉包の外へ置かれたとき（出典: [PRD093](../../memo/done/093_attention_entropy_diagnostics_10prd.md)、§5）。
- Actor設定キーでeval_panelだけにhintを生成させる形 — 不採用: 設定が増え、autoの語が今の条件を表すものになり、n-step窓の所有がAgent外へ出る（出典: [ADR 0058](../../adr/0058-approx-priority-column-computed-by-agent-step-diagnostics.md)、本文）。
- 特徴空間・行動価値・スキップ価値を別 Network にする 3 分割 — 不採用: 切れ目は DAG の branch で表せ、checkpoint の形と Network 1 つ前提の診断・可視化へ波及する（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§4 D3、[ADR 0062](../../adr/0062-networkmodel-holds-auxiliary-network-fed-by-primary-outputs-with-target-used-only-for-acting.md)）。
- 1 つの Network に skip の branch と射影を足す形 — 不採用: 行動を入力に取る包含型で Actor の forward が 2 倍になり、skip の target が複製される（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§4 D3）。
- スカラーのスキップ価値 — 先送り: 型を Q と揃えて目標値の組み立てを流用する。再開条件: 分布型で j の選択が不安定、または QR の分離型で射影が重いと分かったら（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§8）。
- skip Head の独立 Dueling — 先送り: Q 共有型が同じ役を担う。再開条件: Q 共有型で Q(s,a) の基準が skip の学習を不安定にしたら（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§8）。
- 全 k を mask 付きで一括するスキップのサンプル — 先送り: target forward が J 倍になる。再開条件: 1 点 k で skip の学習が遅く、費用を払えるとき。後続の暫定 PRD の (K) が引き継ぎ、作るかは同書の段 0 で決める（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§8、[PRD958 TempoRL の後続](../../memo/958_temporl_skip_followups_10prd.md)、§4 D11）。
- 評価 slot でスキップを切る口 — 先送り: 再開条件: 学習した skip を使う評価と使わない評価の比較が要ると分かったら（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§8）。→ PRD104 で採用（Actor ごとの `actor.[key].skip.max_length_mode = single`。同じ checkpoint の固定あり・なしの評価の切り分けに使う。出典: [PRD104](../../memo/done/104_temporl_skip_auxiliary_only_10prd.md)、§4 D1・D2・§7 の段 0）。
- skip 中の lane の forward を省く — 範囲外: 全 lane の q_values を読む契約を変える別の関心。再開条件: TempoRL が同じ step 数で効き、forward が律速の env があるとき（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§3）。
- 学習の Actor で判断する lane だけを forward する形 — 範囲外: GPU の Actor の forward は呼び出しの回数に強く依ると推定され、lane を間引いても減らない見込みで、全 lane の行を前提にする読み手の契約も変える。再開条件: Actor の forward の実時間を行の数を変えて測り、CPU の forward か IQN の lane×分位の行が律速で、Actor の forward が全体の 2 割を超えると分かったとき（出典: [PRD958 TempoRL の後続](../../memo/958_temporl_skip_followups_10prd.md)、§2.3・§8）。
- スキップ中の forward の省略（判断する lane が無い step の forward を丸ごと飛ばし、replay へ送らない Actor にだけ置く形） — 範囲外: 効くのは 1 env をリアルタイムで動かす実行だけで、学習とは別の関心。再開条件: 実機の制御などの 1 env のリアルタイム実行の PRD が起きたとき（出典: [PRD958 TempoRL の後続](../../memo/958_temporl_skip_followups_10prd.md)、§4 D9・§8）。
- Lazy-MDP の「既定の方策に任せる行動」と罰を足す形 — 範囲外: 行動空間と報酬を変える別の関心（出典: [PRD958 TempoRL の後続](../../memo/958_temporl_skip_followups_10prd.md)、§3・§8）。
- IQN で厳密な Z_tau を得るための追加の τ 列 — 先送り（Defer）: soft 経路のスコアは M 本の経験分位で近似する。再開条件: M が小さい構成で経験分位が粗くて困ったとき（出典: [PRD067](../../memo/done/067_MunchausenRL_10prd.md)、Non-Goals・Complexity Audit の Defer）。
- zero_grad の変更 — 不採用（対象外）: LibTorch 2.11 の zero_grad は set_to_none = true が既定で、既にカーネル起動がゼロである（出典: [PRD011](../../memo/done/011_fused_adamw_10prd.md)、Context（背景・目的）・11. Out of Scope）。
- 旧キー（use_qr・num_quantiles）の tripwire 検出 — 不採用（D14）: 互換処理・マイグレーション・WARN を持たない完全クリーンの方針を再確認し、過去の設定の使い回しによる無言の挙動変更は使う側の責任とする（出典: [PRD001](../../memo/done/001_iqn_10prd.md)、確定した設計判断 D1・D14、正直なリスク）。
- 設定レベルの taus-bind fail-fast と推移的到達性の検査（旧 D7） — 不採用（D15 で廃止）: フレームワークは局所的・決定的に判定できる契約だけを検証し、未使用入力の WARN と IQN Head の rank 検証に置き換え、NN 設定の整合は使う側の責任とする（出典: [PRD001](../../memo/done/001_iqn_10prd.md)、確定した設計判断 D7・D15）。
- 学習時の τ を QMC・低差異列（Sobol、Halton など）で作る形 — 範囲外（Out of Scope）: 分布 RL では未踏の将来候補として、サーベイ要約への記録に留める（出典: [PRD044](../../memo/done/044_iqn_tau_stratified_sampling_10prd.md)、Out of Scope）。
- loss 駆動の τ 重点サンプリング（FQF-lite）と FQF 型の fraction proposal network — 範囲外（別 PRD）: hot path へのフィードバック経路や追加の network が要る（出典: [PRD044](../../memo/done/044_iqn_tau_stratified_sampling_10prd.md)、Out of Scope）。
- skip の optimizer の分け方を `optimizer_mode` の別キーにし、`per_loss`×`stop` を構築時エラーにする形 — 不採用: 設計の空間は遮断・合算・分割の 3 点で、`feature_gradient` の 3 値目で表せ、無効な組み合わせと検査が要らない（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D2・§8）。
- 著者の更新の順（skip を先に step し、更新後のパラメータで Q の勾配を取る） — 範囲外: current の forward が 1 回増え、差は η の 1 歩分。再開条件: `split` が `merge` を上回り、順の違いで結果が変わる兆候が出たとき（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D4・§8）。
- `[eval]` のスキップ長だけを Greedy にする形、`[eval]` の行動も greedy にして著者の評価の条件を写す形 — 不採用: 前者は条件が混ざり skip 有効の Run の評価の時系列が切れ、後者は TempoRL 以外の比較の条件（ε 0.01・UQE）まで動かす。学習したスキップ価値は行動もスキップ長も greedy の評価 session で測る（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D7・§8）。
- `split` で `loss_weight` を skip 側の歩幅の倍率に読み替える形、`split` で `loss_weight ≠ 1` を構築時エラーにする形 — 不採用: 同じキーがモードで意味を変える／共有プロファイルの使い回しで止まる（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D12・§8）。
- skip 専用の replay とバッチ（著者の形） — 先送り: PRD098 D11・D14 の理由（PER・prefetch・世代 key の 2 系統、forward と抽出が 2 倍）。再開条件: k_max に比例する重みを入れても長い j の学習が遅く、skip のデータの古さが効くと分かったとき（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§8）。
- Munchausen の log π の clip 率を判断の旗で分ける計測と、スキップの途中の行の Munchausen の項の扱い — 範囲外: 著者との差ではなく、TempoRL と Munchausen の組み合わせの関心で、replay のサンプルの出力に判断の旗を運ぶ契約の変更が要る（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D13・§8）。
- 合算で眠った・死んだユニットが増えることへの手立て — 範囲外: 機序が未確認。再開条件: 段 1・段 3 で機序の候補が絞れたとき（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§8）。
- 評価側の skip 指標を評価 slot の action_info の step 値（`$eval.[greedy] @train … $action_info`）で取る形 — 不採用: 評価 runner 自身の step 軸に載り、学習の進みや腕どうしと並べられず、判断の回数も作れない。Actor の session の累積を `@session_end` で読む（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D8・§8）。
- エピソードごとの判断回数を trace 行で記録する形 — 先送り: scalar としては並ばず集計が別工程になる。再開条件: 著者の評価のエピソードごとの判断回数と直接比べるとき（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§8）。
- GridMaze のスキップ長の ε-greedy を、6×10 の確認の前に既定にする形 — 先送り: 5×5 の既定 seed・1 seed の結果だけで既定を動かさない。再開条件: 6×10 の 3 seed で UQE 以上（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D3・§8）。→ PRD103 で採用（2026-10-28 に 6×10 の 3 seed で条件を満たし、`run.@skip` の既定にした。出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D3・§7 段 1'）。
- モード値でskip側のノイズの有無そのものを選ぶ形（`skip.noise_mode = shared｜off`など） — 不採用: NN実行設定のカタログの外に2つ目のノイズの指定を作る。`dedicated`でカタログのキーを選ぶ形で表せる（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§4 D1・§8）。
- `skip.head.projection.noisy.enabled=false`でskipのHeadのノイズを消す形（評価の条件として） — 不採用: 構造の設定で、Agent全体とLearnerのskipまで変わり、学習済みのcheckpointをActorごとの条件で評価できない（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§4 D1・§8）。
- Q側と同じ値を`skip.nn_forward_key`に各Actorで書き写す形 — 不採用: Q側の`nn_forward_key`だけを上書きすると、skip側が黙って既定で動く（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§4 D1・§8）。
- `skip.nn_forward_key`が無ければQ側と共用する形（既存の`skip.policy`と同じ形） — 不採用: 未指定に意味を持たせる（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§4 D1・§8）。
- skip専用の方策（`skip.policy`）の共用の決め方もモード値にそろえる形 — 範囲外: 本当の制約ではないが、skip専用の方策を使う今の設定（GridMazeの`run.@skip`など）の移行が要り、本書の問いには要らない。再開条件: skip専用の方策の共用の規則を見直すとき（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§8）。
- LearnerのskipのforwardのNN実行設定を分ける形 — 先送り: 問いはActorの選択に入るノイズで、Learnerのノイズは学習の一部。再開条件: Train Actorのskip側のノイズを切っても学習が変わらず、Learner側のノイズを疑う材料が出たとき（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§8・D5）。
- skip側のノイズでjが入れ替わる割合の診断指標 — 先送り: 評価で切り分けられる見込み。再開条件: 評価の切り分けの読みが「決めきれない」になったとき（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§8）。
- ノイズの倍率をNN実行設定（`nn_forward.[<name>].noisy.*`）に置く形 — 不採用: NN実行設定はlaneもexp_stepも知らず、laneごとのラダーや時間のスケジュールを持てない（出典: [PRD107](../../memo/107_noisy_gain_lane_ladder_10prd.md)、§8）。
- laneの一部だけ別のNN実行設定（`mu_only`）でforwardする形 — 不採用: forwardが2回になる。倍率0の行で同じ値を1回のforwardで作れる（出典: [PRD107](../../memo/107_noisy_gain_lane_ladder_10prd.md)、§8）。
- τの取り方のlaneごとのラダー — 先送り: まずノイズだけの効き目を見る。再開条件: ノイズの無いlaneがGreedyの道をたどりきれていないと分かったとき（出典: [PRD107](../../memo/107_noisy_gain_lane_ladder_10prd.md)、§8）。
- DQN側でNoisyの有無を見て、効かないノイズの倍率にWARNを出す形 — 不採用: ADR 0048の「Noisyの有無で設定の検証を切り替えない」に反する（出典: [PRD107](../../memo/107_noisy_gain_lane_ladder_10prd.md)、§4 D4・§8）。
- checkpoint を読むときの通知を、初期化も含めてすべて INFO にする形 — 不採用: skip 有効の設定で skip の Network を持たない checkpoint を取り違えると、学習していない Network で評価した結果が黙って出る。置き換えは INFO、初期化は WARN にする（出典: [PRD117](../../memo/117_warn_policy_and_unread_config_10prd.md)、D10）。
- RND の `learn_batch_size` の既定を lane の数に結び付ける形（`?= ${run.train.num_envs}`） — 不採用: 既定が全部の lane に変わり、lane が 64〜256 の出荷設定で 1 step の件数が 2〜8 倍になる。lane の数より大きい指定は構築時に止める（出典: [PRD117](../../memo/117_warn_policy_and_unread_config_10prd.md)、D11・§8）。
- 終端の遷移の内的報酬を既定で0にしない形 — 不採用: 終端の観測そのものを採点するので終端が報酬になる懸念が残り、今の中身の再現に指定が1つ増える（出典: [PRD123](../../memo/123_rnd_intrinsic_reward_scale_10prd.md)、§4 D16・§4.1）。
- `intrinsic.observation = state` でもdoneのlaneの内的報酬を0にできる形 — 不採用: 0にする理由の無い組が増える（出典: [PRD123](../../memo/123_rnd_intrinsic_reward_scale_10prd.md)、§4.1）。
- 内的の価値（収益）をgame overで切らない形 — 範囲外: Qを外的と内的に分ける必要がある別の関心で、PRD121が持つ（出典: [PRD123](../../memo/123_rnd_intrinsic_reward_scale_10prd.md)、§1 非ゴール）。

## 変えるときの条件

一般の条件は[リファクタリング観点](../../quality/refactor.md)の「ガードレール」、テストの充足は[定点統計](../../../reports/stats/trend.md)の「テスト充足」を見る。

- shared既定の既存Runのforward回数、保存形式、Train動作を維持する（出典: [PRD036](../../memo/done/036_train_actor_periodic_snapshot_10prd.md)、目的）。
- ImageClsのHead化のFP32等価性を、BF16化の効果と分けて確認する（出典: [PRD033](../../memo/done/033_imagecls_bf16_head_10prd.md)、確定した設計判断）。
- 観測のstack→device転送→正規化の並び、乱数の派生・消費順、aux集合を変えない。同seed・config・exp予算のDefaultDQN/LunarLander/stack4でmetrics checksumを比べ、checkpointのraw checksumはゲートにしない（出典: [PRD083](../../memo/done/083_action_context_retire_10prd.md)、Context・確定した設計判断2〜4・11）。
- 既存のHead/SN FP32保護と用途別AMP精度を維持する。Noisy無効の既存チェーンは決定論backendでmetrics checksumを比較し、sample時の乱数列の割当変更を無効側へ持ち込まない。比較の相手は実装前に保存した基準の実行体・依存DLL・出力とする（PRD060は基準を取り損ねた）（出典: [PRD084](../../memo/done/084_noisynet_10prd.md)、§8.2・§12・§13）。
- 診断ON/OFFで同seed・決定的モードの学習系列を比較し、学習の.grad・optimizer state・RNGを変えない。費用は反復A/Bで実測しprofiler合計でend-to-end増加率を代用しない（出典: [PRD092](../../memo/done/092_gradient_noise_scale_10prd.md)、§7.1・§7.2）。
- captureへ移す既存branch出力の値とdetachを保ち、captureなしforwardは不変とする。同seed・決定論設定の診断ON/OFFで学習由来metrics checksumとRNG・buffer等への非干渉を確認する（出典: [PRD093](../../memo/done/093_attention_entropy_diagnostics_10prd.md)、§6 1・5）。
- ヒント計算の共有化前後でactor_approxの同seed・決定的Runの学習metrics checksumを一致させ、既定のEvalPanel networkとRunnerカウンタの通知前後の時機を変えない（出典: [PRD094](../../memo/done/094_evalpanel_step_history_10prd.md)、§4.2 D6/D7・§8 3）。
- スキップが無効のとき、forward の回数・順序、RNG の消費、loss、優先度、checkpoint の形を今と同一に保ち、metrics checksum の一致で確かめる（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§5.9・§7 段 0）。
- skip の新しい設定が既定（`feature_gradient` は今の値、`sample_weight = uniform`）のとき、Learner の forward と backward の回数・順序、RNG の消費、loss、優先度、checkpoint の形を今と同一に保ち、PRD098 の検証資材の段 0 と同じ比較で metrics checksum を一致させる。skip 有効の構成は、新しい実行体で、評価 session `[greedy]` と評価側の指標を足す前の設定（着手前の snapshot）を動かして比べる（出典: [PRD103](../../memo/done/103_temporl_reference_alignment_10prd.md)、§4 D11・D14・§7 受入 1）。
- `skip.nn_forward_mode`を足す前後で、既定（`shared`）のときskip側のforwardのseedの派生・時計の種別・forwardの回数と順序を変えず、PRD103の検証資材の6構成とskip有効のLunarLanderに`run.@noisy`を足した構成のmetrics checksumを、着手前のsnapshotの同じ設定を前後のビルドへ渡して一致させる。着手前と今の設定を4 env×既定・skip有効で解決して比べ、違いが各Actorの`skip.nn_forward_mode = shared`の追加だけであることも確かめる（出典: [PRD106](../../memo/done/106_temporl_skip_forward_noise_key_10prd.md)、§5.3・§7の受入1・4）。
- ノイズの倍率を足す前後で、既定（倍率1）のとき値と乱数の消費を今と同一に保ち、PRD103の検証資材の6構成とskip有効のLunarLanderに`run.@noisy`を足した構成のmetrics checksumを一致させる（出典: [PRD107](../../memo/107_noisy_gain_lane_ladder_10prd.md)、§5.3・§7の受入1）。
- 既定のfull・decisionの組み合わせではActorの行動・乱数消費とReplayの抽選列を変えず、PRD103の検証資材でmetrics checksumを一致させる（出典: [PRD104](../../memo/done/104_temporl_skip_auxiliary_only_10prd.md)、§5.7・§7の受入1）。
- `intrinsic.use_done_mask` の既定（true）では、doneのlaneの学習報酬をスケール済みの外的報酬だけに保ち、truncatedだけのlaneの扱いと、採点・統計の更新・補助学習がdoneのlaneも対象にすることを変えない（出典: [PRD123](../../memo/123_rnd_intrinsic_reward_scale_10prd.md)、§4 D16・§5.5）。
