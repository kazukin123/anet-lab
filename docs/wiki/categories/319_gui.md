# 319 GUI 共通基盤

[anet-lab](../../../README.md) › [wiki の目録](../index.md) › [機能カテゴリ](../index.md#機能カテゴリ)

## 概要・責務

- Env固有ViewをRunner GUIへ接続し、AuiLayoutFrameがdockサイズ往復・遷移時同期・paneとメニューの連動を担う。（出典: [アプリケーションとツール](../../design/160_applications_and_tools.jp.md)、§2.1）。
- 共通Panelはresize時の再描画を担い、TraceFollowerと再生制御はEval View・Q値・Conv2dの不変snapshotへの追従を共通化する（出典: [アプリケーションとツール](../../design/160_applications_and_tools.jp.md)、§2.1・§3.4）。

## 選ばなかった形

- step traceをtraceチャネルへ記録する配線 — 範囲外: 鏡写しインスタンスを購読先にする配線と同じ関心である（出典: [PRD094](../../memo/done/094_evalpanel_step_history_10prd.md)、§6）。
- 学習側の厳密な優先度の列 — 不採用: EvalPanelには単一networkのforwardしかなくreplayも無いため学習側のonline/targetによる値は得られない（出典: [PRD094](../../memo/done/094_evalpanel_step_history_10prd.md)、§6）。
- raw_obs表示・列値の折れ線・条件付き自動停止 — 先送り: まず表と再生で足りるかを見る。再開条件: 入力が要る、近似優先度の推移を一目で見たい、再生で探す手間が大きい、と分かった各時点（出典: [PRD094](../../memo/done/094_evalpanel_step_history_10prd.md)、§6）。
- episode開始通知とViewの開始表示 — 範囲外: 今回のゴールに効かず手動操作の時点ずれと同じ関心。再開条件: 948_qvaluepanel_manual_action_state_alignmentで手動の時点ずれを決めるとき（出典: [PRD097](../../memo/done/097_env_auto_reset_after_notification_10prd.md)、§5）。
- metricsのtrace定義tagをEvaluation Traceの列として参照する形 — 不採用: 見るだけでも記録の宣言が要り、EMA・間隔・集約を持つscalar統計はstepの生値に合わない（出典: [ADR 0057](../../adr/0057-eval-trace-columns-declared-apart-from-metrics-and-read-at-transition-time.md)、Considered Options）。
- 全targetを許し値の時点差は文書だけで説明する形 — 不採用: 終端行でリセット前後の値が混ざっても見た目で気付けない（出典: [ADR 0057](../../adr/0057-eval-trace-columns-declared-apart-from-metrics-and-read-at-transition-time.md)、Considered Options）。
- Evaluation Traceの表を並べ替えても再生は時系列のまま進める — 不採用: 並べ替えるのは何かの軸で分析するときで、時系列にこだわる理由がないというユーザーの裁定（出典: [PRD105](../../memo/done/105_eval_trace_arrow_key_forced_action_10prd.md)、D7）。
- TrainとEvalを一つのCentre paneにまとめてsplitterで分ける形 — 不採用: Evalのfloat・単独最大化・閉じる操作を失い、表示切替がpaneとsplitterの二系統になる（出典: [PRD110](../../memo/done/110_runner_main_pane_dynamic_centre_10prd.md)、§4.1）。

## 変えるときの条件

一般の条件は[リファクタリング観点](../../quality/refactor.md)の「ガードレール」、テストの充足は[定点統計](../../../reports/stats/trend.md)の「テスト充足」を見る。
- RAM計測で学習の信号を変えず、番号を追加しても既存番号の意味を変えない（出典: [PRD082](../../memo/done/082_atari_ram_progress_metrics_10prd.md)、非ゴールNG1・契約8）。
- UI調整で再生の向き・速度段階・停止時のLive復帰・行の保持と記録値を変えず、既存の再生・行消失・Resume復帰を回帰確認する（出典: [PRD094](../../memo/done/094_evalpanel_step_history_10prd.md)、冒頭2026-10-22改訂・§8 12）。再生の向きは、表を並べ替えている間だけ表の並びに沿うよう改めた（出典: [PRD105](../../memo/done/105_eval_trace_arrow_key_forced_action_10prd.md)、D7）。
- Evaluation Traceの既定の並び（stepの降順）では、再生・コマ送り・端の通知を今と同じにし、今の再生のテストがそのまま通ることを確かめる（出典: [PRD105](../../memo/done/105_eval_trace_arrow_key_forced_action_10prd.md)、§7の受入8）。
- 評価セッションの採用規則と@session_endの集約の読み口を変えない（出典: [PRD097](../../memo/done/097_env_auto_reset_after_notification_10prd.md)、§4.2 4・§4.3.4）。
- paneの表示切替でwindow sizeを変えず、主paneのmaximizeと既存の再生・表示を保つ。描画timerを止めても学習とViewのobserverは継続する（出典: [PRD110](../../memo/done/110_runner_main_pane_dynamic_centre_10prd.md)、§4 D6・§5.1・§7）。
