## 選ばなかった形

- IQN専用のNetworkクラスを設ける形 — 不採用: 既存のbind DAGと最小Headで表す（出典: [PRD001](../../memo/done/001_iqn_10prd.md)、目的）。
- 独立した公開NoisyLinearブロック型 — 不採用: 既存LinearとHead最終射影へ対応する形を採る（出典: [PRD084](../../memo/084_noisynet_10prd.md)、§4.1）。
- AMPの実行設定への集約とノイズ込み重みのSN — 範囲外: 精度は用途ごとに異なり、ノイズ込みSNの推定・保持・比較契約も別の暫定PRDで裁定する（出典: [PRD084](../../memo/084_noisynet_10prd.md)、§8.1・§8.2・§14.2）。
- Noisyの有無フラグ・機能登録・実行条件の汎用比較と独立実行基盤 — 不採用: 固有の解釈と検証を具象の計算部品へ閉じる（出典: [PRD084](../../memo/084_noisynet_10prd.md)、§4.2・§14.2）。
- εを引き直す総ノイズ測定と曲率を含む臨界batch測定 — 先送り: 追加forward・専用乱数やヘッセ行列との積が要る。再開条件: 分岐の結果が条件付き値の読みと食い違いNoisy probeのQ差が大きいとき、または単純版とBの効き目が食い違ったとき（出典: [PRD092](../../memo/092_gradient_noise_scale_10prd.md)、§8）。
- PPO/SAC・複数損失・別optimizer向けの拡張口 — 先送り: 単一損失・AdamWの現用途で完結させる。再開条件: 対象Learner・観測したい損失とoptimizerが具体化したとき（出典: [PRD092](../../memo/092_gradient_noise_scale_10prd.md)、§8 5・§10.2）。
- head単位統計とattention entropy最小値 — 先送り: 層平均で足りる間は公開値と保持データを増やさない。再開条件: 層平均が下がったRunで内訳が必要になったとき。最小値は6層構成で読みにくくなったとき（出典: [PRD093](../../memo/093_attention_entropy_diagnostics_10prd.md)、§5・§7）。
- TraceCallbackのcaptureへの統合 — 範囲外: 1関心2機構の痛みは未計測で、別の暫定PRDのゲートで扱う。再開条件: traceに要求フィルタが要るとき、または名前付き出力の3つ目の経路が要るとき。参照先999の前提は、093のNetworkForwardCaptureがコミット済みであること。（出典: [PRD093](../../memo/093_attention_entropy_diagnostics_10prd.md)、§5・§7）。
- TQLのattention entropy正則化 — 先送り: anetでは本指標で集中の進行をまだ観測していない。再開条件: 層平均の集中と成績の頭打ち・下降が時期として重なったとき。因果は別途判断する（出典: [PRD093](../../memo/093_attention_entropy_diagnostics_10prd.md)、§7 1）。
- moduleのbufferにεを置きreset_noiseで引き直す形 — 不採用: shared networkの同時forwardで競合し、snapshotとhard updateで別用途のεが混入する（出典: [ADR 0048](../../adr/0048-noisynet-epsilon-in-caller-execution-state-and-nn-forward-key.md)、Considered Options）。
- 毎forwardでの設定解釈と内容別キャッシュ — 不採用: 速度が重要な経路に検索・比較・同期が残る（出典: [ADR 0051](../../adr/0051-nn-forward-prepares-concrete-calls-and-purpose-owned-execution.md)、Considered Options）。
- 型別Map・RTTI・型トークンによる具象設定管理 — 不採用: 具象設定の管理が共通層へ移る（出典: [ADR 0051](../../adr/0051-nn-forward-prepares-concrete-calls-and-purpose-owned-execution.md)、Considered Options）。
- 公開PrepareCallによる二段階操作 — 不採用: 呼出操作が増える。別に構築するCallInfoをForwardへ渡す形で足りる（出典: [ADR 0051](../../adr/0051-nn-forward-prepares-concrete-calls-and-purpose-owned-execution.md)、Considered Options）。
- ForwardUpToへのattention専用受け皿とNetwork専用診断メソッド — 不採用: 汎用APIへmodule固有の目的・診断名が漏れる（出典: [ADR 0055](../../adr/0055-forward-capture-request-keyed-carries-module-diagnostics.md)、Considered Options）。
- NN実行Stateのスロットへ診断値を書く形 — 不採用: Stateは呼出側から読めず、部分forwardはStateを持たない既定経路である（出典: [ADR 0055](../../adr/0055-forward-capture-request-keyed-carries-module-diagnostics.md)、Considered Options）。
- 別型の汎用診断captureを足して既存BranchCaptureも残す形 — 不採用: 編集は最小でも1関心2機構になる（出典: [ADR 0055](../../adr/0055-forward-capture-request-keyed-carries-module-diagnostics.md)、Considered Options）。
- ReplayBufferから別に一様抽出する勾配ノイズprobe — 不採用: 実更新と抽選分布・IS重みが違い、forwardも増える（出典: [ADR 0054](../../adr/0054-gradient-noise-scale-in-band-microbatch-split-includes-bf16.md)、Considered Options）。
- BatchNormの専用検出・禁止 — 不採用: 独立サンプルとして解釈できる条件を文書化し、構成と解釈は利用側に任せる（出典: [PRD092](../../memo/092_gradient_noise_scale_10prd.md)、§10.2）。
- attention entropy専用のfeatureキー — 先送り: 今の構成ではTransformerがfeature閉包内にある。再開条件: Transformerがfeature閉包の外へ置かれたとき（出典: [PRD093](../../memo/093_attention_entropy_diagnostics_10prd.md)、§5）。
- 構築時dummy forwardで層数を数える追加API — 不採用: 黙ったNaNは最初の測定のfail-fastで防げ、APIを1つ増やす必要がない（出典: [PRD093](../../memo/093_attention_entropy_diagnostics_10prd.md)、§5）。
- 勾配を止める NN ブロック（Detach） — 不採用: 遮断は Learner が特徴量を補助 Network へ渡す seam で行う（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§4 D6・§5.3）。
- Network の公開出力の専用記法（net.output）や Head の pass-through — 不採用: `net.body.output` の鍵を Network の出力にも残す（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§4 D4、[ADR 0062](../../adr/0062-networkmodel-holds-auxiliary-network-fed-by-primary-outputs-with-target-used-only-for-acting.md)）。
- Head の精度境界フラグ（head_fp32 など） — 不採用（持たせない）: Head と loss の FP32 は構造と autocast の方針が保証するので、BF16 は有効無効と適用箇所の設定だけにする（出典: [PRD033](../../memo/done/033_imagecls_bf16_head_10prd.md)、確定した設計判断 4）。
- SN の per-weight の上書き（ResBlock の weight_norm1 / weight_norm2 を weight ごとに設定する形） — 先送り（deferred gate）: 空間的な選択は当面ブロック・インスタンス単位で足りる。再開条件: Gogianu 型の層選択の実験（1 層だけ SN）が決まったら（出典: [PRD065](../../memo/done/065_nn_spectral_norm_10prd.md)、D11・複雑度監査）。
- DropPath・Dropout などの確率的 module の乱数を purpose stream に分ける形 — 先送り（deferred gate）: 標準 Dropout は generator 引数が無くマスクの自前実装（cuDNN 融合経路の喪失）が要り、移行は既存 Run との同 seed の連続性を切る。再開条件: 構成変更に対する再現性の直交化の実益が決まったら、等価性の説明を持つ別 PRD で（出典: [PRD065](../../memo/done/065_nn_spectral_norm_10prd.md)、複雑度監査）。
- zero_grad の変更 — 不採用（対象外）: LibTorch 2.11 の zero_grad は set_to_none = true が既定で、既にカーネル起動がゼロである（出典: [PRD011](../../memo/done/011_fused_adamw_10prd.md)、Context（背景・目的）・11. Out of Scope）。
- 設定レベルの taus-bind fail-fast と推移的到達性の検査（旧 D7） — 不採用（D15 で廃止）: フレームワークは局所的・決定的に判定できる契約だけを検証し、未使用入力の WARN と IQN Head の rank 検証に置き換え、NN 設定の整合は使う側の責任とする（出典: [PRD001](../../memo/done/001_iqn_10prd.md)、確定した設計判断 D7・D15）。

## 変えるときの条件

一般の条件は[リファクタリング観点](../../quality/refactor.md)の「ガードレール」、テストの充足は[定点統計](../../../reports/stats/trend.md)の「テスト充足」を見る。

- self_attnの登録名とパラメータ名を維持し、既存checkpointを利用できるようにする（出典: [PRD012](../../memo/done/012_sdpa_attention_10prd.md)、1.2 MultiheadAttentionImpl のメンバ）。
- dropout/drop-pathのrateが0の経路は従来出力と一致することを確かめる（出典: [PRD024](../../memo/done/024_nn_dropout_droppath_10prd.md)、受け入れ基準）。
- ImageClsのhead化はFP32の等価性を先に確認し、そのあとBF16を検証する（出典: [PRD033](../../memo/done/033_imagecls_bf16_head_10prd.md)、確定した設計判断）。
- 既存のHead/SN FP32保護と用途別AMP精度を維持する。Noisy無効の既存チェーンは決定論backendでmetrics checksumを比較し、sample時の乱数列の割当変更を無効側へ持ち込まない。比較の相手は実装前に保存した基準の実行体・依存DLL・出力とする（PRD060は基準を取り損ねた）（出典: [PRD084](../../memo/084_noisynet_10prd.md)、§8.2・§12・§13）。
- 診断ON/OFFで同seed・決定的モードの学習系列を比較し、学習の.grad・optimizer state・RNGを変えない。費用は反復A/Bで実測しprofiler合計でend-to-end増加率を代用しない（出典: [PRD092](../../memo/092_gradient_noise_scale_10prd.md)、§7.1・§7.2）。
- captureへ移す既存branch出力の値とdetachを保ち、captureなしforwardは不変とする。同seed・決定論設定の診断ON/OFFで学習由来metrics checksumとRNG・buffer等への非干渉を確認する（出典: [PRD093](../../memo/093_attention_entropy_diagnostics_10prd.md)、§6 1・5）。
- Body の公開出力を Network の出力に残しても、Head の出力・forward の数値・RNG の消費を変えない（出典: [PRD098 TempoRL](../../memo/098_temporl_skip_policy_10prd.md)、§5.3・§5.9）。
- 呼び出し情報に倍率を省いたとき（倍率1）は、NoisyNetの部品の値と乱数の消費を今と同一に保つ（出典: [PRD107](../../memo/107_noisy_gain_lane_ladder_10prd.md)、§5.3・§7の受入1）。
