# 内的報酬による探索の比較

[anet-lab](../../../README.md) › [wiki の目録](../index.md) › [機構](../index.md#機構)

## 今の結論

NGU 型のボーナスと E3B の比較結果は、学習器・環境・合成方法に依存する。MiniHack での結果を Atari の優劣へ持ち込めず、anet の BTR を基にした構成での効果はまだ測っていない。KFM の命中にボーナスが出るかも、逆動力学の特徴がバーの差を保つかに依存する。GridMazeのCPU・256 lane・torch thread 1・Releaseでは、既定RNDの時間はなしの1.339倍だった。Montezumaの64 lane・CUDA・Releaseでは、既定RNDの時間はなしの1.661倍で、RNDの時間の62.66%を採点の統計の区間が占めた。Montezumaのサンプル効率優先＋RNDの30M（1本、RNDなしの対照なし）では、学習側で部屋7に入るゲームが現れた24〜25Mにbonusの平均が前後の1Mより高く、同じ24〜26MにlossとQの最大の平均が上がった。LunarLanderの3 seed×2Mでは、既定RNDを混ぜても評価は基準と同じ帯だったが、bonusは採点5〜10万件で消えた。predictorを採点50,000件ごとに初期化するとbonusは周期信号として続いたが、終盤の評価は同じ帯のままで、1 seedが途中で崩れ、Qの最大の平均と勾配ノルムは全seedで基準より大きかった。MontezumaのRND（β 0.01・Munchausen無効）では、2500点のあと外的報酬の残らない局面でQが18行動ともほぼ同じ値になり、Greedyが動かなかった。同じβ 0.01でMunchausenを有効にすると、Greedyの2500点は99/160から5/160に下がり、500点で止まるゲームが多かった（seed 1、各1本）。同じ実行体・同じ設定でseedだけを1から2に変えたRunは、誤差の標準偏差が0.55〜0.56倍、内的報酬の平均が8M以降で1.6〜3.2倍になった。Taigaらの式のRNDは、Munchausenの有無に依らずMontezumaの鍵より先へ進まなかった。PRD123の既定のwarm-up（200,000 step、predictorだけを学ぶ）にしたβ 0.01・Munchausen無効のRun（seed 1）は、内的報酬の平均が前の実行体の2.3〜14倍で、学習側は部屋13・14・21・22に入り3500〜3700点が出たが、Greedyの2500点以上は26.2Mからだった。同じ設定のseed 2は、誤差の標準偏差がseed 1の0.33〜0.68倍で、Greedyの2500点以上は29.2Mからだった。seed 1を通算50Mまで延ばしても、学習のbatchの報酬の絶対値のうち84〜87%を内的報酬が占め、Greedyが止まった部屋14の局面では内的報酬は0だった。既定（`whiten`）のRNDでは、誤差の統計の二乗偏差の88〜99%を最初の200k exp stepの誤差が占め、KFMでは内的報酬が報酬の数%（Munchausenの項の約1/100）にとどまり、Montezumaでは誤差の標準偏差の膨らみが9〜17倍から3〜4倍へ薄まった。最初の20万件を統計に入れたまま時定数100万件の直近重みに替えても、膨らみが2倍を切るまで510〜700万件かかる見積もりだった。anetの既定はnext_stateを採点するときdoneのlaneの内的報酬を0にするが、Taigaらは終端の遷移も採点して0にしない。KFMの10Mでは、PRD123の既定（warm-up中の誤差を統計に入れない）で内的報酬の平均が同じ実行体・同じβ 0.1の前の中身の12〜36倍になり、誤差の標準偏差の2M〜3Mと9M〜10Mの比は1.95から1.49〜1.62に下がった。β 0.1では内的報酬の割合が2M〜3Mに0.5を超えてε 0.01の評価がRNDなしの8本の範囲を下回りがちで、β 0.03では同じ範囲の中だった。群を内的報酬の割合で並べると、割合が大きいほど評価の点が低かった。β 0.03でwarm-upを1,000,000件に延ばした2本は、比が1.37・1.07で、200,000件の4本（1.50〜1.54）を下回った。内的報酬の平均は同じseedの1.7・2.6倍だった。Montezumaでβを0.01から0.003に下げたRunは、学習側で部屋7より先へ進まなかった。文献では、外的と内的の価値を別々に学ぶ形（Agent57・Burdaら）が内的報酬の重みへの頑健さと探索した部屋の数を改善した。

## 分かっていること

- 文献の比較条件: NGU 原論文は R2D2 を基にした再帰型の学習器を使う。RLeXplore の共通学習器上のモジュール比較とは構成と予算が違い、公開スコアから同じ条件での順位は付けられない（出典: [内的報酬の PRD](../../memo/924_intrinsic_reward_novelty_10prd.md)、§2.8）。
- 文献の比較条件: Henaff ら（2023）の NGU 型ボーナスとの比較は主に MiniHack で、Montezuma's Revenge では E3B 単独と RND・併用でも結果が異なる。E3B を NGU の無条件な上位互換とする根拠にはならない（出典: [内的報酬の PRD](../../memo/924_intrinsic_reward_novelty_10prd.md)、§2.8）。
- 未検証の仮説: KFM のバーの縮みを逆動力学の特徴が保存すれば、報酬 0 の命中にも新しさの手応えを与えられる。ただし自機の姿勢だけで行動を予測できる可能性があり、制御可能な変化が必ず特徴に残る保証は無い（出典: [内的報酬の PRD](../../memo/924_intrinsic_reward_novelty_10prd.md)、§2.5）。
- 調査の範囲: anet の BTR を基にした構成での NGU／E3B の効果は未測定であり、今回の調査では直接比較に使える BTR＋NGU 全体の実績も確認できていない（出典: [内的報酬の PRD](../../memo/924_intrinsic_reward_novelty_10prd.md)、§3「現状」・§2.8「NGU・E3B・BTR の関係と、比較結果の適用範囲」）。
- 切り出し: RND による一生の新しさは lane 別の記憶を持たず、facade（`DefaultDQNAgent::UpdateFromBatch`）で次観測を採点して報酬へ畳めば Replay・Actor の契約を変えずに腕にできる。KFM では対照腕で、判断に効くのは GridMaze の到達率と費用・統計の確認（出典: [RND の腕の暫定 PRD](../../memo/116_rnd_lifelong_novelty_10prd.md)、§1.1・§4 D1・D2・§7）。
- 切り出し: 一生の新しさの口は「倍率 α を返す採点・補助学習・診断・保存」の 4 操作で、RND の本体は DQN から見えない非公開の実装に閉じる暫定の設計（出典: [RND の腕の暫定 PRD](../../memo/116_rnd_lifelong_novelty_10prd.md)、§5.1・§5.7）。
- 比較対象の実装: Taiga ら（ICLR 2020）の Rainbow＋RND は、行動した観測 x_t を agent step ごとに 1 件で採点・学習し、誤差の z を分散に相当する値で割って 0.00005 倍し、Runner が [−1, 1] に clip した外的報酬に足す。合計は clip せず、負の値もそのまま入る。観測の統計は正規化後の値で更新する。Burda ら・anet が採点するのは次観測 x_{t+1}（出典: [RND の腕の暫定 PRD](../../memo/116_rnd_lifelong_novelty_10prd.md)、§2.1・§8.1 の 6）。
- RND の尺度の条件: target と predictor の出力の尺度が揃っていれば、初期値の種類（he／xavier と直交）で新しさの判別は大きく変わらず、target だけ小さいと predictor が誤差を下げられず判別が落ちる。PyTorch の写しで Montezuma の画面を 6 万 step 学習した判断材料で、受入の基準ではない（出典: [RND の腕の暫定 PRD](../../memo/116_rnd_lifelong_novelty_10prd.md)、§2.1）。
- 設定の落とし穴: anet の層カタログ `Conv2d_S`・`Conv2d_M` は葉の階層が読み込みと合わず、2026-11-06〜07 の Atari の RND の Run は既定の 128@3/1 ×2（1 Network 約 1 億パラメータ）で動いていた。写しの比較では判別は落ちず、実証された害は速さと checkpoint の大きさ（出典: [RND の腕の暫定 PRD](../../memo/116_rnd_lifelong_novelty_10prd.md)、§2.1）。
- GridMaze では RND の新しさが最初の数千 step で尽きる: 観測が正規化した (x, y) の 2 値で盤面は固定（`seed_mode = process`）なので入力は 25 通り以下。ε = 1 から始まる 256 lane が全部を踏み、predictor が覚え切って一生の誤差平均を下回り続け、既定（`clipped`・`whiten`）の bonus は 0 になる（2026-11-07 の `run_20261107-212611`: 1,551 点中 9 点以外 0、predictor の損失 3e-9）。手で通っていないセルへ誘導したときの失敗は未踏ではなく off-path の Q の粗さ（出典: [RND の腕の暫定 PRD](../../memo/116_rnd_lifelong_novelty_10prd.md)、§6.4・§7）。
