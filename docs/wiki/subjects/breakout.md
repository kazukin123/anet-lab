# Breakout

[anet-lab](../../../README.md) › [wiki の目録](../index.md) › [題材](../index.md#題材)

## 今の結論

LN512はRR4の天井を押し上げた一方、RR1では対照のブレ幅内だった。BTR型NNとSNの効果はreplay ratioと学習予算に依存し、SN無しの早期優位が後期に反転した。

## 分かっていること

- sticky actionsとepisodic lifeを分けた比較では、sticky 0化で成績が伸び、sticky 0.25固定のepisodic life単独では改善しなかった。設定の効果を他の前処理へ一般化しない。（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md)、現時点のまとめ・探索ブロック03）。
- LN512はRR4の天井を押し上げたが、RR1では対照のブレ幅内だった。（出典: [2026-08-31_rr4-ceiling-ln512.md](../../experiments/default-dqn/atari/2026-08-31_rr4-ceiling-ln512.md)、現時点のまとめ。Run: run_20260831-050214_i_rr4_ln512_breakout / run_20260831-124349_j_rr1_ln512_breakout）。
- UQEでtrain分布は動いたが、evalの差は複製幅内だった。挙動方策を替えた腕の学習品質をtrain平均だけで判定しない。（出典: [2026-09-07_uqe-exploration.md](../../experiments/default-dqn/atari/2026-09-07_uqe-exploration.md)、現時点のまとめ。Run: run_20260907-005108_munch_uqe_s099e05 / run_20260907-033751_munch_uqe_s09e05）。
- BTR型NNの効果とSNの符号はreplay ratioと学習予算に依存し、SN無しの早期優位が後期に反転した。（出典: [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md)、現時点のまとめ・探索ブロック01〜03。Run: run_20260912-074000_rr4_btrfull_munch / run_20260913-025232_rr4_btrnosn_20m）。

- replay_ratioについて: 旧 net では **RR2 が最良**（25-50M 壁突破率 14.33% 対 RR1 11.40 / 11.64%、複製幅 0.24pt の 11 倍）で、RR4 は 8.85%。**その原因は再利用回数（勾配回数ではない）による replay 分布への過学習**（`RR4/B512` 8.84% ≈ `RR4/B256` 8.85%、同じ勾配頻度の `RR2/B256` は 14.33%）。**2026-09-12、BTR の NN構成へ替えると RR4 が RR2 を超えた** — 25-48M プールで btrfull（RR4）589.7 / 15.77% 対 RR2（旧 NN構成）545.7 / 13.91%、RR4 素 455.8 / 8.56%。**逆に RR1 では BTR NN構成が −54.1 で全腕最下位**になるので、**`replay_ratio` と NN構成は独立に選べない**（[2026-09-12](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md) 探索ブロック 10）。**実時間で比べると RR1 が一貫して有利。** 2026-09-17 に eval を切った清浄スループットが両側そろい、**旧 net RR1 6,783 exp/s 対 btrfull 1,804 = 3.76 倍**、100M を 4h05m 対 50M を 7h42m で確定した。（出典: [2026-09-08_replay-ratio-mechanism.md](../../experiments/default-dqn/atari/2026-09-08_replay-ratio-mechanism.md) / [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md) / [2026-09-15_replay-lane-window.md](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md)、現時点のまとめ・対応する探索ブロック）。

- NN構成について: 12-15M の寄与順は **Pool6 +55.1 > 融合位置 +39.9 > SN 除去 +32.9 > SN 追加 −23.8**。**ただし RR1 では同じ Pool6 が −28** で符号が反転する。**6×6 は内点ではなく 4×4 がさらに +25.8**（18-20M）だが、これは trunk512 骨格での測定で、**本番構成（btrfull）への移植は未測**（融合次元が同時に動くため新規配線が要る）。**SN は早期コスト・後期利益**で、ε=0 断面では **−98.7**。**機序は「ε=0 を上げる」ではなく「長い訓練で貪欲変換が潰れるのを防ぐ」** — SN 無しは ε=0.01 が伸び続けている（20M 549.4 → 50M 576.4）のに ε=0 が下がり（597.8 → 586.4）、貪欲変換が **+48.4 → +10.0** と潰れる。SN 有りは逆に **+55.5 → +82.2** と育つ（同一系統の resume での観測なので Run 間ばらつきではない）。**実時間コストと成績コストは別の層に乗っている** — stem conv 3 本の SN は実時間 +5.8% を払って成績にはほぼ効かず（12/15 − 15/15 = +1.1〜+7.9）、res block 12 本の SN は実時間 +0.3% で成績側の本体（0/15 − 12/15 = +31.8）（[2026-09-12](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md)、[2026-09-15](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md) 探索ブロック 04）（出典: [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md) / [2026-09-15_replay-lane-window.md](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md)、現時点のまとめ・対応する探索ブロック）。

- NN = IMPALA-CNN（Scale=2）について: Nature CNN 比で 50M 時 eval1 147.7 対 115.7。Nature は 44M でピークアウトするが IMPALA はピークが最後尾。≥400 点は IMPALA だけが出す。Scale=2 は BTR 準拠（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md)、現時点のまとめ・対応する探索ブロック）。

- dueling V/A の活性について: RR1 / 旧 net / 50M で、V/A の隠れ層を SiLU → ReLU にすると 25-50M の壁突破率が 1.35% → 3.48%（2.6 倍）。**効果の 95% は A ストリーム**で、A だけで 3.31%、V だけでは 1.89%。dueling の集約 `q = v + (a − mean a)` では argmax Q = argmax A が厳密に成り立つので、区分線形の A が行動の入れ替わり（`01_action_churn_ratio`）を 0.0301 → 0.0104 と約 1/3 にする。**V を ReLU にすると `41_probe_dormant_ratio` は下がるが成績はほとんど動かない**（機序指標の改善が成績につながらない直接例）。LeakyReLU は 2.48% で、churn は ReLU と同じだけ下がる。残り半分は硬いゼロから来るが、その経路は churn ではない。100M でも崩れず、95-100M の 8.70% が最終窓で最高だった（[2026-09-01](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) 探索ブロック 05・11・12・19・20）（出典: [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md)、現時点のまとめ・対応する探索ブロック）。

- τ 埋め込みの活性について: 融合 512 で τ 埋め込みだけを ReLU にすると `41_probe_dormant_ratio` が 0.043 → 0.123（2.9 倍）になり、壁突破率は 1.71% と基準並みに留まった。融合 2304 では同じ変更で dormant が 0.190 → 0.140 と下がり、壁突破率 4.96% が複製対（3.07% / 4.18%）の上限を超えた。seed 2 で取り直すと 3.77%（対の平均 4.37%）で、seed 1 / 2 の差 1.18pt は btrstruct の同 seed 複製対の差 1.12pt と同程度だった（[2026-09-01](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) 現時点のまとめ33・探索ブロック 27）。ReLU が半分のチャネルを止めても、2304 なら 1,152 チャネルが残る（[2026-09-01](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) 探索ブロック 11・24）（出典: [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) / [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md)、現時点のまとめ・対応する探索ブロック）。

- replay_capacity / num_envsについて: lane 窓 16,384 の 2 点（`envs64`/1M と `envs128`/2M）は ε=0 で **685.12 対 685.30**（学習 Run 複製幅 18.7 の 1/100）。この 2 点は `num_envs` も遷移の総寿命も 2 倍違う。**lane 窓 8,192 だけが 615.73 で −69.4**。効き方は閾値的で、**貪欲エピソード長 1 本ぶんでは壊れ 2 本ぶんで直る**。**機序としては「lane step で測った窓」が制御変数で、「更新数で測った量」はどれもラベルを追わない** — 遷移の総寿命（16,384 / 16,384 / 32,768）も完全同居時間（8,634 / 884 / 17,268）も一致せず、**`n_step` 由来の「価値を逆行させる機会が多いほど良い」という筋はそのままでは成立しない**（機会が 2 倍の G2 が G1 と同点）。言えるのは **「lane 窓 / エピソード長が同じなら更新を何回かけても着地点は同じ」**まで。**その比が何を通じて成績を決めるかは未測**で、「完全なエピソードが載っていること」自体が要件とは言いにくい（`n_step=3` は 1 更新に完全なエピソードを要求しない）。閾値がなぜ 1 本と 2 本の間に来るのか、なぜ ε=0 にだけ出るのかは未測。**この差は ε=0.01 にはほとんど出ない**（−4.8 = 複製幅の内側）ので、`52_eval2` の平均だけ見ていると見落とす。train 側の `42_env/41_game_score_ge432_ema` は複製幅の 3.8 倍で分離する。`46_agent_replay_fit/24_sampled_age_mean` が lane 窓 / 1.82 を返すので、`game_len` と割れば Run 中に診断できる。**エピソード長はゲーム間で 8.2 倍違う**ので、`num_envs=128` / `capacity=1M` では **breakout と name_this_game だけ危険域**（[2026-09-15](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md)）。旧根拠の「`num_envs=128` 採用（throughput が 128 で頭打ち、学習効率は 128 まで無傷）」は throughput については有効だが、**成績については lane - spatial exploration（ε ラダー 上端 0.4）について: ON/OFF と上端 4 点（0.01 / 0.2 / 0.4 / 1.0）で単峰。eval1 平均 257.7 → 358.3、`<100` 15.5% → 1.4%、p10 83 → 273。上側はほぼ動かず**下振れだけが消える**。0.4 対 0.2 は平均差 5.8σ。throughput コストはほぼゼロ。**ラダーの端点は `num_envs` に依存しない**（log スケールで `[eps_end, eps_start]` を等分するので、比率分布は 64 と 128 で小数点以下まで一致する）。**2026-09-27、qbert（サンプル効率優先 50M、1 seed）では上端 0.4 の旧ラダーが第 8 面の経験を飢えさせていた** — train の第 8 面到達率は lane の ε で急落し（ε 0.01〜0.016 で 37.6%、0.1 以上で 0.1%）、ラダーを 1e-4〜0.05 に下げると第 8 面の突破が 41.5M から出始めた（旧ラダーは 0 本）。代わりに序盤は遅い（[2026-09-25](../../experiments/default-dqn/atari/2026-09-25_sample-efficiency-profile-atari5.md) 探索ブロック 03）。**2026-10-02 追記** — 同じラダーの 128 env / 2M を seed 2・3 で取り直すと、45-50M の突破率は 4.7% / 0.3%（seed 1 は 5.1%）。battle_zone に当てると ε=0 断面の最良は 118,388 対 115,533（+2%）でほぼ同点、序盤は遅い。BTR 型の ε の経過（0〜6M はラダー 0.06〜1.0、6〜25M は全 lane 0.01、以降は上のラダー）は qbert で ε 腕と同等（45-50M 7.7% 対 5.1%）（[2026-09-27](../../experiments/default-dqn/atari/2026-09-27_btr-gap-qbert-bz.md) 探索ブロック 01〜03）（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md)、現時点のまとめ・対応する探索ブロック）。

- UQE（train 方策）について: Breakout で成績中立（[2026-09-07](../../experiments/default-dqn/atari/2026-09-07_uqe-exploration.md)）。qbert の 64 env / 1M の上でも、45-50M の第 8 面突破率 45.8% は env64 の 3 seed の幅（0.7〜45.6%）の中。τ が楽観側の lane だけが抜けやすくなる形も出ない（[2026-09-27](../../experiments/default-dqn/atari/2026-09-27_btr-gap-qbert-bz.md) 探索ブロック 04）（出典: [2026-09-07_uqe-exploration.md](../../experiments/default-dqn/atari/2026-09-07_uqe-exploration.md) / [2026-09-27_btr-gap-qbert-bz.md](../../experiments/default-dqn/atari/2026-09-27_btr-gap-qbert-bz.md)、現時点のまとめ・対応する探索ブロック）。

- 行動に使うネットの同期（actor.[train].sync_interval）について: 25 step（3,200 遷移）にすると qbert の序盤は速い（ε=0 断面 20.4M で 25,850 対 22,298）が、第 8 面の突破は定着しない（45-50M 1.8%）。序盤の速さは 128 env / 2M の seed の幅（20.4M で 17,390〜22,298）の上端にあたる（[2026-09-27](../../experiments/default-dqn/atari/2026-09-27_btr-gap-qbert-bz.md) 探索ブロック 03）（出典: [2026-09-27_btr-gap-qbert-bz.md](../../experiments/default-dqn/atari/2026-09-27_btr-gap-qbert-bz.md)、現時点のまとめ・対応する探索ブロック）。

- grad_clip_tauについて: 5 は毎 update 発動して安全弁でなく正規化器になり、median 134 対 323 で劣る。30 は当時の `grad_norm` 6.0-15.4 に対する値で、RR1 の現在は平均 0.5-1.4（全区間 max 28.6）なので 10 でも平常時は不発（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md)、現時点のまとめ・対応する探索ブロック）。

- weight_decay = 0について: 0.1 は 0-30M で +40〜99% 先行するが 30M で交差し 45-50M で **−43.4%**。機構自体は働くが（`q_gap/q_max` −25%）成績は落ちるため、**Q の過鋭化は症状であって直接下げにいく対象ではない**。**2026-09-11 に RR4 で 0.01 を試行。25-33M 窓で 8.89% 対 RR4 素 8.41% と複製幅（0.42pt）の中で、天井は動かなかった。**しかも `01_loss` は 0.331 と全腕最低で、**正則化のつもりの腕が replay への当てはまりを最も良くしている**（[2026-09-08](../../experiments/default-dqn/atari/2026-09-08_replay-ratio-mechanism.md) 探索ブロック 06）（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md) / [2026-09-08_replay-ratio-mechanism.md](../../experiments/default-dqn/atari/2026-09-08_replay-ratio-mechanism.md)、現時点のまとめ・対応する探索ブロック）。

- per_beta = 0.2 固定（アニール撤去）について: 旧根拠: 10M < 50M で予算の半分が最良、「総予算に合わせる」は実測が反証。**新: `per_beta_step` は `${@vars.half_exp_step}` を参照する唯一の学習ハイパラで、予算違いの Run が prefix 比較できなかった。0.2 固定は RR1・RR4 とも成績中立**。BTR は IS 重みを β でなく `alpha` = 0.2 で計算しており（`PER.py:324`）、差分も減る。**`21_grad_norm` 0.741 → 2.053・`01_loss` 0.204 → 0.631 が不連続に変わるため、この日をまたぐ勾配系の比較は不可**（[2026-09-01](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) 探索ブロック 02・03）（出典: [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) / [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md) / [2026-08-29_bundle-fix-rebaseline.md](../../experiments/default-dqn/atari/2026-08-29_bundle-fix-rebaseline.md)、現時点のまとめ・対応する探索ブロック）。

- BF16について: γ 0.997 で相対 action gap が 4〜5 分の 1 に潰れ、余裕は 1.2-1.7 ULP。1 を割る局面でも成績は最良で、6 例の反例により**成績の予測子ではない**と確定した（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md)、現時点のまとめ・対応する探索ブロック）。

- q_gap（定常値）について: 95-100M で RR2 0.0798 > RR1 0.0729 > RR4 0.0579 となりスコア順（RR1 > RR2 > RR4）と一致しない。可塑性の代理として使えるのは**過渡の深さ**だけであってレベルではない。**2026-09-17 に追加の反例** — lane 窓の ε=0 ラベル（good / bad / good）に対し `19_q_gap_rel_ema` は 0.0429 / 0.0315 / 0.0339 で追わない。`action_churn` `loss` `dormant` `srank` も同様に追わなかった。**2026-09-20 に条件付きで覆った** — lane 窓 8,192 では確かに動かないが、**4,096 では全部動く**（`01_loss` 0.614 対 0.741〜0.765、`04_td_std` 0.532 対 0.615〜0.625、`16_q_std` 0.553 対 0.633〜0.646、`17_q_gap` 0.172 対 0.206〜0.234、`action_churn` +24%）。**検出限界の問題**であって無感度ではない。向きは「当てはまりが良いのに成績が悪い」で、[2026-09-08](../../experiments/default-dqn/atari/2026-09-08_replay-ratio-mechanism.md) の過学習署名と同じ（[2026-09-15](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md) 探索ブロック 07）（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md) / [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) / [2026-09-08_replay-ratio-mechanism.md](../../experiments/default-dqn/atari/2026-09-08_replay-ratio-mechanism.md)、現時点のまとめ・対応する探索ブロック）。

- プロトコルについて: sticky 0.25 が Breakout で支配的（0 にすると train 生スコア 42 → 119）。`episodic_life` は単独では効果ゼロ。**2026-08-28 以前の全 Run は noop 0** — 2026-08-27 に root ラダーを 30 へ変更したものの `run.@v5_iqn_impala_x2` が `@v5_noop0` を再指定して打ち消しており、2026-08-29 に修正した（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md) / [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md)、現時点のまとめ・対応する探索ブロック）。

- evalについて: **ε=0.01 を選んだ当初の理由は 2 つとも失効した。** (1)「ε=0 は `fire_reset=false` と組で FIRE デッドロックに落ちる」— **ε=0 断面 9 本が `fire_reset=false` のまま完走**しており、いまの強さでは再現していない（2026-09-07 の観測は当時の弱い方策での話）。(2)「ε=0.01 → 0 の得が腕依存だから腕間比較は ε=0.01」— **その腕依存こそが測りたい信号だった**。SN の −98.7 も lane 窓の −69.4 も ε=0.01 では見えず ε=0 でだけ出る。**20M の ε=0 断面は腕を判定できない**（50M で −98.7 の SN 軸が 20M では +5.0。学習 Run 複製幅 18.7 に対し 4 腕とも内側〜境界上）。**ブレ幅は 2 種類ある** — eval プロトコル自体（同一スナップショット 2 回）は 2.12〜16.2 点で**水準が上がるほど広い**ので一般の物差しにできず、**判定に使うのは学習 Run どうしの 18.7 点**（ε=0.01 の 6.7 より広い）。**eval の実時間コストは設定で桁が変わる** — `btreval_r1` の RR1 100M Run は eval デューティ **99.7%**、eval / train の env step 比 **1.76**（旧設定は 0.27）。**`interval` を learn step で書くとエピソード長の伸びに比例してコストが膨らむ**（同じ RR1 100M Run の中で 5-10M 窓 −54% が全区間平均 −65% になる）。**eval のコストは RR で regime が変わり、RR1（env 律速）で −54%、RR4（learner 律速）で −20%**。**PRD061 の Actor カタログ（`actor.[key].policy`）でスロット別に ε を指定できるようになり、2 チャネル構成で着地した**（ε=0.01 の時系列 + ε=0 の断面を同一 Run 内で並走させる。断面を別 Run へ切り出す必要が無くなった）。**この構成の複製幅は [2026-09-15](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md) 探索ブロック 07 で引き直した。****`24_game_len_max` はセッション内の最大値なので `eval_episodes` が違う Run の間で比較できない**（[2026-09-15](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md) 探索ブロック 03-05）（出典: [2026-09-15_replay-lane-window.md](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md)、現時点のまとめ・対応する探索ブロック）。

- per_alpha / adam_eps / update_warmup_steps / IQN τ 数について: 0.2 / **1.95e-5**（2026-08-29 から） / 200,000 / 8（online・target・行動選択とも）。**2026-08-28 以前の全 Run は `adam_eps` = 1e-4** — `A1` に置いた値をチェーン後段の `@bf16` が上書きしており、A2 へ移して修正した（出典: [2026-08-17_baseline.md](../../experiments/default-dqn/atari/2026-08-17_baseline.md) / [2026-08-29_bundle-fix-rebaseline.md](../../experiments/default-dqn/atari/2026-08-29_bundle-fix-rebaseline.md)、現時点のまとめ・対応する探索ブロック）。

- PER 初期優先度について: RR1 では `07_evicted_unsampled_ratio` が 0.377 まで上がって −9%。**RR4 ではその経路が 0.0276 とほぼ閉じ、成績も実時間も中立**（5 窓で符号が交互、平均 +0.6 / +2.0）。**ただし PER の識別性能は明確に改善する** — 未サンプル群の TD 比が **1.06 → 0.86**、年齢が 2.1 倍。`max` では「まだ引かれていない経験の方が難しい」という倒錯が起きている。代償は `action_churn` +53% / `dormant_ratio` +46%（[2026-09-12](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md) 探索ブロック 13）（出典: [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) / [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md)、現時点のまとめ・対応する探索ブロック）。

- PER 初期優先度の観測量 07_evicted_unsampled_ratio には内部最適がある: RR1 で fixed 0.3 にすると 4M の 0.269 から 49M の 0.354 へ漂い（max は 0.237 → 0.249）、壁突破率は 0.75% 対 1.35%（同設定複製対の平均）で半減した。RR4 では 0.0001 まで下がり、全データが最高優先度で入って優先度付けが機能しない。max の初期化は分布に追従するが、1.0 から始まり上にしか動かない単調な高水位である（出典: [999_metric_targeted_hyperparam_control_10prd.md](../../memo/999_metric_targeted_hyperparam_control_10prd.md)、Context §2〜§4；[2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md)、現時点のまとめ8・9）。

- target 更新機構（soft / hard）について: soft と hard は env 時間を揃えれば成績が同水準だが**分散が違う**。同一設定の複製差は hard 0.304pt（N=4）に対し soft 1.65pt。soft は 25M まで一致してから発散する例があり、予算を延ばしても縮まない。1 変数比較の基準として再現性が要るため hard を採る。**BTR も hard を採用しており、値も一致した**（出典: [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) / [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md)、現時点のまとめ・対応する探索ブロック）。

- target 更新速度（hard_update_interval）について: 旧値は BTR の C=500 を RR4 前提のまま RR1 へ持ち込んだもので、**8 倍の遅れ**にあたり壁突破率 3.48% と全設定中最低だった。BTR の C=500 / hard C=125 / soft τ=0.008 の 3 者は env 時間で 32K exp step に一致するため、**この軸は grad step ではなく env 時間で決まる**（`940_target_update_step_axis_10prd.md`）。なお 32K の周辺（soft 0.008 / 0.020 / 0.050）の順序は複製幅に埋もれており、**32K は代表値であって内点最適として確認したわけではない**（出典: [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) / [2026-09-15_replay-lane-window.md](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md)、現時点のまとめ・対応する探索ブロック）。

- Munchausen RLについて: hard125 基準からの 1 変数（＋強制される Double OFF）で、25-50M 壁突破率が **11.35 / 11.52%** 対 基準 6.00 ± 0.30%（N=4）。**本キャンペーン最大の単一効果**（差 5.435pt / Welch t = 31.2）。`use_double_dqn=false` 単独の対照は無効果なので**寄与はすべて Munchausen**。機序は相対 action gap の 3.6 倍化。**2026-09-06 に 100M へ延長し、95-100M で 18.68% / `≥600` 8.66% と最終窓が最高値**（50M の 1.62 倍）。**旧 net では RR4 と併用できなかった**（8.85%）が、**BTR NN構成の下では RR4 + Munchausen が最良構成になっている**（25-48M 15.77%）ので、この制約は NN構成に条件付きだった（[2026-09-01](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) 探索ブロック 28・29・31、[2026-09-12](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md) 探索ブロック 01）（出典: [2026-09-01_btr-feedback-arms.md](../../experiments/default-dqn/atari/2026-09-01_btr-feedback-arms.md) / [2026-09-12_btr-network-port.md](../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md) / [2026-09-08_replay-ratio-mechanism.md](../../experiments/default-dqn/atari/2026-09-08_replay-ratio-mechanism.md)、現時点のまとめ・対応する探索ブロック）。

- 予算について: 旧バンドルのラダー構成では 45M→80M で `≥432` が約 3-4 倍に立ち上がり、**ラダー無しの対照は 30M で完全に頭打ち**だった。予算が効くかどうかは予算の問題ではなく**データ被覆の問題**である。**2026-09-06、Munchausen + RR1 を 100M へ延ばすと 95-100M が最高値**で、50M は早い打ち切りと確定。一方 **BTR NN構成 + RR4 は 50M の ε=0 が 685 で頭打ちに見えていたが、2026-09-20 に lane 窓 32,768 で 719.85 まで伸びた**。**685 は予算の天井ではなく lane 窓の制約だった**。**2026-09-25、実時間優先の Atari-5（seed 2）でも 100M の 90-100M 窓が 5/5 で最高値**（40-50M 比で HNS +5.6〜+75.1%、Atari-5 回帰 +24.0%）。ただし qbert は第 8 面の手前での伸び、double_dunk は公表値の上位帯に着いたうえでの伸びである（[2026-09-21](../../experiments/default-dqn/atari/2026-09-21_realtime-profile-atari5.md) 探索ブロック 04）（出典: [2026-09-21_realtime-profile-atari5.md](../../experiments/default-dqn/atari/2026-09-21_realtime-profile-atari5.md) / [2026-09-25_sample-efficiency-profile-atari5.md](../../experiments/default-dqn/atari/2026-09-25_sample-efficiency-profile-atari5.md) / [2026-09-15_replay-lane-window.md](../../experiments/default-dqn/atari/2026-09-15_replay-lane-window.md)、現時点のまとめ・対応する探索ブロック）。
