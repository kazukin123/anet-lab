# AtariEnv のゲーム固有 RAM メトリクスは番号付き汎用キーで参照し、意味はゲーム別の RAM 定義が持つ

## 元の材料

[ADR 0046](../../../adr/0046-atari-ram-metrics-bound-per-game-to-numbered-keys.md) blob:ba45ce06980a972bb8cc4b2810050f647a5b3804

## 要点

- ゲームごとの RAM 番地と意味を設定で定義し、メトリクスから番号付きの ram_metric を参照する。
- 番号の解釈は Run に保存された AtariEnv の設定で確認できる。
- コードに固定せず、ゲームごとの観測対象を再ビルドなしで変えられる。
- 集計は実ゲーム単位とし、定義のない番号は trace で null、scalar は出力しない。
- 後の契約ではその Step の結果を読み、残機だけを失った回と実ゲームが終わった回を区別する。

## 内容

### 記録の定義

ゲーム固有の進行を示す RAM は番地も意味もゲームによって異なる。番地番号をメトリクス名に埋めず、ゲーム別に番号・ラベル・集約方法を結び付ける。ゲームごとの C++ 表を更新する再ビルドも避けられる。

### 集計期間

実ゲーム中の全フレームを対象とし、残機を失った際の soft reset をまたいで集計する。画面表示とログでも同じ定義を使い、確定値の時点は Step の結果から読めるようにした。
