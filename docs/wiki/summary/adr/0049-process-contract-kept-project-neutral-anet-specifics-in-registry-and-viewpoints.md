# プロセス契約とレビューエージェントの定義は、プロジェクトに依存しない文面に保ち、anet 固有のことはレジストリと観点に置く

## 元の材料

[ADR 0049](../../../adr/0049-process-contract-kept-project-neutral-anet-specifics-in-registry-and-viewpoints.md) blob:750b34c405a200a10ced78e6ec566dfffe6c8de7

## 要点

- 工程とレビューエージェントの定義は、複数プロジェクトで改善を持ち寄れる共有の文面にする。
- anet 固有の対象や用語への対応はレジストリとレビュー観点で示す。
- anet 専用に書き換える案では他のプロジェクトとの差分を追いにくい。
- ローカルでの変更を一切禁じる案では、使用時に見つけた改善を反映しにくい。
- 後の決定で共有コアにおける skill・エージェント・アダプタの anet- 接頭辞を認めた。
