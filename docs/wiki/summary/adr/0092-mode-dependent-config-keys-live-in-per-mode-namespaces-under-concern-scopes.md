# モードで使う設定キーが変わるときは、関心ごとのスコープに mode を置き、設定キーはモードの名前空間に持つ

## 元の材料

[ADR 0092](../../../adr/0092-mode-dependent-config-keys-live-in-per-mode-namespaces-under-concern-scopes.md) blob:2eeee68634a32842d9ffeeb6c0945b8f3852e44f

## 要点

- モードで使うキーや意味が変わる設定には関心ごとのスコープを設ける。
- 選択はスコープの mode で表し、個別の設定はモード名の下に置く。
- 同名でも単位や適した値が異なればモード別に分ける。
- どのモードでも同じに使う部品の設定は共有できる。
- 該当する既存設定を変更するときにまとめて移す。値だけ選ぶ単純なモードまで同じ構造に変えない。
