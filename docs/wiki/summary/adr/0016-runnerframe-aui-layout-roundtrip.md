# RunnerFrame の dock サイズ制御は構造化シリアライザ往復と遷移時同期で行う

## 元の材料

[ADR 0016](../../../adr/0016-runnerframe-aui-layout-roundtrip.md) blob:9aec75ab434e483f7d72faf5a75d32ebb02f2043

## 要点

- wxAUI は既存 dock の幅を直接設定する公開 API を持たず、空になった dock の幅も保存しない。
- 構造化されたレイアウトの保存と再読込で dock サイズを反映し、表示状態の遷移で幅を同期する。
- 再読込後は古い pane 参照を使わず、非表示や浮動 pane の幅には記憶値を補う。
- 最大化中に再読込すると復元情報が壊れるためサイズ調整を避ける。
- 後の改訂では主 pane の配置変化も200 ms の更新時に検知する。共通処理は AuiLayoutFrame が持つ。

## 内容

### 同期の注意点

レイアウトの再読み込みは pane 配列を差し替える。事前に取った参照を使い回さず、非表示・浮動時に保存値が0となる幅は記憶値で補う。

### 適用時機

最大化時の往復は復元情報を壊すため避ける。補助 pane やサッシには次の遷移まで補正が遅れる場合がある。共通の保存・同期は GUI 基底クラスで担う。
