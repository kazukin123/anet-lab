# 設定継承は最終値の差分合成とし、個別指定をベースより優先する

## 元の材料

[ADR 0042](../../../adr/0042-config-inheritance-as-differential-base.md) blob:7553ef3fb6c0d5cf038af06cc76e8f212424dc32

## 要点

- 設定の $ はベース指定で、選択元の最終値を差分として合成する。
- 全体の指定より部分指定、部分指定より個別の設定キーを優先する。
- 既定値には ?= を使い、選択先から同じキーが供給されたときだけ譲る。
- Run・CLI の最終値伝播と休止中プロファイルの扱いを維持する。
- 後に設定ファイルの規約の正本は実装レビュー観点へ移ったが、代入演算子の意味は変わらない。

## 内容

### 差分合成

$ で指定したベースの全体を後から入れ替えると、別の指定で加えた個別キーまで失われる。右側の選択元が供給する値を合成し、全体・部分・個別の優先関係を行順と分ける。

### 移行

既定を毎回専用プロファイルとして列挙する形は取り下げた。設定を書く位置で ?= を使えるようにし、同じキーに有効な個別指定がある場合にだけ既定値が譲る。
