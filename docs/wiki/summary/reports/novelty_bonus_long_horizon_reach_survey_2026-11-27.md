# Survey: 新しさのボーナスで、長い移動の先や、ふだん通らない状態へ届くか

## 元の材料

[Survey: 新しさのボーナスで、長い移動の先や、ふだん通らない状態へ届くか](../../../../reports/novelty_bonus_long_horizon_reach_survey_2026-11-27.md) blob:88c6deac294a9b940a817189d6bcfb267f3e3921

## 要点

- 外的報酬もエピソードの終わりの信号も使わない好奇心だけの PPO が、Super Mario Bros で 11 の面を見つけ、ボスを倒すまで探索した（並列の環境 2048）[Burda Large-Scale (2018/08), §3.1 B・図 3(a)]。
- ICM は、固定の開始から 350 step 先の目標（VizDoom の very sparse）に 66% の Run で届いた。報酬なしの Mario は 38% の位置の穴（15〜20 のキー入力の決まった列が要る）で止まった [Pathak ICM (2017/05), §4.1・§6]。
- 報酬の密な Seaquest で、報酬だけの ES は浮上しない局所解（中央値 960）に固まり、新しさを混ぜた NSR-ES は 2329.7 だった [Conti NS-ES (2017/12), §4.2・図 3]。エピソード内の位置の新しさ（DeepCS、A2C）は中央値を 1791 から 3443 にした [Stanton DeepCS (2018/06), §3・図 2]。
- 探索の分類の原典は、KFM を ε-greedy が得点の抜け道を見つけるゲームの例に挙げる [Bellemare Count-Based (2016/06), 付録 C.2・表 1]。
- KFM の RND は、Rainbow では 10M〜200M フレームのどの時点でも ε-greedy を下回り（200M で 24087.6 対 28741.8）[Taïga Bonus-ALE (2021/09), 表 2〜5]、PPO の上の EIPO の表では外的だけの 47266.5 を上回る 66954.2 だった [Chen EIPO (2022/11), 付録 A.6・表 7]。
- DQN の Q が正確なのは学習の極限の分布に従う状態・行動だけ、という解析がある（理論のみ）[Ramaswamy Asymptotic (2020/08), §4.1]。
- 受け身の Double DQN が能動の Agent の Replay だけで学ぶと大きく劣り、自分の遷移を 10〜20% 混ぜると劣化が大きく減り、半々で消えた [Ostrovski Tandem (2021/10), §2.2・§3.2・図 7]。
- human starts（人の play から取った 100 の開始点）は、学習で見ていないかもしれない状態への汎化を測るために使われたが、開始点を変える方式である [Nair Gorila (2015/07), §5.2；Machado Revisiting-ALE (2017/09), §5.3]。
- 見つからなかったもの: エピソード内の新しさ（NGU の k 近傍・E3B）で報酬の密な横スクロールのゲームのボスへ行き着かせた事例、KFM のボスや面の進みを探索の手法で比べた研究、途中から誘導した状態からの成功率を DQN 系で測った研究。

## 内容

### 冒頭（問い・結論・範囲）

Q11（長い移動の先・手前の稼ぎ・KFM）と Q9（通らない状態で粗くなる問題と測り方）の外の部分を、2026-11-27 に一次の資料 17 本で調べた。PDF をテキストに直して読み、表は画像で照合した。

### 2. 報酬の無い長い移動の先へ届いた事例

Burda らは並列の環境を 128 から 2048 に増やすと Mario の探索が大きく広がったと書く（図の凡例は 1024 で食い違う）。終わりの信号を外しても Agent は死を避け、原典は死ぬと何度も見た開始へ戻るからと説明する。好奇心が外的報酬と揃うのは設計者の導く順序のためかもしれないと推測し、揃わないゲーム（Atlantis、IceHockey）もある。ICM の VizDoom は開始を固定し、270 step と 350 step の部屋から始め（上限 2100 step）、very sparse では A3C と画素予測は一度も届かなかった。報酬なしの Mario は面 1 の 30% 超まで進み、敵を倒す・避ける行動を覚えた。

### 3. 手前に稼げる報酬があるときの新しさ

NS-ES は RAM の列で行動を特徴づけ、新しさだけの NS-ES は 5 本すべてで浮上を覚えて 1044.5 だった。停滞してから新しさの重みを上げる NSRA-ES は、50 世代ごとに 0.05 ずつ変えると抜けず、10 世代ごとなら NSR-ES と並んだ。局所解の無いゲームでは新しさが費用になった。DeepCS は RAM の位置の格子をゲームの初めに空にし、Seaquest では格子が 700 フレームでほぼ埋まった。格子の入力を外しても内的報酬があれば成績はほぼ同じだった。探索で集めた状態で DQN を off-policy に学ぶ案は試していない。EIPO は内的報酬が気をそらす問題を挙げ、61 ゲームで P(RND > EO) は 0.49 だった。2 次元の迷路では、ランダムに置いた点に RND が引かれた。

### 4. Kung-Fu Master を名指しした記述

分類の原典は分類を粗いものと断り、KFM の抜け道の中身は書かない。Taïga らの KFM は 200M で CTS 26439.4、PixelCNN 27234.6、ICM 28168.3 も ε-greedy より低く、NoisyNets が 39382.1 で最も高い。EIPO は 49152000 フレーム・5 seed 以上で、KFM の EIPO は 48329.4。内的報酬だけで学んだ KFM は、Burda らの図 8 でランダムより上（目で読んだ）、Mega-Reward の表 1 で Cur 3042、RND 652.1、Mega-Reward 352.4 だった。どの出典もボスや面の進みは報告しない。

### 5. 収束した方策が通らない状態で粗くなることの扱い

de Bruin ら（DDPG、振り子）は、FIFO の Replay で探索を減らすと経験が好む軌跡に集まり、反対向きの技能を忘れたと報告する。TD 誤差で引くと状態空間の全体で精度がそろうとも書く。Fu らの表形式の単体試験では、一様・Replay・TD 誤差の重みが方策自身の分布より高い収益だった。tandem の実験では、能動の Agent の ε を上げると受け身の成績が上がり、Replay を大きくしても劣化が遅れるだけで、止めた方策のデータでは同じ重みから始めても崩れた。β-DQN は被覆の方策を DQN の中で分け、MiniGrid の成功率 0.49 を 0.83 にしたが、被覆は訪問の分布図で定性的に示しただけである（HTML の前半だけを読んだ）。

### 6. 測り方

Machado らは human starts の欠点として、開始のあとは決定的で行動列を覚える方法でも点が出ること、偏りの無い開始点を選びにくいことを挙げる。Zhang らは初期状態（迷路の構成）を学習用と試験用に分け、環境に乱れを入れる評価は過学習を見つけるとは限らないと報告する。Osband らは bootstrap が観測したデータから来ない不確かさを表さないとして乱数の prior を足す（要旨だけを読んだ）。

### 7〜9. 批判・総合評価・調査の限界

到達の事例は PPO・A3C・A2C・進化戦略の上で、DQN 系での同じ結果は見つからなかった。Mario の到達は外的報酬が無い条件である。読めた範囲は、Osband らが要旨、Nair らが評価の節、β-DQN が HTML の前半で、Burda らの図 8 は値を読み取っていない。Large-Scale Study の中で、好奇心がランダムを上回る割合の書き方（IDF 75%・RF 70% と、図 8 の題の約 71%・約 67%）が食い違う。
