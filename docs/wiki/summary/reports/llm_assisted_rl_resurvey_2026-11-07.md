# LLMを活用したRLの再サーベイ

## 元の材料

[LLMを活用したRLの再サーベイ](../../../../reports/llm_assisted_rl_resurvey_2026-11-07.md) blob:be5c54403ff44ae6687a207954a36bee2453910a

## 要点

- 評価で特に注意するのは、LLM呼び出しの削減と、RLを何度も学習する費用の削減が別であることだ。BIRDは候補の生成から方策の学習・評価までを共通化して比較する。
- LRMはQwen3-VL-8B-Instructを、進捗・完了・時間順序の比較という別々の報酬モデルに調整する。模倣学習で初期化した方策をManiSkill3でPPO改善する実験と、実機4課題での進捗による重み付き行動模倣を分けている。後者を実機のオンラインRL成功例として数えない。9月のv3では問い合わせ間隔と遅延も検討されている。arXiv / LRM (2026/09), §III–IV
- TextAtari v2 は AtariARI の RAM ラベルを文章化して言語エージェントを評価した。23ゲーム・各1,000 interaction step・5 seed で、名称の「100K」はこの評価の長さを表さない。
- 対象には報酬や観測をコード化する方式と、映像から進捗を採点する方式の両方がある。
- 調査は実験の再実行を含まず、小型モデルを共有 GPU で動かす総費用は未測定。

## 内容

### 1. 対象と読み方

今回の中心は「LLMに毎回行動を決めさせる」方式だけではない。報酬のプログラム、観測の変換、課題の難易度、学習の更新則をLLMが作り、通常のRLが環境との相互作用を担う方式を含める。次表は本報告の整理であり、各論文が同一の分類体系を提唱したという意味ではない。

以下の数値は著者の報告であり、この調査で再現実験を実行した値ではない。LLM自体の数学・コード能力をRLHFやRLVRで高める研究は対象外とする。視覚モデルはVLMと明記する。

### 7. 比較条件と失敗を調べる

報酬が出過ぎる、APIの意味を取り違える、といった不具合を診断してコードを直す研究である。PPOと構造化されたMiniGridを中心に、1〜4回のLLM呼び出しを使う。大幅な改善値はあるが、10月のv2では同じ指示を与えた3モデル×2課題の比較において、多重比較補正後に修正の有意な優位性は残らなかった。4呼び出し・同一episode予算の候補選択も競争力がある。密な報酬の移動課題では診断が誤作動した。TMLR / Diagnostic-Driven Refinement (2026/09), §9.4–9.8; arXiv v2 (2026/10)

理論については本調査で注意点を見つけた。式(6)が遷移後も古い目標で採点するため、目標が切り替わる場合の一般的な不変性は成立しない反例を構成できる。これは本調査の指摘であり、著者自身の結論ではない。別冊の数式照合・反例・検算に条件をすべて記した。

### 8. 費用とローカル実行の証拠

次の値は論文ごとに課題・機材・価格時点が違う。横並びの順位表にはしない。金額は論文内の記載であり、現在のAPI価格ではない。

RoboReward はロボット報酬予測用の4B・8Bモデルを学習し、8Bを実機 RL に用いた。TextAtari は7B・8Bの言語エージェントを評価した。どちらの資料にも、個人用 GPU を RL と共有して Atari を学習した際の総所要時間は示されていない。

### 9. 到達点と調査の限界

前回から追加された大きな論点は、LLMが出す助言の内容だけでなく、報酬・観測・課題・更新則のどこを生成対象とするかである。LIMEN (2026/05)、LEACL (2026/07)、Evolutionary Discovery (2026/03)は、その異なる範囲を具体的に検証している。

本調査では学習実験・モデルダウンロード・有料API実行を行っていない。量子化による劣化、GPU共有時の速度、対象環境への転移、全失敗候補を含む総費用は再現していない。ロボットの意味付き状態や専門家動画を使う結果を、画素だけのAtariへ適用済みの根拠として扱わない。

公開実装の既定値・再試行・採点処理は再現条件の別冊へ、目標切り替え時の数式の指摘と小さな検算は保証の別冊へ分けた。

追加調査では、制御コードと学習環境の5論文、小型モデルと費用の4論文、探索に渡す情報の2論文、更新則発見の3論文、言葉を環境へ結び付ける3論文、小目標と振り返りの4論文、行動助言の3論文、蒸留と先読みの2論文を別冊にした。本文と合わせて47論文であり、原著の結果・公開コードの状態・本調査の推論を区別している。
