# AGENTS.md を作業状況別に分ける案

## 元の材料

[RFD0199　AGENTS.md を作業状況別に分ける案](../../../memo/0199_agents_md_split_by_situation_10rfd.md) blob:d2153979cea60ed1d3ac684e368895856582623f

## 要点

- すべての作業で長い共通文書を読む構成では、当面使わない規則も毎回コンテキストを占める。
- 既に見出しを「いつ要るか」で並べ替えたが、これだけでは読み込み量が減らなかった。
- ビルド・実験などに固有の規則を別ファイルへ移す案を比べる。原本§7〜§9の仕様・実装契約・受入は、§6の未決表の既定を採った場合に限る。
- 入口には開始条件と参照先を置き、移動した規則を必要な場面で見落とさない形を検討する。
- どの節を分けるか、参照関係と読込量がどう変わるかを比較したうえで決める。

## 内容

### 解決したい問題

起草時の AGENTS.md は28節・770行で、担当する作業に関係しない規則も毎回読み込んでいた。状況ごとの見出しに並べ替える第一段階は済んでいたが、読み込む量は減らなかった。ファイル分割は別の未決事項である。

### 未決表に置いた候補

ビルド・検証、Run・実験、コミットメッセージの細かな決まりをそれぞれ専用ファイルへ移し、毎回必要な原則は入口に残す案を置いた。各場面をどこで検出するか、検証の規則をレビュー観点に置くか、移した規則を見落とさないかは再グリルの対象である。

### 条件付きの仕様と受入

§7〜§9は未決表の既定を選んだ場合の試案である。入口の表と関連スキルの読み先を付け替え、現用の参照が新しい文書に届くか、読み込み量が減るかを検証する想定だった。移し先の名前や分割方法は採択済みの構成ではない。
