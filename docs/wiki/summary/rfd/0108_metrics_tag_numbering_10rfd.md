# メトリクス群と指標の番号体系

## 元の材料

[RFD0108　メトリクス群と指標の番号体系](../../../memo/0108_metrics_tag_numbering_10rfd.md) blob:44c9607f3bf29ff22057267c4a7812781c8d830f

## 要点

- 番号帯と移行手順は起草時の暫定案である。比較済みの値と新しいタグ体系の候補を区別する。
- Viewer ではタグが文字列順に並ぶため、番号がグラフのまとまりと読み方を決める。
- 暫定案では、Run の進み、環境、評価、Agent の更新・方策・NN を番号帯で区別し、一つの群番号を複数の用途に割り当てない。
- 群内番号には用途別の規則を設け、RAM 指標では番号と統計の種類がタグから分かるようにする。
- scalar・trace・画像と解析ツールが出すタグを含め、現用の設定、テスト、文書を同じ対応表で移す。
- 新しい Atari Run は新しい Workspace に記録し、過去の Run のタグは当時の記録として残す。

## 内容

### 問題と調査時の状態

Viewer で群名と指標名を辞書順に並べると、共通設定と環境別設定の間で同じ番号を持つ群が隣に混ざる。調査時には10、36〜39、53が重複し、解析ツールが出力する Atari 5ゲームの集約も Agent の画像と60を共用していた。

### 維持する条件

対象は配布設定と解析ツールが記録するタグ名である。値、通知、step 軸、平滑化の係数は維持する。環境と評価の成績を比較する既存の群番号も残す。

### 暫定の番号体系

Runner の進みを00〜29、環境を40〜49、評価を50〜59、Agent を60〜89、性能を90〜99に置く。Agent の60番台は更新、70番台は方策・行動、80番台はネットワークの状態と画像に充てる。RAM の番号1〜9には51〜59を使い、平均・移動平均・最大の区別はタグ末尾へ置く。

### 候補を採る場合の切り替えと検証

Atari の新しい Run は Workspace も分け、移行前後のタグが同じ実験群で混ざるのを防ぐ。番号付きの実験バッチが止まってから切り替え、同梱設定のテストで群番号の重複、RAM タグ、40文字の上限を確かめる。
