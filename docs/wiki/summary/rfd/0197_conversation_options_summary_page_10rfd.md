# 会話の判断と進捗を非公開ページで見返す

## 元の材料

[RFD0197　会話の判断と進捗を非公開ページで見返す](../../../memo/0197_conversation_options_summary_page_10rfd.md) blob:b7c35201e25f10f5424498d19467b05165ab9a59

## 要点

- 案・判断・結果・残件が長い会話に分散し、時間が空くとスマートフォンで経緯を探しにくくなっていた。
- 会話ごとに非公開のまとめページを用意し、論点と選択肢の中身、何を試したか、現在の判断をまとめる。
- 実験や比較など必要な場面で作成・更新し、同じ会話の結果を一つのページで追えるようにする。
- Claude Code・Codex の双方で利用できる入口と、会話をまたぐときの引き継ぎを決める。
- 閲覧範囲を限定し、実際の会話での読みやすさ・更新・使用量を確認する。

## 内容

### 目的と問題

その会話の手助けになる情報を、会話を遡らず、聞き直さずに、1 か所で見返せる。中身は、議論や整理の助けになる情報（案・選択肢とその状態、決まったこと、未決など）に、進捗と残件を加える。寝たあとなど間が空いても、それを見れば思い出せる。
題材の課題 issue-20261122-717309 が片付く。
簡単な会話（Run を 1 本見るだけ、番号で選んで終わるなど）では作られていない。会話の記録で確かめる。

### 起草時点の現状

要った手順: HTML に文書の外枠（`<!doctype html>`・`<html>`・viewport）を足す。ホスティングの設定 1 枚と合わせて、Sites 専用の Git へ送る。外枠と設定は、出すときだけ組み立てればよく、手元に置かなくてよかった。
つまずいた点: 制限付きの実行環境では、Sites 専用の Git の名前が引けずに止まった。ネットワークの許可を受けて出し直すと、2 版とも送れた。
Claude Code の会話一覧の直近 200 件（片付けたものを含む）のうち、anet-lab の 180 件を、題名のキーワードと目で分けた。目で分けた分を含むので概数である。
ファイル名を `grill-rfd0197.html` へ改めたあと、出し先の URL を渡して出し直すと、同じ URL のまま更新された。

### 確定事項

レビュー（2 往復目）の指摘から出た 2 件で、決まりから一意に導けなかったので、レビューが OK になったあとに開発者に聞き、推奨で埋めた。

### 実装契約

wiki の 311 開発ツールのトピック別まとめ は、この RFD の起草で書き戻す（実装では直さない）。
