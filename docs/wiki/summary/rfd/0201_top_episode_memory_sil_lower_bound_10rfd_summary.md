# 上位エピソードを保持し外的価値の下限を学ぶ案

## 元の材料

[RFD0201　上位エピソードを保持し外的価値の下限を学ぶ案](../../../memo/0201_top_episode_memory_sil_lower_bound_10rfd.md) blob:bd2fb4657eb7539ef28f19314f8e1fddfb6e31e5

## 要点

- SIL の保持対象、損失、採否の測定は暫定案であり、再グリルの材料として区別する。
- Montezuma の n-step 10 の9本中8本が部屋23の高報酬を経験したが、学習側に多数の成功が定着したのは2本だった。
- 残りの希少な成功は通常 Replay の上書きで失われるため、上位エピソードを別に保持する候補を比べる。
- 暫定案では観測した割引収益が外的 Q を上回るときだけ下限損失を加える。
- 成功を新しく見つける探索と、見つけた経験を繰り返し使う学習を別の問いとして評価する。
- 方式・採用条件と参照実装の不足は未決で、追加調査を再グリルの前提とする。
- 2026-11-28 の改訂で、打ち切りの扱い、長いエピソードの写し方、Replay の部品の共有、上位を選ぶ偏り、損失の重み、外的の bootstrap との引っ張り合いなどをグリルの材料に足し、未決に 5 件を足した。

## 内容

### 目的と問題

この RFD は、まれに出た上位のエピソードを Replay とは別に持ち続け、その遷移の外的の Q を、実際に得た割引収益で下から引き上げる仕組みを DQN 系の Learner に足す。見つける数を増やす仕組みとは別に、見つけたものを手放さない側を受け持つ。

### 起草時点の現状

部屋 23 に初めて入った exp step は、45 が 12,028,288、48 が 12,038,784（どちらも数え始めの直後）、ほかは 16,616,192〜28,899,456だった。
49 は学習側で先の道（主に 3500・3600 点）へ移ったが、Greedy の最後の 5 回は 612.5〜2,593.8 で、骸骨の道へ戻った。51 の先の道も 3500・3600 点が主だった。

### ゴールと非ゴール

ゴール: まれに出た上位のエピソードを、Replay の上書きで失わずに学習に使い続け、その遷移の外的の Q を実際の収益まで引き上げる仕組みを、設定で有効にできる形で DQN 系の Learner に足す。Montezuma's Revenge の n-step 10 の構成で、部屋 23 まで行くエピソードが数本出た Run が、Greedy で部屋 23 まで行く道に定着する割合を上げられるかを確かめる。

### 機構ごとのゴールへの寄与と、仮説・比べ方・終わり方

仮説: 部屋 23 のエピソードが数本出た Run でも、記憶と下限の損失があれば、Greedy で部屋 23 まで行く道に定着する。
終わり方: 4 seed の 30M を流し終えたところで判定する。4 本すべてが定着すれば、9 本中 2 本と比べた Fisher の正確検定（片側）でおよそ 0.02（15/715）で、効いたとみなす。2 本以下なら効かなかったとし、記憶の中身と損失のメトリクスで、記憶に部屋 23 のエピソードが入らなかったのか、入っても引き上げが効かなかったのかを分ける。3 本なら seed を足すかを開発者が決める。

### 候補を採る場合の成功の測り方

部屋 23 のエピソードが 1 本も出ない Run（44 型）は、この仕組みでは変わらない見込みで、割合の分母からは除かない（seed ごとの探索の当たり外れを含めて比べる）。

### 候補を採る場合の実装契約

`TopEpisodeStore` と `ReplayBuffer` の足す口は汎用の層に置くので、外的・内的やゲームの名前を持たない。エピソードの順位に使う値（外的報酬の episode return）と割引収益は、Learner が計算して渡す。

### 移行対象

新しい設定キーとメトリクスを足すだけで、今ある設定・テスト・サンプルの振る舞いは変えない（既定は `off`）。

### グリルの材料（2026-11-28）

開発者は、膠着して打ち切りで終わるエピソードが多いと終端だけを入れる形は効きにくいこと、エピソード記憶をできるだけ Replay と共通にしたいことを挙げた。AI は、報酬が負にならない構成では打ち切りまでの収益も下限として正しいこと、Replay に残る後ろの部分だけを写しても G は正しいこと、上位の軌跡を持つ記憶は方策ベースの自己模倣（GASIL・SIDP）に先行例があること、上位を選ぶと運のよい回を選びうること、外的の bootstrap が `combined` だと下限と TD が引っ張り合いうることを材料に挙げた。決定ではない。
