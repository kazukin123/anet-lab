# DropMergeEnv 直前行動観測(prev-action trio + DROP 列マーカー・暫定)

## 元の材料

[DropMergeEnv 直前行動観測(prev-action trio + DROP 列マーカー・暫定)](../../../memo/done/0040_dropmerge_prev_action_obs_10rfd.md) blob:d9e7bbf52d0900a8dc6e53fe5e2b9124f11dec81

## 要点

- LunarLander での直前行動観測に続き、DropMerge の状態にも直前の操作を含めて検証する。
- 前の行動に関する3項目と、DROP した列のマーカーを追加する。
- 同じ列への連続 DROP をエピソード単位で数え、入力を変えたときの振る舞いを比較する。
- 成績と安定性を主に評価し、長い NOOP の連鎖への影響は副次的に見る。
- 3項目と列マーカーを一つの候補として比較するため、個々の寄与をこの比較だけで判定しない。

## 内容

### 直前の DROP を表す観測

投下ノイズ、転がり、合体によって、現在の盤面から以前の投下命令を読み取れないことがある。direct 系の行動で、直前の行動が有効か、NOOP か、どの列に投下したかの3値を観測ベクトルの末尾に追加できるようにする。別設定で直前の DROP 位置をグリッドにも描く。NOOP またはリセット直後にはマーカーを描かない。

### 形状・互換性

direct 系では現在の投下装置の位置を表示しないので、マーカーに既存のクラス12の面を使える。グリッド形状とクラス数は維持する。移動操作を持つモードではこの面が既に使われており、投下座標も同じ意味を持たない。ベクトルの3値を有効にする場合は入力形状と最初の畳み込みの重みが変わり、以前の形状の snapshot をロードできない。

### 実験の読み方

設定が無効のときの観測・乱数消費の一致と、有効時に train・eval で入力仕様が実際の観測に合うことを確認する。短期比較では同じ step 帯で既存 Run のブレを超える悪化がないかを確認し、効果の判断は700M以上の終盤の報酬と到達 MaxRank で行う。操作の痕跡をそのまま繰り返す方策になっていないか、同列への連続 DROP も監視する。
