# AI ハーネス動線マップ(harness_map)— 入口・条件読み・動線の可視化

## 元の材料

[AI ハーネス動線マップ(harness_map)— 入口・条件読み・動線の可視化](../../../memo/done/0080_harness_map_10rfd.md) blob:03a96bac0fd5b7bbd8b5cbc26902077084b742bd

## 要点

- エージェントが何をいつ読むかという決まりが AGENTS.md、skill 一覧、設計文書などに分かれていた。
- 入口、条件を満たしたときに読む資料、skill 呼び出しと検証先のつながりを図と表で示す。
- AGENTS.md の各節がどの経路で読まれるかを明らかにし、常時読む入口を減らす候補を探せるようにする。
- 公開できる開発手順と個人用の情報で、出力先を分ける。
- 文書や skill の変更に応じて対応表と図を再生成する手順を整える。

## 内容

### 追跡する範囲

AGENTS.md は条件を満たしたときに読む資料を指し、skill 一覧と設計文書にもそれぞれ入口がある。テスト資材を指す節の位置も文書によって異なる。個別の索引を結び、どこを起点にどの検証に届くかを示す。

### 公開版と手元の版

リポジトリから分かる入口・条件・関係は公開用の図と対応表にまとめる。利用者固有の情報を含む関係は手元の成果物で扱う。2か所に実体コピーされたスキルと、同名の別スキルが優先して起動する事象も区別する。

### 再生成

anet-harness-map で文書と skill の現物から対応関係を調べ直す。入口の追加や参照先の移動があれば、図と表を同じ変更に合わせる。
