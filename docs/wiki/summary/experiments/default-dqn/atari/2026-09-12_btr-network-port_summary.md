# Atari Breakout: BTR NN構成の移植検証 — 2026-09-12

## 元の材料

[Atari Breakout: BTR NN構成の移植検証 — 2026-09-12](../../../../../experiments/default-dqn/atari/2026-09-12_btr-network-port.md) blob:be6eff8e472ab2e3ef356dcd0b39b02cf570c5ba

## 要点

- BTR の NN構成を移植して BTR 公開実装を上回った。
- ε=0 / 400 エピソードの 50M 断面は 685.1（SEM 9.30、4 セッションすべてで max 864、 `≥432` 82.0%、`≥600` 62.5%）。BTR 論文値 602.01 を +13.8%、BTR ローカル実行の ε=0 窓 45-50M の 641.2 を +43.9 上回る（探索ブロック 01）。
- 25-48M プールで RR4 素の 1.29 倍。
- SN の符号は累計 20-22M で反転し、以降は差が広がる。
- BTR NN構成の利得は高 replay ratio に条件付きである。
- `actor_approx` 初期優先度は RR4 でも成績中立で、実時間コストも実質ゼロ。
- ε=0 断面は 20M では群を判定できない。

## 内容

### NN構成（3 軸）

B と C の学習パラメータ数は完全に同一である。SN は `u` バッファしか足さないので、 checkpoint の `model_size` が 17,211,990 対 17,286,434 と 74,444 バイトだけ違う（online + target の 2 本ぶん）。

B の配線は `run_20260913-071609_tmp_wiring_btrtrunknosn` で解決させてあり、 C との設定差分は `main_feature.structure` の 1 行（SN 接尾辞）だけである。 A との差分は `AtariPool6` の挿入と `train.num_envs` 128 → 64 の 2 行。

### 成績

btrfull の throughput が低いのは eval2 の interval が 1009 learn step（他は 3906）で セッション数が 4 倍あるためである。NN構成の重さだけの値ではない。

融合前（`main_feature`）のパラメータ数と成績が単調に対応する。 A' → C → B' は readout が 558,592 で完全に同一で、動いているのは融合前だけである。btrfull は融合前をさらに削り、 readout を 2,510,080 へ太らせている。

### 探索ブロック 01: BTR 公開実装との突き合わせ

2026-09-08 探索ブロック 10 で、BTR 公開実装は同じ再利用 4 回で 本構成の RR4 素を大きく上回った。BTR の NN構成（Pool6 + 融合 2304 + SN、共有トランク無し）を移植して 差が埋まるかを見る。

ε が揃っている 20-31M では btrfull が +21〜+25 上回る。 10-15M は同等（−3.5）。 31M 以降で BTR が上回って見えるのは eval の ε が 0 に切り替わるためで、構成差ではない。

### 探索ブロック 02: NN構成の分解

18-20M では同じ辺が +31.8 / +80.3 / +7.7 になる（SN の辺は探索ブロック 03）。

最大の寄与は融合位置（+39.9 / +80.3）で、`AtariLinear512` を τ 融合の後ろへ移すことにあたる。 readout が 558,592 → 2,510,080 パラメータになり、main_feature は 1,570,208 → 389,024 に減る。 総パラメータは 2,128,800 → 2,899,104 と増えるが、A（4,914,080）よりは依然 41% 少ない。

### 探索ブロック 03: SN の符号反転

符号が 20-22M で反転する。 22M 以降は 9/9 窓で SN 有りが上、`≥432` も 8/9 窓で上。

2026-09-01 探索ブロック 07（RR1 / 50M で SN 群が全群最下位 0.43%）とは 群の構成が違う。同記録は residual ブロックのみ SN + he init で、本記録は全 15 conv の SN である。

### 探索ブロック 04: grad_norm と勾配クリップ

累計ステップで揃えた `37_agent_qtd/22_grad_norm_ema` と `25_grad_clip_ratio_ema`（`grad_clip_tau = 10`）。

SN 無しは 22M → 43M で 4.096 → 4.792（+17.0%）まで上がり、そこで頭打ちになって 4.62 へ戻る。 クリップ率は 0.20% → 0.57% と 2.9 倍。SN 有りは全区間 2.61〜2.83 で平坦、クリップ率は 0.02〜0.05% で横ばい。

### 探索ブロック 05: エピソード長キャップとセッション本数のバイアス

両方にデータがある 2 窓では SN 有りのほうがわずかに高い。 0-20M で SN 有りが 0 件なのは、 3,070 エピソードしか見ておらず、真の率 0.038% なら期待値 1.2 件で、0 件は p ≈ 0.30 で普通に起きるためである。 初キャップ到達点の 2.7 倍差は測定バイアスであり、構成差ではない。

率はセッション内で複数本キャップしても 1 本としか数えないため下限である。

### 探索ブロック 06: RB を引き継がない継続 Run

初回セッションで `16_game_score_max` = 864、`20_game_len_mean` = 4,013.6。 親の 17-20M の個別セッションは 521.1〜581.2 に散らばっており、542.1 はその内側である。

`replay_capacity` は 1,048,576 で、20M 時点の連続 Run の RB も直近 1.05M しか保持していない。 継続後 1M 程度で実質同じ分布に戻るため、真の不連続は最初の約 1M（PER 優先度リセットと `learn_start` ゲート）に限られる。

### 探索ブロック 07: 実時間

起票時は「SN の実時間コストは分離できていない」としていた。btrnosn 対 btrtrunk の −10.6% は SN と融合位置の両方が違う対であり、同一構成の再実行（btrnosn 対 その継続）でも 1,486 対 1,317 = −11.4% 出ていて、実験機のドリフト（1 時間で最大 8%）と同程度だったためである。

2026-09-15 に被覆だけを変えた単一軸の対が取れて分離できた。 `AtariImpalaConv32` と `AtariImpalaConv32SN` の差は `weight_norm.mode = spectral` の 1 行だけである。

### 探索ブロック 08: `AtariPool6` の用量反応

6×6 は内点ではない。 BTR の `AdaptiveMaxPool2d(6)` は本構成の RR4 では最適点を当てていない。 BTR 自身は Pool を「性能は下がるが計算量が決定的に下がる」と評価しているが、本構成では逆である。

伸びは後半ほど大きい。 12-15M で +11.1、18-20M で +25.8。飽和ではなく、 4×4 のほうが立ち上がりが遅く後から伸びる形である。

### 探索ブロック 09: ε=0 断面での SN

学習中 eval（ε=0.01）では SN の差が 25-48M プールで −17.8 だった。 `learner.enabled = false` の別 Run で 50M の close スナップショットを ε=0 / 400 エピソード評価し、 断面でも同じ大きさかを見る。

学習中 eval の −17.8 に対し、断面では −98.7 で 5.5 倍に開く。

### 探索ブロック 10: `replay_ratio` 梯子と実時間フロンティア

RR1 + BTR NN構成は 25-48M プール 447.2 / 6.03% で全群最下位である。 `AtariPool6` の RR1 −28 / RR4 +55.1 と同じ向きの交互作用が、NN構成全体でも成立する。

btrfull 行を訂正した。 起票時の「9h22m / 1,482 exp/s」は btrfull 自身の実測ではなく、 別群（btrnosn 1,486 / btrtrunk 1,328）近傍から借りた導出値だった。実測は `run_20260914-231706_rr4_btrfull_envs128_50m` の 1,296 exp/s / 10h43m である （`num_envs` は throughput をほぼ動かさない。2026-09-15 探索ブロック 01）。

### 探索ブロック 11: BTR NN構成の複製幅

5 窓すべて |差| ≤ 6.7、符号もばらばら。 `≥432` は最大 0.32pp。 他群から借りていた 10.6 点より狭い。

### 探索ブロック 12: SN 被覆を BTR 準拠の 12/15 へ

平均差は +5.0 / +6.3 で複製幅 6.7 の境界上。 ただし `aainit` の符号交互パターン（探索ブロック 13）と違い 9 窓中 8 窓がプラスで、効果は序盤 6-9M に集中している（+18.1 / +15.3、`≥432` も 6.61% 対 5.44%）。 18-20M では +1.7 / +6.1 に収束し、`≥432` は逆に基準を下回る（11.58% 対 12.50 / 12.55%）。

### 探索ブロック 13: `actor_approx` 初期優先度を RR4 で

5 窓で符号が交互に入れ替わり、平均は複製幅 6.7 の内側。 雑音そのものの形である。 `≥432` も 5.95 / 8.21 / 10.02 / 11.22 / 12.25% で、複製対の幅（最大 0.32pt）に対し最大 0.5pt、符号は混在。

### 探索ブロック 14: SN 12/15 と ViT ハイブリッドの 50M 断面（新 eval プロトコル）

2026-09-01 の「ViT ハイブリッドは新基準でも 0.64 倍」は、 その後に入った 4 件の改善（`AtariPool6` / 融合 2304 / SN / Munchausen）を含まない土台での値だった。 現行の btrnet 上へ載せ直して測る。
