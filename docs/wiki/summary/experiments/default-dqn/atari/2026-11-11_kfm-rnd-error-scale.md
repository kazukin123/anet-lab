## 要点

- β 0.03 の群（b003）の ε=0.01 の評価は、4 seed とも β 0.1 の群（r123）を上回った。
- b003 は RND なしの 8 本の範囲の中だった。
- r123 の内的報酬の割合（`03_bonus_share`）は、4 本とも 2M〜3M の区間に 0.5 を超えた（0.54〜0.79）。
- 評価でボスに当たり続けたのは、新しい RND の 14 本のうち b003 の s06 だけだった。
- w1m の 4 本の ε=0.01 の評価の 8〜10M の平均は 23,812（9,032〜33,558）で、b003 の 23,956（14,595〜31,600）と差が無く、seed ごとの開きは b003 より大きかった。
- w1m の s05 は、ε=0.01 の評価で 5.2M からボスを倒し、8.2M 以降の 4 回は 1 ゲームの平均で `floor_clear` 0.7〜1.0、`boss_kill` 1.0〜1.2 だった。

## 内容

### 目的と比較条件

PRD123（RND の誤差の統計を warm-up 中の誤差で膨らませない）の効果を、同じ実行体で今の中身を再現した群と並べて確かめる（PRD123 §7.1）。あわせて、§8 の U1（β の既定）を決め直すための β 0.03 の群と、§8 の U2（warm-up の長さ）を見るための、β 0.03 で warm-up を 1,000,000 件にした群を足した。

共通の構成: 実時間優先の構成（2026-10-15 の既定 10M と同じ。replay ratio 1、128 env、IQN、Munchausen 有効）に `run.@rnd` を足した。`[eval]` の τ は固定（RND なしの Run と同じ）。予算 10M（exp step）。

### 探索ブロック02: seed ごとの評価

ε=0.01 の評価の 8〜10M の平均 / Greedy 5.25M / 学習側の 8〜10M の平均。

### 探索ブロック03: 内的報酬の大きさと割合

b003 の内的報酬の平均は、同じ seed の r123 の 0.24〜0.42 倍だった（β の比は 0.3）。

### 探索ブロック04: PRD123 §7.1 の主の条件

条件 1・2 は r123 の 4 本とも満たした。条件 4 は s07 だけが満たした。b003 と w1m は条件の対象ではないが、同じ値を並べた。

### 探索ブロック05: PRD123 §7.1 の記録する値

ゲームの長さは `52_eval2/20_game_len_mean`（8〜10M の 4 回の平均）と `53_evalg/20_game_len_mean`（5.25M）。単位は env step。

### 探索ブロック06: ボス

b003 の s06 は、ε=0.01 の評価で `boss_hit` の 1 ゲームの平均が 5.7M 2.8、6.7M 0.8、7.2M 3.2、8.2M 2.3、9.7M 0.1 だった（ほかの回は 0）。Greedy 5.25M は 0。学習側の `boss_kill` が正の区間は 8.46M の 1 か所。
