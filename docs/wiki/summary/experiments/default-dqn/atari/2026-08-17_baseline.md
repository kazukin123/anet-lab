# Atari ベースライン定義 探索履歴

## 元の材料

[Atari ベースライン定義 探索履歴](../../../../../experiments/default-dqn/atari/2026-08-17_baseline.md) blob:f785ea67b670c7f165c88706bd8be78691078cd7

## 要点

- sticky actions が Breakout で支配的。0.25 → 0.0 で train 生スコア 42 → 119（2.8 倍）。v5 プリセットのまま回すと 5M step で 42 に飽和し、以降 22M step 分がほぼ無駄になる。sticky 0 では 50M まで伸び続けた。
- episodic_life は単独では効果ゼロ。sticky 0.25 固定で false / true を 27M step 比較し、train 生スコア 42.0 対 41.9、median 41 対 41 で差がない。中間指標（`q_gap_rel` 上昇、`q_max` 低下）は設計どおり動いており、機構は効いているがスコアに繋がらなかった。`lives` が 3.45 対 3.64 と変わらないことが決定的で、死ぬ頻度そのものが改善していない。
- eval が 実時間 を支配しうる。Pong で `interval` 100 → 500 にすると真の throughput が 478 → 1,198 steps/s（2.5 倍）。train 曲線は完全一致しており、差分は eval の実行コストのみ。
- NN は IMPALA-CNN を採用（探索ブロック 07）。同じ 50M で train 生スコア 134.7 対 121.2、eval1 147.7 対 115.7。差の本体はサンプル効率で、中盤（10-25M）に 2 倍前後がつく。加えて Nature CNN は 44M でピークアウトして −12.0% 劣化するのに対し IMPALA は −1.6% で、ピークが最後尾にあり 50M でも飽和していない。高得点の裾も違い、≥400 点は IMPALA だけが出す（1.0% 対 0.0%、max 431 対 384）。
- 100M の比較では RR を4から1まで下げると後半の成績が上がり、0.5まで下げると低下した。

## 内容

### ベースライン実効設定

`run_20260816-162140_atari_breakout/config/config_data.txt` を正本として確認した。

`per_beta_step` と `eps_decay_steps` は Atari.txt の「ステップ数依存設定」章にあり、2.5M 予算前提の値のまま 50M Run に適用されている。

### 探索ブロック 01: num_envs

Random Policy ラダーの `exp_step_per_sec` は num_envs に対し単調増加（n32 5.1k → n512 11.5k → n1024 12.1k）。しかし実構成では learner 律速であり、この天井は一度も binding しない。

実時間 では n512 が 2.65 倍速く見えたが、これは eval 発火頻度の差によるものだった（n512 は `LCM(16,100)=400` 更新周期、n64 は 100 更新周期で 4 倍発火）。n64 の eval interval を 500 にして頻度を揃えると 1,198 steps/s となり、n512 の 1,264 steps/s とほぼ一致する。

### 探索ブロック 02: eval interval の 実時間 影響

`exp_step_per_sec` メトリクスの表示値は 1,830 対 1,531 で、真値（478 対 1,198）と乖離していた。旧実装は 200ms 窓の瞬間値を時間重みなしで拾うため、stall 区間が観測から抜けていた（PRD 053 で修正）。

train 曲線・loss・episode_len が小数以下まで一致したことから、eval 頻度は学習に一切影響せず、差分は純粋に eval の実行コストである。eval エピソード長はスキル向上に伴って伸びる（Pong で 764 → 5,342 step）ため、固定 interval では Run 後期ほど eval が高くつく。interval 100 の後期（2.0-2.5M）は 334 steps/s まで落ちた。

### 探索ブロック 03: Breakout プロトコル（sticky / episodic_life）

1M ごとの推移でも、序盤（〜3M）は true がやや速く、5〜15M は false が上、20M 以降は拮抗し、両者とも 41〜43 の同じプラトーに収束した。

sticky 0 では同じ `lives` が明確に上昇した。sticky は 4 回に 1 回前の行動が固着するため、パドルの精密制御を直接阻害する。Breakout は狙った列に当て続けてトンネルを掘る戦略が高得点の要件であり、そこが塞がれていた。

### 探索ブロック 04: Breakout 50M 長期

ピークアウトは train 側で一貫している（43-44M 140.1 → 44-45M 126.1 → 47-48M 119.9 → 49-50M 119.1）。eval1 の window 平均も 195.3（42-45M）→ 142.2（45-47M）→ 80.3（47-50M）と低下した。

max スコアは 360 → 402 → 427 と推移し、1 画面 432 点にほぼ到達した。

### 探索ブロック 05: num_envs の env 天井（Random Policy）

全 Run で前半／後半の throughput 比が 0.96〜1.04 に収まり、定常に達している。瞬間値の median も真値と一致した（例: N=8 で 2,576.5 対 2,581.8、N=1024 で 11,649.6 対 11,538.9）。PRD 053 の時間重み EMA 化以前は同じ指標が真値の 3.8 倍を示していた。

天井は N=512 でほぼ飽和し、1024 への増加は +6% にとどまる。

### 探索ブロック 06: num_envs の実構成ラダー（学習あり）

N=128 以上は 2,647〜2,709 に収まり、差 ±1.2% は同一設定のブレ幅（2 周目 n64 の 2 本で 1.3%）内。

N=128 と N=256 はそれぞれ 2 周で ±0.3% に収まっており、両者の差 −17% は確実に有意。n64 のみレンジが 12.6% と広いのは、lane 数が少なく train 平均のサンプルノイズが大きいため。

### 探索ブロック 07: NN 構成（Nature CNN vs IMPALA-CNN）

eval1 の 5M window は Nature が 40-45M の 138.3 から 45-50M で 115.7 へ落ちるのに対し、IMPALA は 160.1 → 147.7 で高原を保つ。

差の本体はサンプル効率である。中盤（10-25M）で 2 倍前後がつくが、Nature CNN は 35M 以降に急追し 40-45M で一度逆転する。したがって IMPALA の優位は表現力の天井そのものではなく、同じ経験からより速く学べる点にある。

### 探索ブロック 08: fire_reset と長期挙動（100M）

50M 以降が本題である。 eval1 の best window 337.5 は fire_off の全区間最高（160.1）の 2 倍超で、HNS57 1166%。Nature DQN の Breakout 401.2（HNS57 換算 1387%）の 84% に相当する。ただし 50M 以降は対照が無いため、この伸びが `fire_reset` の寄与か単に長く回した結果かは分離できない。

文献はピーク値で報告している。 Mnih et al. 2015 の Methods は評価について "the highest average episode score is reported" と明記しており、401.2 も best checkpoint の値である。したがって本記録でも比較値は best window で取るのが土俵として正しく、現在の到達点は「eval1 337.5 / HNS57 1166%」となる。

### 探索ブロック 09: NN 構成（IMPALA vs IMPALA+ViT ハイブリッド）

ε 摂動への感度. `eval2` は train と同一の online net を greedy で走らせたもので、差は ε=0.01 の有無だけである。`game_len` が約 1,250 step なので 1 ゲームあたり平均 12.5 回のランダム action が入る。

差の実体は ε 摂動への頑健性である。 同一重みで ε を外すと IMPALA は 1.82 倍に跳ね、ViT は 0.99 倍で変わらない。つまり IMPALA は 1 ゲーム 12.5 回のランダム action で得点を半分近く落としており、ViT は落としていない。「ポカミスが少ない」という体感はこの差である。正確には、打ったポカから復帰できるかどうかの差になる。

### 探索ブロック 10: PER beta スケジュール（10M / 50M / end 0.55）

b055 は速いが不安定である。 20-30M で 3 本中最速（139.0）かつ 432 超えが最初に出現し、45-50M でも eval1 291.0 と最良を記録する。一方で `grad_norm` が 16.4 → 25.0 と単調増加し `loss_ema` が 2.1 に達し、最後の 2.5M で train EMA が −35.2% 崩壊した。50M で停止したため回復するかは未観測である。

### 探索ブロック 11: Breakout 100M（Nature DQN 401.2 水準への到達）

50M 以降で 1 画面突破のレジームに入った。 40M まで 0 件だった 432 点超えが 50-60M で 1.94%、90-100M で 9.99% に達し、10 ゲームに 1 回は 2 面目へ進んでいる。max 812 は 2 面目をほぼ削り切った値である（理論上限 864）。`game_len` も 1,389 → 1,561 と伸びている。

### 探索ブロック 12: grad_clip_tau（クリップ飽和の切り分け）

飽和相は利益ではなく handicap だった。 tau30 は b50 を全区間で上回り、1 画面突破の初出が 40-50M から 30-40M へ 10M 以上前倒しになった。したがって探索ブロック 10 で残した「beta の効きはクリップ飽和を抜けたことが本体では」という可能性は否定される。beta の寄与はむしろそれが誘発するクリップ飽和によって一部打ち消されていたことになり、実効は測定値より大きい。

### 探索ブロック 13: weight_decay

ViT の滑らかさは表現から来た結果であり、weight decay の滑らかさは重みを一律に縮めた結果である。同じ `q_gap/q_max` という数値が出ていても中身が異なり、後者は容量を削るため終盤の 2 面プレイや長時間ラリーで不足する。0-30M で大きく先行したのは、序盤は容量を絞るほど汎化が速いという同じ効果の表側と解釈できる。

### 探索ブロック 14: NN 構成（ViT 軽量版 / grad_clip_tau 30 での再評価）

lite_t30 のみ eval1 上限が 108,000 frames で他 3 本は 18,000 frames。上限が緩い側が 331.4 対 314.0 で下回っている。

### 探索ブロック 15: BTR 準拠バンドルと崩壊（replay_ratio が原因）

classic で 2.5M step の median が 335。対照 `run_20260821-122717`（tau30）が全 101M で記録した最高の 5M 窓 median は 332（95-100M）であり、約 38 分の 1 のサンプル数で同水準に到達した。noop 30 のぶん土俵は新しい側が厳しい。

その後 median は単調に低下し、classic は 10M で 60（対ピーク 18%）、v5 は 35〜47% で振動した。

### 探索ブロック 16: eval の FIRE デッドロック（v5 プロファイル固有）

直後の 9.78M で 396 に戻っているため、方策そのものは無傷である。

### 探索ブロック 17: RR=4 での 50M 長時間（崩壊耐性と天井）

速度側の土俵は揃った。 200M frames / 6.07h は BTR の同 frames / 12h の約 2 倍である。スコアは eval で約 263 に対し BTR 682。sticky 込みの公表値である Rainbow 109 / DQN 92 は 2.4 倍上回っている。

### 探索ブロック 18: スコア分布の解剖（低スコア裾・ラック境界・アーキ差）

低スコア帯は「停止」ではなく「短命」である。 直近 4,368 エピソードを (score, `game_len`) 対で見ると 単調に対応する。

### 探索ブロック 19: action gap の γ 依存と BF16 の余裕

低スコア裾は action gap では説明できない。 45-50M で ViT は `q_gap/q_max` 0.0223 と tau30 の 0.0362 より 狭いのに、`<100` は 13.5% 対 36.3% で良い。向きが逆である。

### 探索ブロック 20: spatial exploration（Ape-X 型 ε ラダー）

追試（2026-08-25）: `eps_start` 0.2 で単調性が破れ、0.4 が山と確定した。 `run_20260825-084548_atari_breakout_apex_e02`（他は e04 と同一、diff は `eps_start` の 1 行のみ）。

### 探索ブロック 21: 5-6M 過渡の機序（多指標の上昇→急落→緩回復）

「多くのメトリクス」の中身は 3 種類に分かれる（5 Run・1M ビン）。

価値の水準は滑らかに上がっている。落ちているのは行動の識別性（`q_gap`）だけである。

### 探索ブロック 22: 予算 100M（相転移の観測）

`q_gap` は 15-20M の谷 0.0399 から単調回復し、55M 頃に当初ピーク 0.0485 を超えて 0.0580 まで伸びた。 第 2 の過渡は存在しない。`grad_norm` / `loss` は 45-50M で底を打って以降ゆるやかに上昇するが、 これは β が 50M で 1.0 に到達した時刻と一致する（IS 補正が完全になり実効重みが増える）。

### 探索ブロック 23: `replay_ratio` 2（三軸同時の勝ち・過渡の減衰）

実時間軸: RR4 が 10.95h かけて到達した最終水準（90-100M mean 390.1）に、 RR2 は 25.3M exp = 1.49h で到達する（20 点移動平均 392.5）。7.3 倍の短縮である。

### 探索ブロック 24: `replay_ratio` 1（過渡の消失・2 ラック完全掃き切り）

ただし 0-20M では RR1 が最下位である。 更新回数が少ないぶん立ち上がりが遅く、`≥432` は 20M まで 0 件。 exp 軸で RR2 を追い抜くのは 40M 前後である。

### 探索ブロック 25: `replay_ratio` 0.5（単調性の終端・RR1 が内点最適）

`q_max` が 10.18 で 4 本中最低であり、100M 時点でもまだ上昇中である。RR4 の崩壊署名（`grad_norm` / `td` の上昇）は 一切無く、`grad_norm` 0.95 / `loss` 0.253 は RR1 に近い。価値関数が収束しきっていない = 勾配 step 不足の絵である。
