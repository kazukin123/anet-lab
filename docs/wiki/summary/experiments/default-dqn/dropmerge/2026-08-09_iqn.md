# DropMerge IQN 導入・QR 比較の探索履歴

## 元の材料

[DropMerge IQN 導入・QR 比較の探索履歴](../../../../../experiments/default-dqn/dropmerge/2026-08-09_iqn.md) blob:2735c805d1d84c018eee2b982f05548e9456bf8d

## 要点

- 同一のB256/RR1、`alpha=1e-4`、PER alpha 0.2、initial priority fixed 0.3、`use_optimistic_target=false`で、IQN32 randomとQR51の100M scratch比較が成立した。実効設定差はquantile modeとそれに伴うhead / tau経路が中心である。
- QR51のPRD048診断ではquantile crossing約36%、lower-risk/full-Q不一致約60%、upper-tail/PER priority Spearman約0.62だった。期待値成績は有効だが、tailを整列した分位関数として読む信頼性は低く、今後のstratified IQNでもcrossingを先に確認する。
- target M=8/16/32/64の20M比較では`target_mc_scale`が概ね`1/√M`で変化し、M軸の実効性を確認した。一方、M16/M8に有意な速度利得はなく、M64もlate scoreを十分改善しなかった。M8の単発score首位は同一M32反復で観測した非決定論幅内であり、M32を維持してK探索へ進む。
- IQN では 30–40M に Q 値全体の一時的な膨張が生じ、約 39.75M で `q_max_real_max=30.61` に達した。50M 付近までに QR と同程度の Q 水準へ戻り、その後は安定している。
- 現 Run は歴史的 QR51 baseline に主要設定を合わせた実用比較であり、厳密な QR/IQN A/B ではない。QR51 と IQN32/32、Eval tail score の意味差が残る。
- tau samplingとK/N/M探索を完了し、後続基準はK=N=M=32の`stratified`とする。100M matched A/Bでは約40M以降にstratifiedがantitheticを上回り、Train Double Suikaもstratifiedだけで3回生成した。次はPERを一軸ずつ探索する。

## 内容

### 採用したIQN探索基準の実効設定

`run_20260813-111617_dm_iqn32-stratified-b256-rr100/config/config_data.txt`を正本として確認した。

後続探索ではK=N=M=32のstratified設定を比較基準とし、各Phaseでseedを明記する。Run名ではなく`config/config_data.txt`のK/N/Mとsample modeを毎回確認する。

### 探索ブロック 01: IQN 32/32 の初期成立性と QR51 比較

LunarLander で成立確認した IQN を DropMerge の既存 QR 長期ラインへ移し、学習成立、sample efficiency、Q 分布、PER、NEET、throughput を確認する。

60–72M の同一 exp-step window では、IQN は QR51 baseline より遅かった。

同じ 実時間 では QR がより多い exp-step へ到達するため、実時間差を含む性能差はさらに大きい。

Q 値の過渡変動はあるが、50M 以降は TD error、loss、grad norm とともに安定した。

### 探索ブロック 02: ReplayBuffer 満杯境界と Q 値遷移

LunarLander では ReplayBuffer が grow-only から overwrite へ切り替わる境界で Q、loss、grad、reward が同時に変化した。DropMerge の 30–50M Q 遷移も同じ機構かを確認する。

256 env 換算では、warmup 終了が train step 100、満杯が 2,048、warmup 経験の完全忘却が 2,148 である。

Q は滑らかに増えており、TD error と reward に急変はない。QR baseline も同様だった。

### 探索ブロック 03: Q 値バブルと一時的 NEET

約 39.75M で `q_max_max=4.93`、`q_max_real_max=30.61` に達した。単発スパイクではなく、`q_sa_real_mean` も上昇したため、価値分布全体の広い Q 水準変化である。

Q が約半分へ下がる一方で Eval reward は上昇した。高い Q が性能向上を表したのではなく、一時的に膨らんだ価値尺度を実リターンへ再較正したと解釈する。

Eval episode step EMA は 32–34M の約 563 / 496 から、52–54M の約 250 / 243 へ短縮した。max rank と fruit count が維持され、reward は上昇しているため、単なる早期 GameOver より待機行動の減少と整合する。

### 探索ブロック 04: QR から IQN への変更が Q 応答を増幅する理由

LunarLander の引き金: ReplayBuffer 満杯・初期経験 overwrite に伴う経験分布切替が有力。

共通の増幅器: IQN の stochastic tau と共有 quantile function が、経験分布変化に対する Q 応答を大きくする可能性。

cross-Env の方向は一致するが、まだ各 single-seed であり一般則とはしない。

### 探索ブロック 05: IQN fixed-grid control

fixed にすると learner の積分点と target が等間隔の中心へ固定され、QR の固定分位グリッドへ近づく。しかし次は残る。

IQN UQE tail mean は `[tau,1]`へ直接固定点を置く。QR は全域固定 quantile のうち tau 以上を抽出するため、action query の点数と位置が一致しない。

厳密な UQE action semantics の一致には、IQN でも全域固定 grid を query して QR と同じ index 規則で tail を抽出する実装 mode が必要である。

### 100M 時点の判断更新

90–100M の確定 window。同一exp-stepのQR51 baselineと比較した。

80–90Mから90–100Mへ、IQNのEval target rewardは約2.3%、policy rewardは約3.4%上昇した。完全な停滞・劣化ではなく、QRとの差も60–72Mの約19%から約16%へ弱く縮小している。ただしmax-rank差とDouble Suika未達が残り、現時点で長期最終性能の逆転を示す証拠はない。

終盤のNOOP診断も鎮火を示す。最終付近のNOOP優位率EMAはEval1約4.08%、Eval2約2.26%、marginはそれぞれ約-0.028、約-0.047だった。reset NOOP marginもEval1約-0.020、Eval2約-0.020で負を維持し、持続的Eval NEET再発の証拠はない。

### 探索ブロック 06: B256/RR1同条件 QR51 / IQN32 100M比較

DropMergeの1 Runを短縮しつつ評価品質を維持できる基本条件としてB256/RR1を固定し、QR51とIQN32 randomのsample efficiency、最終window、学習健全性、実時間性能を比較した。

生rewardの中央値もTargetでQR 1768、IQN 1487、PolicyでQR 1684、IQN 1240だった。EMAの一時的peakだけではなく、終盤episode分布全体でQRが優位である。

QRのTarget / Policy reward EMAは60–80Mの1529 / 1454、80–90Mの1580 / 1554、90–100Mの1629 / 1584と継続上昇した。IQNは20–40MにTarget側で一度接近したが、40M以降はQRとの差が再び開いた。現在の条件ではrandom tau IQNの積分近似と共有tau表現がsample efficiencyの負担になっている可能性と整合する。

### 探索ブロック 07: IQN tau sampling 5方式の20M screening

Eval raw値の区間平均を使う。20M RunはEval 781点、最終Eval step `19,993,856`まで到達した。

stratifiedはrandom 2本平均に対して10–20MのTargetで約+8.1%、Policyで約+7.7%。antitheticも約+6.2% / +4.3%だった。systematicはrandom平均とほぼ同じで、被覆を強くするだけでは改善しなかった。fixedは0–10Mこそrandom並みだが、10M以降の伸びが止まり明確に劣後した。

### 探索ブロック 08: stratified / antitheticのseed 2再現と50M比較

antitheticは40–50MでstratifiedをTarget +1.9%、Policy +0.5%上回った。ただし同じEval stepで対応付けたantithetic−stratified差は、Target `+24.6`、95%区間`[-22.2,+71.4]`、Policy `+5.6`、95%区間`[-44.2,+55.4]`で、どちらも0をまたぐ。50Mでも方式差を確定できない。

両方式ともrandomを上回ったが、40–50MではQR51へTarget / Policyとも約6–8%届かなかった。Train / EvalのDouble Suikaは両方式とも未観測だった。

理由は2-seed Targetがわずかに高いこと、全stratum被覆を保証すること、rare transitionへ外れtau集合だけが当たる問題を直接緩和することである。

### 探索ブロック 09: tau本数探索

最初の`run_20260813-232408_dm_iqn-k32-n32-m32-stratified`から始まる4本は、Run名だけMを変更し、実効設定がすべてM32だったためM比較から除外した。この4本は同一seed・同一M32の非決定論反復として、10–20M rewardのRun間幅がTarget約7%、Policy約7%あることの参考にのみ使用する。

修正版4本はartifactと起動ログの両方でM=8/16/32/64を確認し、全Runが約20Mで正常終了・正常保存、`stderr.log`は空だった。

### 探索ブロック 10: stratified / antithetic 100M matched A/B

Phase K/N/M後に、50Mまで実質同率だったsampling finalistをK=N=M=32、B256/RR1で100Mまで比較した。

両Runの実効設定差は`app.run_name`と、train Policy / learner current / learner targetの3か所の`sample_mode`だけだった。両方とも約100Mで正常終了し、同じ852,107,692 bytesの`agent_close.anet`を保存、`stderr.log`は空だった。

### 残件と実験キュー

同一B256/RR1のQR51とIQN32 randomを100M、正常closeまで完了した。

QRは終盤reward、max rank、throughputでIQNを上回り、過去QRと同等scoreを維持した。

`run_20260809-033908_dm_iqn32-b128-rr125`は100Mで正常AutoPause・正常closeした。
