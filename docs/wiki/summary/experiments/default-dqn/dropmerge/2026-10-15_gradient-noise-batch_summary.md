# DropMerge 勾配ノイズと batch / replay ratio の機序の探索履歴

## 元の材料

[DropMerge 勾配ノイズと batch / replay ratio の機序の探索履歴](../../../../../experiments/default-dqn/dropmerge/2026-10-15_gradient-noise-batch.md) blob:c4e036de6498758bc12a3579dbaa962450d5f090

## 要点

- 勾配ノイズの臨界バッチ（Adam 前処理版）は学習とともに増え続けた。B256/RR1 で 0–10M の 232 から 170–230M の約 3,900 まで、B で割った比は 0.9 から 15.2 になった。0〜50M は分散が 4 倍に増え、50M 以降は分散が横ばいのまま信号が 1/3 に細った。分散の約 95% は feature 側にある。
- 停滞区間（170→230M）の対照（42A）は、学習側の平均点が 60M で +2.7%（20M あたり約 0.9%）だった。同じ系列の 300M の延長 Run の同じ区間と 10M 窓で ±0.3% 以内で一致した。評価専用 Run の平均点は同じ 60M で +4.2%（1,950→2,032）伸びており、評価で見る限り成長は止まっていない。
- 最終 checkpoint の評価専用 Run（target ネットの Eval1・Eval3、各群約 10,000 局）では、対照の複製 2 本が 2,031.9 / 2,031.8 で一致した。B1024/RR1 は +0.9%（約 2.4σ）、B512/RR2・B1024/RR2 は +0.2〜0.3%、B256/RR2 は −0.8%（約 2σ）だった。online ネットの Eval2 は、同じ設定の複製でも 2.2% ずれた。
- 評価方策の UQE τ を下げると対照の評価が +1.8% 上がる、という 1 組目の結果は、別の局の組で再現しなかった。τ の効果は 4 checkpoint 中 1 つで約 2σ、他は差なしだった。
- 停滞区間（170→230M）で学習率を 7.1e-5 に下げた群（42B）は、最終の評価専用 Run で +1.0%（約 2.5σ）と B1024/RR1 と同じだけ上がり、学習中の評価でも 60M の間 +1.2〜1.8% を保った。伸びている区間の同じ群（41c）では上乗せが 30〜40M で消えていた。NoisyNet で行動が変わる割合はほとんど下がらなかった（10.0%、対照 10.5%）。
- B1024/RR1 の系列は 230M 以降も評価で伸び続けた。評価専用 Run は 2,051（230M）→ 2,099（290M）→ 2,148（350M）と 60M ごとに +2.3% で、学習中の評価では 230–290M に B256/RR1 の系列より約 1.6% 高く、伸びの傾きは同程度だった。230M からの群では、学習率をさらに 7.1e-5 に下げる（−0.4%）、学習中の Actor に一定の ε 0.02 を入れる（−1.3%）、Munchausen α を 0.7 に下げる（−0.6%）のどれも上積みにならなかった。ε の群では方策がかえって尖り、最後の 2M で終局が NoDropTimeout に寄った。
- 学習中の評価の値は採用した局の報酬の合計で、終局の罰（−10、NoDropTimeout は −20）を含む。評価専用 Run の値はログのゲームの点で、罰を含まない。罰をそろえて比べると、学習中の評価 ×8 の最後の 10M と最終の評価専用 Run の差は 8 本で平均 −0.1%（−1.5〜+0.8%）で、×8 は系統的には低く出ない（探索ブロック 11 の判断更新）。

## 内容

### この文書の読み方

経験数は各 Run の自分の経験数（分岐からの経験数）で書き、通算の位置を括弧で添える。

評価専用 Run の平均点はログに出た局のゲームの点で、学習中の評価はセッションごとの報酬の合計の平均（終局の罰 −10、NoDropTimeout は −20 を含む）である。どちらも同じ種類どうしで比べる（探索ブロック 11 の判断更新）。

### 探索ブロック 01: 勾配ノイズの推移（B256/RR1 の系列）

feature 側の臨界バッチは readout 側の 10〜15 倍（170–230M で feature の ÷B 約 24、readout の ÷B 約 1.9）。分散の約 95% が feature 側、信号の約 60% が feature 側。0–10M では両者の差は 2 倍だった。

`05_ratio_adam` の一時的な跳ねは、推定のぶれ（信号は大きい数の差）と feature 側の分散の一時的な増加で、他の指標や成績には表れていない。読むのは 10M 程度の平均の傾きである。

### 探索ブロック 02: 伸びている区間での分岐（50M から、41a〜41d）

学習中の評価（3 ランナーの平均）は、90–100M で 41a 1,780 / 41b 1,779 / 41c 1,760、70–80M で 41a 1,765 / 41d 1,763 だった。

ノイズを下げる 3 つの群は、どれも分岐直後に学習側で +2〜3% 上がった。41b・41c は 30〜40M でその上乗せが消え、41d だけ +1% 前後が残った。学習中の評価では 3 本とも対照と同点圏だった。

### 探索ブロック 03: このマシンで使える B の上限

参考: B256/RR1 は 11.7M exp/h、B512/RR1 は 12.5M exp/h。

### 探索ブロック 04: 停滞区間での分岐（170M から、42A / 42D / 42H）— 学習側の結果

42A は、同じ系列の 300M の延長 Run（`run_20261012-122028_dmfb_29_21_to300`）の同じ区間と、10M 窓で ±0.3% 以内で一致した。

### 探索ブロック 05: 評価専用 Run による比較（42A / 42D / 42H と出発点の 34a）

入れ替わり（DS が増え、DS の無い局が下がる）は Greedy の Eval3 でも同じだった（DS 1.48% / 2.06% / 1.90%、DS の無い局 1,985 / 1,971 / 1,972）。

### 探索ブロック 06: NoisyNet ありで評価する（学習側の差の正体）

NoisyNet ありの評価は、学習側と同じ順と大きさの差を再現した。学習側の差は、方策の強さではなく、NoisyNet の揺らぎに対する感度の差である。

### 探索ブロック 07: 評価方策の UQE τ の掃引と再現確認

42A の τ0.85 のダブルスイカ率は、評価 seed 1 で 1.20%（Eval1）/ 1.31%（Eval2）、評価 seed 2 で 1.58% / 1.52% だった。

### 探索ブロック 08: B1024/RR1（42J）

学習側では 4 本の中で最大の上乗せだったが、評価の平均点の差は +0.5% 程度で有意でない。1 回の更新のノイズを下げる効果は、学習側（NoisyNet ありの方策）にだけ出る、という読みと合う。

### 探索ブロック 09: 7 月の長期 lineage の評価の再読

NoisyNet の無い B512/RR2 の lineage も、300M の間ほぼ横ばいだった。B256 の枝は cy07 の終盤とほぼ同じ水準で、B512/RR2 との差は 1〜3% にとどまる。元の記録の「+13%」は cy08 1 回目の 20〜30M の 1 窓（2,702）との比較で、2 回目の同じ窓は 2,624 だった。

### 探索ブロック 10: B256/RR2（42I）— 取りこぼしだけを減らす

勾配ノイズ（前処理なしの版、0–20M → 40–60M）は、42I が臨界バッチ 313 → 456・信号 0.025 → 0.012、42A が 295 → 332・0.026 → 0.018 だった。分散はどちらも横ばいだった。

### 探索ブロック 11: 対照の複製（42G）と学習中の評価 ×8

学習中の指標（40–60M）は、Q の水準 8.58 / 8.64、Munchausen のボーナス −0.0178 / −0.0184、NoisyNet で行動が変わる割合 10.5% / 10.5%、online と target の食い違い 9.7% / 10.5%、feature の大きさ 12.65 / 12.73 で、差は 0.1〜8% だった。

### 探索ブロック 12: 学習中の評価で見た経過（42 系列 6 本）

B1024 の 2 本は、分岐後 20M までに対照より約 3% 高くなり、その後は横ばいだった。対照は 60M かけて同じ水準に着いた。40–60M では 42H が対照と同点、42J が +1.3%（約 1.2σ）だった。最終 checkpoint の比較（探索ブロック 05・08・11）で差が小さかったのは、対照が追いついた後に比べたためである。B を上げると、評価も早く上がる。

### 探索ブロック 13: 学習の中身の比較（42 系列 6 本）

② に沿って動いたもの: feature 側の重みの増え方。更新回数 2 / 1 / 1/2 / 1/4 の順に、+7.7% / +2.7〜3.1% / +0.9% / +0.1% だった。

### 探索ブロック 14: 学習率 7.1e-5（42B）— 停滞区間で学習率を下げる

停滞区間では、学習率を下げた上乗せが評価で 60M 続き、最終の評価専用 Run でも B1024/RR1 と同じ +1.0% だった。伸びている区間で 30〜40M で消えた 41c とは違う。

### 探索ブロック 15: 230M からの継続と 4 つの群（45a〜45e）

45c の評価専用 Run は、終局の 86% が NoDropTimeout で、1 局の step が 415 だった（他の群は NoDropTimeout が 0%、1 局 317〜319 step）。学習中の評価では、NoDropTimeout の終局は 58M までほぼ無く（Eval3 の 20–30M に 0.7%）、58–60M に Eval1 36%・Eval3 58% になった。学習側の局も 58–60M に 1 局の step が 301 から 313 に延びた。

### 探索ブロック 16: 290M からの継続（46a）

46a の学習中の評価（10M 窓）は 2,107 / 2,091 / 2,121 / 2,123 / 2,116 / 2,113 だった。
