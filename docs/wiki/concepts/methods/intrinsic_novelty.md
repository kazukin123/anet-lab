# 内的報酬による探索の比較

[anet-lab](../../../../README.md) › [wiki の目録](../../index.md) › [手法](../../index.md#手法)

## 今の結論

NGU 型ボーナスと E3B の比較は、環境・学習器・ほかのボーナスとの組み合わせに依存する。MiniHack の結果から Atari での順位は決められない。
Montezuma と KFM では RND の尺度や warm-up に応じて探索の経過が変わった。文献と比べるときは、採点する観測・predictor の更新・報酬の正規化・評価方策をそろえて読む。

## 分かっていること

### anet の知見

- 未検証の仮説: KFM のバーの縮みを逆動力学の特徴が保存すれば、報酬 0 の命中にも新しさの手応えを与えられる。ただし自機の姿勢だけで行動を予測できる可能性があり、制御可能な変化が必ず特徴に残る保証は無い（出典: [内的報酬の RFD](../../../memo/0173_intrinsic_reward_novelty_10rfd.md)、§2.5）。
- 調査の範囲: anet の BTR を基にした構成での NGU／E3B の効果は未測定であり、今回の調査では直接比較に使える BTR＋NGU 全体の実績も確認できていない（出典: [内的報酬の RFD](../../../memo/0173_intrinsic_reward_novelty_10rfd.md)、§3「現状」・§2.8「NGU・E3B・BTR の関係と、比較結果の適用範囲」）。
- 切り出し: RND による一生の新しさは lane 別の記憶を持たず、facade（`DefaultDQNAgent::UpdateFromBatch`）で次観測を採点して報酬へ畳めば Replay・Actor の契約を変えずに腕にできる。KFM では対照腕で、判断に効くのは GridMaze の到達率と費用・統計の確認（出典: [RND の腕の暫定 RFD](../../../memo/0116_rnd_lifelong_novelty_10rfd.md)、§1.1・§4 D1・D2・§7）。
- 切り出し: 一生の新しさの口は「倍率 α を返す採点・補助学習・診断・保存」の 4 操作で、RND の本体は DQN から見えない非公開の実装に閉じる暫定の設計（出典: [RND の腕の暫定 RFD](../../../memo/0116_rnd_lifelong_novelty_10rfd.md)、§5.1・§5.7）。
- 比較対象の実装: Taiga ら（ICLR 2020）の Rainbow＋RND は、行動した観測 x_t を agent step ごとに 1 件で採点・学習し、誤差の z を分散に相当する値で割って 0.00005 倍し、Runner が [−1, 1] に clip した外的報酬に足す。合計は clip せず、負の値もそのまま入る。観測の統計は正規化後の値で更新する。Burda ら・anet が採点するのは次観測 x_{t+1}（出典: [RND の腕の暫定 RFD](../../../memo/0116_rnd_lifelong_novelty_10rfd.md)、§2.1・§8.1 の 6）。
- RND の尺度の条件: target と predictor の出力の尺度が揃っていれば、初期値の種類（he／xavier と直交）で新しさの判別は大きく変わらず、target だけ小さいと predictor が誤差を下げられず判別が落ちる。PyTorch の写しで Montezuma の画面を 6 万 step 学習した判断材料で、受入の基準ではない（出典: [RND の腕の暫定 RFD](../../../memo/0116_rnd_lifelong_novelty_10rfd.md)、§2.1）。
- 設定の落とし穴: anet の層カタログ `Conv2d_S`・`Conv2d_M` は設定キーの階層が読み込みと合わず、2026-11-06〜07 の Atari の RND の Run は既定の 128@3/1 ×2（1 Network 約 1 億パラメータ）で動いていた。写しの比較では判別は落ちず、実証された害は速さと checkpoint の大きさ（出典: [RND の腕の暫定 RFD](../../../memo/0116_rnd_lifelong_novelty_10rfd.md)、§2.1）。
- GridMaze では RND の新しさが最初の数千 step で尽きる: 観測が正規化した (x, y) の 2 値で盤面は固定（`seed_mode = process`）なので入力は 25 通り以下。ε = 1 から始まる 256 lane が全部を踏み、predictor が覚え切って一生の誤差平均を下回り続け、既定（`clipped`・`whiten`）の bonus は 0 になる（2026-11-07 の `run_20261107-212611`: 1,551 点中 9 点以外 0、predictor の損失 3e-9）。手で通っていないセルへ誘導したときの失敗は未踏ではなく off-path の Q の粗さ（出典: [RND の腕の暫定 RFD](../../../memo/0116_rnd_lifelong_novelty_10rfd.md)、§6.4・§7）。
