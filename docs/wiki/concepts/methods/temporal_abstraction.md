# 行動の時間尺度

[anet-lab](../../../../README.md) › [wiki の目録](../../index.md) › [手法](../../index.md#手法)

## 今の結論

TempoRL は行動とその繰り返し長を学ぶ。LunarLander、qbert、DropMerge には、学習中の繰り返しと評価時のスキップを分けた比較がある。
LunarLander で見られた利得は、Atari と DropMerge の比較では再現していない。評価時の行動・スキップ長の選び方も成績を左右する。

- TempoRL の論文（付録 B の Algorithm 1）は、行動を Q の ε-greedy で選んだあと、その行動を条件にしたスキップ Q の ε-greedy でスキップ長を選ぶ形を例に挙げる。ε は、Atari では最初の 200 000 ステップで 1.0 から 0.01 へ線形に下げて以後は固定、特徴量の環境では 0.1 に固定で、表形式では線形減衰・対数減衰・一定 0.1 の 3 つのスケジュールで比べた。著者の公開コードは行動と skip に同じ ε を別の乱数で使い、特徴量の環境の ε は 0.2 で本文の 0.1 と違う。論文は今後の課題に、スキップ方策と行動方策の学習に別々の探索方策を使うことを挙げる（出典: [biedenkapp2021_temporl_paper_2026-10-03.md](../../../../reports/biedenkapp2021_temporl_paper_2026-10-03.md)、4.1 表形式の TempoRL・4.2.2 特徴量ベースの環境における DQN・4.2.3 Atari 環境・付録 B・付録 H・6. 結論；[0103_temporl_reference_alignment_10rfd.md](../../../memo/done/0103_temporl_reference_alignment_10rfd.md)、§2.2 の T10・T15）。
- 同じ行動を d step 続ける行動の繰り返しの損失は、課題ごとの「慣性の代価」で上から抑えられ、実効の地平が短くなることによる学習の得で相殺されうる（Kalyanakrishnan ら。抄録で確かめた。抄録は n-step と action gap に触れていない）（出典: [nstep_action_gap_survey_2026-11-27.md](../../../../reports/nstep_action_gap_survey_2026-11-27.md)、§1.4）。
- 時間刻みに頑健な DAU（Tallec ら）の論文は、Double DQN、優先度付きリプレイ、多段の目標値、分布型の価値（QR や IQN）との組み合わせを扱っていない（出典: [tallec2019_time_discretization_paper_2026-10-03.md](../../../../reports/tallec2019_time_discretization_paper_2026-10-03.md)、キューの論点への答え「論文が扱っていない点」；[nstep_action_gap_survey_2026-11-27.md](../../../../reports/nstep_action_gap_survey_2026-11-27.md)、§4.1）。
- TempoRL 型のスキップ長の価値を、行動に使わず補助タスクとしてだけ学ぶ事例は、2026-11-27 の調査では見つからなかった。TempoRL を引用する 45 本の題と抄録（Semantic Scholar）で繰り返しを扱うものは、どれも学んだ価値か別の規則（SNAP は状態の新しさ）で行動か長さを選んでいた（探した範囲: 被引用の一覧と web の検索）（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§1.1・§5）。
- スキップ長の選択に NoisyNet などのパラメータのノイズを使う事例は、2026-11-27 の調査では見つからなかった（探した範囲: TempoRL を引用する 45 本の題と抄録と web の検索）。近いものは、NoisyNet で行動を選び、長さや繰り返すかを別の仕組みで決める形（εz-greedy、SNAP）だった（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§2.1・§4・§5）。
- 割引率の違う 10 個の Q を共有の表現の上の γ ごとの線形の Head で同時に学び、行動は固定の γ で選ぶ多地平の補助タスク（Fedus ら、Dopamine の Rainbow、sticky actions 0.25、各 3 seed）は、Rainbow をしばしば上回った。双曲の割引で行動する版と有意な差が無く（19 ゲーム）、著者は改善を補助タスクによるものとした。n-step とはよく組み合わさった。表現を直接調べた実験は無い（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§1.2）。
- C51 に多地平の補助を足した Multi-C51 は、10 ゲーム中 9 ゲームで C51 を上回った（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§1.2）。
- 補助タスクが誘う表現の解析（Lyle ら、AISTATS 2021）では、複数の割引率の価値の予測は平均の割引率の単一の予測と同じ表現に向かい、追加の仕組み（課題ごとの初期化の部分空間など）が無ければ単一の課題より役立たない。著者はその仕組みを試しておらず、多数の割引率は Atari で試していない（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§1.3）。
- ランダムに選んだ行動の列に条件付けた多段の予測（ランダムな GVF）を補助タスクにすると、価値の予測・pixel control・CURL と同じくらいの表現が得られ、RL の目的の勾配を表現に返さなくても、補助だけで学んだ表現が end-to-end の actor-critic を上回った（Zheng ら、NeurIPS 2021、Atari と DeepMind Lab。抄録で確かめた）。行動の繰り返しに限った予測ではない（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§1.4）。
- どの長さの遷移からも全部の長さの行動価値を同時に更新する PerDQN（Sabbioni ら、AAAI 2023）は、長さの価値を行動と長さの選択に使い、探索は行動と長さの組に対する ε-greedy である。Atari の 6 ゲーム（各 5 Run）のうち 5 ゲームで DQN と TempoRL より学習曲線が速く、Seaquest では撃つ行動を続けるために DQN が上回った（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§1.5）。
- εz-greedy（Dabney ら）は、探索の行動を zeta 分布（既定は μ = 2）から引いた長さだけ続け、長さは学ばない。Rainbow の実験では NoisyNet の方策の上に重ね、行動は NoisyNet で、探索を始める時期と続ける長さは ε と zeta 分布で決まる。Atari-57 の人間で正規化した得点の中央値は、R2D2（30B フレーム）で 16.44 → 17.77、Rainbow（200M フレーム）で 2.03 → 2.30 だった（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§2.2）。
- SNAP（Hu ら）は、直前の行動を繰り返す確率を状態の擬似回数から決め、繰り返しのための価値や方策は学ばない。ε-greedy・entropy 正則化・NoisyNet の探索に重ね、NoisyNet の場合も標本効率が上がったとするが数値は無い。画像入力の DeepMind Control（DrQ-v2、5 seed）の連続制御で、Atari は無い（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§2.3）。
- TAAC（Yu ら、NeurIPS 2021）は、直前の行動を繰り返すか新しい行動にするかの 2 択を、Q から作る Boltzmann 形の分布で選び、温度は entropy の項で自動調整し、ε は使わない。著者は前の行動に沿った持続する探索が生じるとした（14 の連続制御の課題、3 seed）（出典: [skip_auxiliary_task_noise_survey_2026-11-27.md](../../../../reports/skip_auxiliary_task_noise_survey_2026-11-27.md)、§2.4）。
