# 評価と比較の条件

[anet-lab](../../../../README.md) › [wiki の目録](../../index.md) › [測り方](../../index.md#測り方)

## 今の結論

1 ゲーム 2 seed で確認できるのは観測した方策どうしの差とその幅までである。BTR の公開 CSV では学習中の最良値が最後の 10 回の平均をゲームの中央値で 1.15 倍上回った。
評価時の ε・τ・ノイズや予算で順位が変わる。qbert ではスキップなしと TempoRL 分割で、Greedy と学習中と同じ方策を比べたときの上下が逆になった。

## 分かっていること

### anet の知見

- Breakout の `soft_update_tau` を変えた実験（RR1・50M・V/A ReLU）では、25〜50M の `42_env/10_game_score_mean` を集め、そのうち 432 以上の割合を壁突破率とした。この条件での壁突破率は τ=0.008 で 6.16%、τ=0.020 で 5.19% だった。この 0.97 ポイント差を 2σ で区別するのに必要な標本数は、1 群あたり約 4,600 エピソード、6.5M env step 相当と見積もられた（出典: [RFD0153](../../../memo/0153_q_statistics_config_screening_10rfd.md)「Context / Problem Statement」と実測表）。

- qbertでは、平均点や第8面の突破率が上がっても、第9面の進行を示さない。TempoRL合算singleの各200ゲームの評価では第9面の突破が15本なのに対し、その面で終わる179本の得点中央値は43,850、長さの中央値は9,080 stepだった。BTRとの平均点比較にも、先に終わった20本を採るBTRとanetの採用方法の差が入る（出典: [行動固定を評価時だけ外す比較](../../../experiments/default-dqn/atari/2026-10-29_temporl-auxiliary-only-stage0.md)、探索ブロック04。Run: `run_20261029-105620_t104_stage0_merge`；[BTRとの比較と初期値の記録](../../../experiments/default-dqn/atari/2026-10-23_btr-qbert-repro-init.md)、メタデータ・探索ブロック08・09）。

  - 確かめ方: 今ある battle_zone の Run（サンプル効率優先、実時間優先の 2 seed、64 env・1M の 2 seed、ε ラダーの群）の ε=0 断面から 50M までの 10 回の最大を取り、BTR の公開 CSV の max（K=10）145,903 と並べる（今ある Run の集計で済む）。サンプル効率優先の 50M を seed を変えて 2 本足し、ε=0 の最良の幅を見る（新しい Run が要る）。
  - 出どころ: AI（開発者の質問を起点、2026-10-23）

## 分かっていないこと

- GridMaze で通らないセルから再開してゴールに着かないとき、点数の方策は壁へ向かう行動を繰り返して位置が変わらないまま打ち切られているのか。RFD0116 の観察（RND を足した Run）では、通っていないセルへ誘導すると穴へ入っていて、壁の前で止まる形とは違う。どちらの形が、どの条件で起きるのか（出典: [0173_intrinsic_reward_novelty_10rfd.md](../../../memo/0173_intrinsic_reward_novelty_10rfd.md)、§2.7「見立て」。Run では未確認；[0116_rnd_lifelong_novelty_10rfd.md](../../../memo/0116_rnd_lifelong_novelty_10rfd.md)、§7）。
- 評価 session を足すと同じ seed の軌跡が `[eval]` の 2 点目（14848 step）から変わるのは、どの乱数の系列（評価の方策の τ の抽選、env の seed、Actor の乱数）を学習側や既存の評価 slot と共有しているためか。同じ設定の 2 本が一致するかも確かめていない（出典: [2026-10-28_temporl-split-kmax-epsilon.md](../../../experiments/default-dqn/lunarlander/2026-10-28_temporl-split-kmax-epsilon.md)、pending）。
- 評価 session の追加で乱数の系列が変わったという読みは、2 点目が学習前の点であることを前提にしていたが、2026-11-05 の訂正で、最初の学習は 8,448 exp step とされた。記録の探索ブロック 02 の 3 つ目の箇条は、訂正の前の「学習前に 2 点目が変わる」のままである。訂正のあとも、この読みは立つか（出典: [2026-10-28_temporl-split-kmax-epsilon.md](../../../experiments/default-dqn/lunarlander/2026-10-28_temporl-split-kmax-epsilon.md)、探索ブロック 02 の結果の 1 つ目と 3 つ目の箇条）。
- qbertのスキップなしseed1で、終了checkpointを学習中と同じ選び方で評価した8面突破率（60.0%）が、学習中の最後の区切り（87.0%）より大きく低いのはなぜか（出典: [qbertの行動固定を評価時だけ外す比較](../../../experiments/default-dqn/atari/2026-10-29_temporl-auxiliary-only-stage0.md)、探索ブロック03）。
- TorchRL の論文が報告した Atari のスコアは、どの版・sticky actions・評価手順で再現されるか。調査した公開資料では条件がそろわなかった。（出典: [Survey: TorchRL の設計と現状 ― Transforms、実装の参考、実験結果の比較元](../../../../reports/survey/torchrl_survey_2026-11-20.md)、13. 調査の限界）。
