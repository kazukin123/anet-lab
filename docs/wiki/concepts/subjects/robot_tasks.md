# 実ロボット課題の選定

[anet-lab](../../../../README.md) › [wiki の目録](../../index.md) › [題材](../../index.md#題材)

## 今の結論

実機候補の調査では、自動resetと成功検知が可能なアーム・治具・制御リグが挙がった。価格が安くても長時間の自律収集が成立するとは確定していない。

## 分かっていること

### anet の知見

なし

### 外の事例

- 2026-08の調査は、自動resetと成功検知が可能なアーム・治具や制御リグを候補として整理した。価格の安さだけで長時間の自律収集が可能とは判断していない。（出典: [real_robot_offline_rl_candidates_2026-08-14.md](../../../../reports/survey/real_robot_offline_rl_candidates_2026-08-14.md)、1. 結論・2.2 実機で本当に高価なのは reset）。
- 調査はサンプル効率を測る候補として自動復帰リグを、接触を含む offline RL の候補としてダイヤルや引き出しなど正逆を繰り返せる課題を挙げた。各装置で長時間の無人実行に成功したという実測ではない（出典: [実ロボットでサンプル効率・オフライン学習を行う候補サーベイ](../../../../reports/survey/real_robot_offline_rl_candidates_2026-08-14.md)、1. 結論「1.1 第一候補」）。
