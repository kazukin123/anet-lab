# 会話から wiki を引く・書く

Codex は `$anet-query-wiki`、Claude Code は `/anet-query-wiki`。問いは今の会話から取る。実行前に [wiki の規約](../../../docs/wiki/README.md#anet-query-wiki)の手順と書く先の表、[発言の記録の基準](../../../AGENTS.md#発言の記録の基準)を読む。

1. [目録](../../../docs/wiki/index.md)で題材名・別名を引き、該当する概念のページを読む。知見は「今の結論」「横断的知見」「見立て」の順に見て、必要な「分かっていること」を読む。出典を開く前に、wiki に答えがあったかを規約の「判定と `query` の行」の表で付け、「答えがある」なら答えていた項目のページと節を控える。同じ会話の中で書いた項目は、無いものとして付ける。そのあと出典の該当箇所を確かめる。実装の経緯ならトピック別まとめから該当の RFD・ADR へ進む。事例を探す順は概念のページ、資料別サマリ、[サーベイの索引](../../../reports/INDEX.md)、見出しと本文の検索、web。確かめた事実の出典には元の資料を使う。
2. 答える前に出典と比較の条件を照合する。wiki と出典が食い違えば正本に合わせて是正し、作業の記録に `fix` を足す。答えに読んだページ名を1行で示し、出典を添える。
3. 答えに複数の中身があれば、規約の表で一つずつ上から判定する。今の会話の見立て・仮説・疑問にも同じ表を使う。発言は記録の基準に従って要旨・日付・出どころを記し、確定した決定と分ける。表と発言の基準で確認を求める場合は、確認が済んだ範囲だけを書く。
4. その応答中に正本または該当ページを更新し、正本を更新したら [取り込みの手順](../anet-ingest-wiki/SKILL.md)でサマリと概念のページに反映する。作業の記録に、質問 1 つにつき `query` の行を 1 行、`YYYY-MM-DD query <問いか発言の 1 行> → <書いた所。書かなければ「なし」>（判定: <値>。根拠: <ページと節。無ければ「なし」>）` の形で足す。何も書かなかった質問も足す。開発者の発言を書いた分は、値を「発言」にして行を分ける。要旨を書けない質問は「（要旨なし）」と書く（規約の「判定と `query` の行」）。正本を取り込んだ分の `ingest` も記録する。答えの末尾に書いた先を1行で知らせる。記録しないと決めた発言をログに写さない。
5. Plan Mode は読み取りと回答までとし、書く内容と行き先を計画に残す。`query` の行は足さない。
